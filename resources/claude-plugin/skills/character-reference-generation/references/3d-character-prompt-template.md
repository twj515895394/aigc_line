# 3D 半写实人物角色设计图提示词参考

当目标风格包含“3D、半写实、国漫 CG、游戏 CG、影视 CG、虚拟偶像、高级时装 CG”时，使用本参考补充材质与渲染用语。**版式以 `image-prompt-skill` 角色资产默认四区设计图为准，不要使用本文件旧示例中的头部+正侧背四联。**

## 使用原则

- 把示例视为结构与细节密度参考，不要逐字复制。
- 必须按角色档案替换性别、年龄、族裔特征、身高、体型、气质、发型、妆容、服装和配饰。
- “18—20 岁男性”“2.2 米”“九头身”“韩系潮男”等都是示例变量，不是全局默认值。只有剧情明确需要时保留。
- 不要用“英俊、白皙、不女性化”等示例偏好覆盖用户指定的女性、儿童、老人、不同肤色、不同审美或非人角色。
- 版式固定为 16:9 三大版面四功能区：左列正面无头全身、中列背面含后脑不露脸全身、右侧上下为中性与微笑 3/4 面部特写。
- 全身保持自然中立站姿和双臂自然下垂，不使用 A-pose 或 T-pose。
- 身份底图重点固定不可变身份；场景派生图必须以底图为唯一人物参考，只改变明确指定的服装、妆造、湿污、伤妆或随身物状态。

## 推荐结构

按以下顺序组织提示词：

1. 媒介、渲染与角色总体气质；
2. 年龄、性别表达、骨相、五官、肤质、发型和身份标记；
3. 四区必须同一人物的一致性声明；
4. 16:9 四区布局、各区职责和自然站姿；
5. 身体比例与完整入镜要求；
6. 服装轮廓、层次、材质、颜色、结构和背面设计；
7. 无缝影棚背景、主光、轮廓光、发丝光、镜头和画质；
8. 与当前角色冲突风险相关的精简负面约束。

## 场景派生图适配骨架

场景派生仍是中性影棚四区人物资产，不把环境参考图画进角色设计图中：

```text
以输入身份底图为唯一人物参考，保持其高精度[3D风格]、脸型、五官、年龄、肤色/材质、体型、发型、发色和身份标记严格不变。只把四区人物统一调整为[目标场景对应的服装、妆造、湿污、破损、伤妆、配饰或随身物状态]，服装正面和背面结构完整一致。
```
