# Video Prompt Skill

一个面向 AI 视频生成的通用 Prompt Skill。

它把用户的创作意图、参考图片、参考视频和音频，转换成可直接用于视频模型的完整 Prompt、镜头级时间轴或多镜头 Prompt Pack。

项目采用 **模型无关核心 + 轻量模型适配层** 的架构：先完成通用导演方案，再根据目标模型转换表达方式。

## 能解决什么问题

支持以下任务：

- 文生视频；
- 图生视频；
- 多图、多视频、多音频混合参考；
- 视频动作、表演、运镜、节奏或特效复刻；
- 视频转视频；
- 视频局部编辑；
- 视频向前或向后延长；
- 对白驱动、音频驱动和音乐卡点；
- 故事板、分镜、多镜头和多片段视频；
- 失败 Prompt 诊断与重写。

Skill 不只补充风格词，而是优先解决：

1. 视频从什么状态开始；
2. 谁或什么在运动；
3. 动作如何按时间发展；
4. 镜头为什么动、怎样动、停在哪里；
5. 人物、场景、道具和空间如何保持连续；
6. 表演、对白、环境音和音乐如何同步；
7. 最后一拍如何自然收束。

## 两种运行模式

### 快速模式

默认模式。

除非用户明确要求讨论、脑暴、逐步设计或先提问，否则 Skill 会：

- 不追问；
- 不要求用户确认中间方案；
- 自动补足不影响主方向的缺失信息；
- 直接输出可复制使用的最终 Prompt；
- 简单任务默认只提供一个主版本；
- 不默认展示内部分析、自动补全项或无价值备选方案。

### 交互模式

只有用户明确希望共同设计时启用。

交互模式遵循：

- 每次只问一个最关键的问题；
- 每个问题同时给出推荐答案与理由；
- 已确认的信息不重复询问；
- 能从上下文和参考素材确定的内容不追问；
- 当剩余问题只影响轻微细节时立即收口并交付最终结果。

## 正式支持的模型输出

### Generic

默认模型无关协议。

适合：

- 用户未指定模型；
- 需要跨平台迁移的通用视频 Prompt；
- 不希望使用某个平台专属素材引用语法。

Generic 不伪造平台参数、时长限制、分辨率或素材引用语法。

### Seedance 2.0

适合：

- 图片、视频、音频混合参考；
- 视频编辑；
- 视频延长；
- 对白、声音和音乐卡点；
- 使用 `@图片N / @视频N / @音频N` 绑定素材职责。

每份素材都必须声明用途，不能写成“综合参考所有素材”。

### LTX-2.3

适合：

- 自然语言导演式 Prompt；
- 连续人物表演；
- 对白、停顿、呼吸和视线变化；
- 图生视频中的自然运动延续；
- 同步音频描述。

最终 Prompt 默认压缩为具体、流动、现在时的自然语言段落。

当前不建设 Kling、Veo、Sora、Runway 等其他平台的空适配页。未正式支持的模型默认使用 Generic 协议。

## 使用示例

### 文生视频

```text
生成一段 10 秒写实办公室视频：一名员工发现桌上的文件有问题，先快速翻看两页，短暂停顿后抬头看向同事，镜头不要乱飘，最后自然停住。
```

### 首帧图生视频

```text
把这张图片作为首帧。人物先保持当前姿势一秒，然后自然起身，拿起桌上的文件离开画面。保持人物、服装、场景和光线一致。
```

### Seedance 多模态参考

```text
使用 Seedance 2.0：图片 1 提供人物身份，图片 2 提供场景，视频 1 只参考动作与身体节奏，音频 1 提供对白和时间节拍。生成一段 12 秒视频。
```

### LTX 连续表演

```text
按 LTX-2.3 格式生成：两个人在餐桌旁进行一段克制对话，包含短暂停顿、视线回避、呼吸变化和轻微手部动作，镜头缓慢推进并自然停住。
```

### 失败 Prompt 诊断

```text
这段 Prompt 生成后人物一直变脸，镜头也在乱绕。请定位主要原因并重写成可直接使用的版本。
```

## 架构概览

```text
用户输入
→ 输入理解
→ 任务 Playbook
→ 按需控制
→ 按需资料库与风格
→ 模型适配
→ 输出合同
→ 失败时诊断
```

### 输入层 `references/inputs/`

负责理解输入素材及其职责：

- 纯文字；
- 单图；
- 多图；
- 视频；
- 音频；
- 混合多模态。

### 任务层 `references/tasks/`

负责决定任务流程：

- 文生视频；
- 图生视频；
- 多模态参考；
- 视频复刻 / 视频转视频；
- 视频编辑；
- 视频延长；
- 音频驱动；
- 故事板 / 多镜头。

### 控制层 `references/controls/`

负责判断、协调和限制：

- 时间轴与节拍；
- 主体运动；
- 镜头方向；
- 空间调度；
- 连续性；
- 表演与微表情；
- 音画同步；
- 参考素材绑定；
- Prompt 组装；
- 真实感与物理可信。

### 资料库 `references/libraries/`

提供详细可选项：

- 镜头、机位、焦段和运镜；
- 动作、打击、体育和物理反馈；
- 表情、微表情和对白表演；
- 转场与视觉特效；
- 光影与色调；
- 环境音、拟音和 BGM；
- 题材级节拍与组合。

### 风格层 `references/styles/`

说明风格如何被执行：

- 电影化真人；
- 写实短剧；
- 动画；
- AI 漫剧 / 动态漫画；
- 商业广告；
- 纪录 / UGC；
- 实验影像。

### 模型层 `references/models/`

只负责模型能力边界和表达转换：

- Generic；
- Seedance 2.0；
- LTX-2.3。

### 诊断层 `references/diagnostics/`

只在用户反馈生成失败时读取。当前包含：

- 身份漂移；
- 动作断裂；
- 镜头失控；
- 空间瞬移；
- 肢体与接触错误；
- 失重与物理错误；
- 口型与对白错误；
- 音画不同步；
- Prompt 过载与冲突；
- 素材职责冲突。

## Reference 加载原则

Skill 不会一次性加载整个知识库。

典型任务固定读取：

- 1 份输入 Reference；
- 1 份任务 Playbook；
- 1 份模式输出合同；
- 1 份主交付模板。

按需读取：

- 0–3 份 controls；
- 0–2 份 libraries；
- 0–1 份 style；
- 0–1 份 model adapter；
- 失败诊断时 0–1 份 diagnostic。

详细路由见 [`references/index.md`](references/index.md)。

## 输出原则

- 主体运动和镜头运动分开描述；
- 一段视频保留一个主镜头任务；
- 多模态素材必须绑定明确职责；
- 每个关键维度只能有一个主真源；
- 情绪优先改写成眼神、呼吸、姿态和小动作；
- 光影与声音必须有场景来源；
- 负向限制只针对当前最危险的失败模式；
- 最后一拍必须有自然落点；
- 不用导演名、品牌名或质量词代替可执行设计。

## 项目边界

本仓库提供的是 Prompt Skill 与知识架构，不包含视频模型推理服务，因此仓库验证不等于模型实机效果验证。

实际生成中的以下能力仍受目标模型影响：

- 人脸与服装稳定率；
- 手部和复杂接触动作；
- 高强度体育和打斗动作；
- 口型、对白和同步音频；
- 视频编辑与延长的产品端能力；
- 平台实时素材数量、时长和分辨率限制。

模型规格发生变化时，应更新对应模型适配页并注明来源与复核日期。
