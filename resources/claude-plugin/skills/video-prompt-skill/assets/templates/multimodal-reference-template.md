# 多模态参考视频模板

## 适用范围

用于同时存在图片、视频、音频和文字目标中的两种或以上输入，或单一模态中存在多个互相分工的素材。

本模板负责对外保留执行所需的素材职责，不展示内部完整审计过程。

## 内部素材职责表

复杂任务内部先建立：

```text
| 素材 | 类型 | 主职责 | 辅助职责 | 保留强度 | 禁止继承 | 冲突说明 |
|---|---|---|---|---|---|---|
```

每个关键维度只能有一个主真源：

- 人物身份；
- 服装；
- 场景；
- 动作；
- 运镜；
- 节奏；
- 特效；
- 对白和音色。

## 对外简洁绑定格式

```text
素材职责：
- 参考图 A：人物身份与面部锚点；强保留，不继承背景。
- 参考图 B：服装与配色；不继承人物姿势。
- 参考图 C：场景结构与光影。
- 参考视频 A：主体动作阶段和身体节奏；不继承原人物、服装和场景。
- 参考视频 B：镜头轨迹和转场。
- 参考音频 A：对白、音色和时间节拍。
```

简单任务可以合并成一个自然语言句子。

## 必须保留、允许适配和禁止继承

```text
必须保留：人物身份、主服装识别点、产品外观、主场景结构、关键道具。
允许适配：构图微调、动作幅度、次要背景、光影细节、镜头距离。
禁止继承：参考视频中的原人物和剧情、无关文字水印、冲突服装、冲突场景、错误品牌元素。
```

只列当前任务相关内容。

## 兼容性检查

写最终 Prompt 前检查：

- 首帧姿态是否能自然进入动作视频的第一阶段；
- 尾帧目标是否可由当前动作和空间到达；
- 不同图片中的人物身份和身体比例是否冲突；
- 场景参考与运镜路线是否有足够空间；
- 音频节拍是否与动作和镜头数量匹配；
- 同一维度是否被多个素材同时强绑定；
- 是否存在无贡献素材可以删除。

不兼容时优先降低辅助参考强度、拆分片段或放弃无关素材，不强迫平均融合。

## Generic 输出

使用语义化素材名：

```text
以人物参考 A 作为唯一人物身份，服装参考 B 提供服装，场景参考 C 提供空间；动作节奏参考视频 A，镜头参考视频 B，声音参考音频 A。
```

## Seedance 2.0 输出

转换为明确的 `@素材` 绑定：

```text
以 @图片1 的人物作为唯一主角，穿着 @图片2 的服装，处于 @图片3 的场景；主体动作和身体节奏参考 @视频1，但不继承其中人物与背景；镜头运动参考 @视频2；对白、音色和节拍参考 @音频1。
```

## LTX-2.3 输出

LTX 最终正文以画面和运动为主。素材职责可以在 Prompt 前用一行说明，正文转成连贯导演描述，不保留冗长素材表。

## 最终 Prompt 骨架

```text
[素材职责与保留边界]
[视频目标与时长]
[全局固定项]
[按时间或镜头描述主体动作、镜头、表演和声音]
[光影与风格延续]
[最终落点]
[连续性和高风险限制]
```

## 输出检查

- 每份素材是否有明确职责；
- 每个关键维度是否只有一个主真源；
- 是否写清只参考什么和不继承什么；
- 首尾帧、动作、场景和音频是否兼容；
- 对外是否只保留执行必要的职责说明；
- 是否已按目标模型转换引用方式；
- 是否避免“综合参考全部素材”之类模糊写法。
