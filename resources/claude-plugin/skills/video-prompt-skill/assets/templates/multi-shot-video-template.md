# 多镜头 / 多片段视频模板

## 适用范围

用于以下任务：

- 两个及以上镜头；
- 多段剧情或多片段视频；
- 故事板到视频；
- 需要跨镜头保持人物、场景、道具和动作状态；
- 需要把较长内容拆成多个模型生成包。

## 第一层：全片固定项

只写跨全片稳定的内容：

```text
全片目标：
总时长 / 分包方式（单包默认 15 秒，更长内容拆包）：
开场角色卡（人数 + 每人外貌 / 穿着 / 当前状态）：
人物身份与主外观：
主服装、饰品与关键道具：
场景骨架与空间原点（前中后景；简单场景 2–4 物件，复杂场面继承可见骨架）：
主光源、色调与渲染方式：
声音主线（环境 / 拟音 / 对白 + BGM 决定）：
跨镜连续性：
模型适配：
```

不要在每个镜头重复完整角色和场景说明。

## 第二层：段落规划

当视频存在多个叙事段落时，先确定：

```text
Segment 1：段落目标 + 进入状态 + 结束交接状态
Segment 2：承接上一段 + 段落目标 + 结束交接状态
Segment 3：承接上一段 + 高潮 / 结果 + 最终落点
```

每段必须回答“为什么需要这一段”，不能只是时间切块。

## 第三层：镜头单元

每镜统一使用：

```text
Shot [编号]｜[绝对时间]
镜头任务：
起始景别与机位：
主体起始状态：
主体动作 / 表演链：
镜头运动（主运镜 + 路线 + 速度 + 停止；固定机位须写明）：
环境、周边物件与声音反馈：
结束状态：
与下一镜承接：
```

快速模式可以压缩成自然语言，但字段顺序必须在语义上保留。

## 推荐最终输出骨架

```text
全片固定项：...

Segment 1｜[时间范围]｜[段落目标]
Shot 01｜0.0-...
[主体状态和动作]；镜头 [运动]；[表演、环境和声音]；最终 [落点]。

Shot 02｜...-...
从上一镜的 [状态] 开始；[动作与镜头]；最终 [交接状态]。

Segment 2｜...
...

全片连续性与失败限制：...
```

## 跨镜承接规则

相邻镜头必须至少承接以下一项：

- 人物姿态或动作阶段；
- 视线和朝向；
- 道具所在手、位置和状态；
- 空间位置或出入口；
- 镜头运动方向；
- 声音、对白或音乐；
- 光影和时间变化。

切镜允许改变景别和视角，但不能无理由重置全部状态。

## 跨包生成规则

当模型时长不足，需要拆成多个生成包时：

```text
Pack 1 结尾交接帧：人物姿态、朝向、道具、镜头位置、环境状态、声音状态。
Pack 2 开头继承：逐项继承上述状态，再继续新动作。
```

每个 Pack 自身必须可独立复制，同时保留必要全局锚点。

## 故事板转换规则

故事板提供的是关键状态，不自动等于连续运动。转换时补足：

- 镜间动作如何发生；
- 镜头为何切换；
- 道具和空间如何连续；
- 哪些画格属于同一动作阶段；
- 哪些画格需要拆成不同生成片段。

## 镜头密度控制

- 简单情绪片段：镜头更少、停留更长；
- 动作和广告：可增加镜头，但每镜只承担一个清楚任务；
- 短时长内不要为每个动作细节都新增镜头；
- 镜头数量由叙事和模型可执行性决定，不由“丰富感”决定。

## 输出检查

- 全局固定项是否只写一次，且开场有角色卡和空间物件；
- 每个段落是否有明确目标；
- 每镜是否有开始、推进和结束状态；
- 每镜运镜是否写了任务 / 主运动 / 停止，而不是只写景别；
- 表演峰值人物是否有可见信号链；
- 声音是否分层，BGM 是否显式决定；
- 相邻镜头是否存在可验证的承接；
- 道具、站位、朝向和运动轴线是否连续；
- 分包交接状态是否足以复现；
- 是否避免重复输出故事梗概和同义 Prompt；
- 是否按目标模型正确组织最终文本。
