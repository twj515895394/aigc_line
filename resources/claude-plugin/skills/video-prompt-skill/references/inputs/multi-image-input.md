# Multi Image Input

## 1. 适用范围

用户提供两张或以上图片，并由这些图片共同决定视频中的人物、服装、场景、道具、首尾帧、动作、构图、光影或风格时读取本页。

核心原则：

> 多图不是平均融合，而是职责绑定。

---

## 2. 先建立素材职责表

```text
图片编号：
主要职责：
可借用内容：
禁止继承内容：
保留强度：高 / 中 / 低
是否主参考：是 / 否
```

常见职责：

- 人物身份；
- 脸部和发型；
- 服装与配色；
- 场景与空间；
- 道具；
- 首帧；
- 尾帧；
- 关键动作；
- 构图和机位；
- 光影和色调；
- 视觉风格。

---

## 3. 主参考判断

优先级：

1. 用户明确指定的主图；
2. 承担人物身份和整体构图的图片；
3. 第一张与用户目标最一致的图片；
4. 其他图片作为单维度辅助参考。

同一维度只能有一个主参考。其他图片只能补充，不得与主参考竞争。

---

## 4. 冲突处理

### 人物冲突

分别绑定人物 A、人物 B，或指定唯一身份主图。禁止把两张不同人物脸平均融合。

### 服装冲突

明确哪张图提供上装、下装、配色或完整服装；没有指定时，优先采用主人物图的服装。

### 场景冲突

只选择一个主场景。其他场景图只能提供局部道具、材质或光影，不能把多个空间强行拼接。

### 构图与动作冲突

首帧构图优先于辅助动作图。动作图提供身体关系和运动方向，不覆盖主图身份和场景。

### 风格冲突

选择一个主风格机制。其他图片只提供色调、材质或局部氛围，不并列堆叠多个媒介风格。

---

## 5. 首帧与尾帧组合

当两张图分别为首帧和尾帧时，检查：

- 是否同一人物和服装；
- 是否同一场景与光源；
- 姿态和空间是否存在可达路径；
- 道具状态是否能连续变化；
- 镜头位置变化是否合理；
- 目标时长是否足以完成动作。

如果首尾差异过大，任务层应拆为多镜头或加入关键过渡帧，而不是强行单镜头变形。

---

## 7. 何时进入混合输入

如果用户同时提供视频或音频，不再读取本页，统一路由到 `mixed-multimodal-input.md`，由混合输入页建立完整素材职责表。
