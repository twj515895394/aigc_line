# Text Input

## 1. 适用范围

用户只提供文字目标，没有图片、视频或音频参考时读取本页。

输入层只负责把文字整理成可供任务 Playbook 使用的素材描述，不直接完成最终 Prompt。

---

## 2. 提取字段

从用户文字中提取：

```text
创作目标：
主体：
场景：
初始状态：
核心动作 / 情绪变化：
期望镜头：
时长与比例：
风格与质感：
对白与声音：
必须保留：
禁止出现：
指定模型：
```

没有明确给出的非关键字段可以交由任务层自动补全。

---

## 3. 自动扩展原则

### 可以补全

- 最少量场景空间；
- 能让动作成立的初始姿态；
- 单镜头的自然时长和收尾；
- 支撑情绪的光影与环境声；
- 当前任务最危险的连续性限制。

### 不可擅自补全

- 新角色；
- 新剧情线；
- 强反转；
- 大世界观；
- 用户没有暗示的对白；
- 会改变核心意图的镜头结构。

---

## 4. 可视化改写

把抽象词转换为可观察内容：

- “紧张” → 呼吸变浅、视线游移、手指收紧；
- “电影感” → 具体镜头、光源、色调、景深和节奏；
- “很快” → 动作阶段、速度变化、环境反馈；
- “高级” → 材质、光比、构图和色彩秩序；
- “自然” → 微小停顿、惯性、呼吸和设备记录感。

---

## 5. 冲突处理

优先级：

```text
明确任务目标
→ 必须保留 / 禁止变化
→ 动作和叙事可读性
→ 镜头可执行性
→ 风格修饰
```

例如用户同时要求“固定机位”和“高速环绕跟拍”，必须保留更符合核心目标的一项，不能把互斥要求全部写入最终 Prompt。

---

## 6. 输出给任务层

```text
输入类型：纯文字
目标任务候选：
已知变量：
自动补全变量：
核心视觉起点：
核心运动目标：
声音需求：
模型指定：Generic / Seedance / LTX / 未指定
主要风险：
```

任务明确且信息足够时，不向用户追问。只有核心目标、时长和内容完全无法对应时，才进入交互模式询问一个关键问题。
