# Video Input

## 1. 适用范围

用户提供一个或多个视频作为主要输入或参考时读取本页。

视频可能承担：

- 待编辑主体；
- 待延长主体；
- 动作参考；
- 表演参考；
- 运镜参考；
- 节奏和剪辑参考；
- 特效或转场参考；
- 场景动态参考；
- 声音、对白或音色参考。

先判断视频职责，再决定是复刻、编辑、延长还是仅借用某一动态维度。

---

## 2. 视频职责分析

```text
视频编号：
主要职责：
时间范围：全片 / 指定片段
需要继承：
禁止继承：
是否待编辑主体：
是否待延长主体：
保留强度：高 / 中 / 低
```

不要只写“参考该视频”。必须拆出具体维度。

---

## 3. 动态提取维度

### 主体运动

- 初始姿态；
- 动作阶段；
- 速度与节奏；
- 重心、惯性和接触；
- 动作落点。

### 表演

- 视线；
- 表情变化；
- 呼吸和停顿；
- 手部与身体小动作；
- 对白时的表演节拍。

### 镜头

- 景别和机位；
- 运动类型和路线；
- 运动开始与停止节点；
- 焦点变化；
- 切镜和转场。

### 空间

- 人物与道具位置；
- 行动路线；
- 前中后景；
- 摄影机可移动范围；
- 场景结构是否连续。

### 声音

- 对白；
- 音色；
- 环境音；
- 拟音；
- BGM；
- 声音与动作的同步点。

---

## 4. 多视频职责

多个视频不能全部设为“完整参考”。应分别绑定：

```text
视频 1：主体动作
视频 2：镜头运动
视频 3：节奏、特效或声音
```

同一维度存在冲突时：

1. 用户明确指定的视频优先；
2. 待编辑主体优先保持原视频；
3. 与任务目标最匹配的视频作为主参考；
4. 其他视频只提供局部动态机制。

---

## 5. 待编辑视频

提取：

```text
必须保留：
必须修改：
允许变化：
禁止变化：
原视频时长与镜头结构：
原主体动作：
原场景与声音：
```

只修改指定内容时，不应自动重新设计运镜、节奏或剧情。

---

## 6. 待延长视频

必须读取接点状态：

- 最后一帧或第一帧的主体姿态；
- 动作方向和速度；
- 镜头位置、方向和速度；
- 光影和天气；
- 声音正在发生什么；
- 道具和空间状态。

延长部分必须从接点自然继续，不能重置动作或突然切换场景。

---

## 7. 输出给任务层

```text
输入类型：视频
主视频：
视频职责：
继承维度：
禁止继承：
待编辑 / 待延长状态：
动作结构：
镜头结构：
声音结构：
主要连续性风险：
指定模型：
```

如果同时存在图片或独立音频，路由到 `mixed-multimodal-input.md`。
