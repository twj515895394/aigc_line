# Audio Input

## 1. 适用范围

用户提供独立音频，并希望音频决定对白、音色、节拍、口型、动作、镜头或整体时间结构时读取本页。

音频可能是：

- 对白；
- 旁白；
- 歌唱；
- BGM；
- 节拍轨；
- 环境音；
- 拟音；
- 混合音轨。

---

## 2. 音频职责判断

```text
音频职责：
时间范围：
说话人 / 声源：
语言与音色：
节拍结构：
关键声音事件：
是否驱动口型：
是否驱动画面剪辑：
是否只作为氛围参考：
```

不要默认所有音频都驱动口型或镜头卡点。

---

## 3. 时间结构提取

按任务需要识别：

- 开始和结束；
- 句子或歌词段落；
- 重音和停顿；
- 节拍点；
- 音乐段落变化；
- 音效爆点；
- 渐入、渐强、突停和渐出。

输出可以使用：

```text
0–2 秒：声音事件 / 对白
2–5 秒：声音事件 / 节拍变化
5–8 秒：声音事件 / 收束
```

只有关键节点需要绑定视觉事件，不为每个节拍强行设计切镜。

---

## 4. 对白与口型

需要提取：

- 说话人；
- 每句开始和结束；
- 语速、音量和音色；
- 停顿和呼吸；
- 情绪变化；
- 是否需要精确口型；
- 说话时可见的身体动作。

对白较长时，任务层应拆成短句和表演节拍，避免人物持续机械张嘴。

---

## 5. BGM 与卡点

BGM 可以承担：

- 整体节奏；
- 情绪曲线；
- 转场节点；
- 动作爆点；
- 品牌或结尾落点。

卡点应绑定明确视觉事件：

```text
鼓点：动作命中
节奏切换：镜头或场景切换
音乐停顿：人物凝视或动作突停
高潮进入：主体动作或空间揭示
尾音：画面定格、后拉或渐暗
```

---

## 6. 环境音与拟音

声音必须有画面来源和空间位置：

- 近处脚步；
- 远处交通；
- 房间混响；
- 风吹衣物；
- 道具碰撞；
- 雨声或机械声。

不要堆叠与场景无关的声音，也不要让 BGM 覆盖关键对白和动作反馈。

---

## 7. 输出给任务层

```text
输入类型：音频
音频职责：
时间骨架：
对白 / 歌词：
节拍和爆点：
声音空间：
口型需求：
视觉事件绑定建议：
主要风险：
指定模型：
```

如果同时存在图片或视频，路由到 `mixed-multimodal-input.md`。
