# Single Image Input

## 1. 适用范围

用户提供一张图片作为视频输入或参考时读取本页。

图片可能是：

- 首帧；
- 尾帧；
- 角色参考；
- 场景参考；
- 关键帧；
- 单格分镜；
- 风格或光影参考。

首先判断图片职责，再决定需要保留什么和允许什么运动。

---

## 2. 图片职责判断

### 首帧

重点提取：

- 主体和身份锚点；
- 当前姿态与重心；
- 构图、景别和镜头位置；
- 场景空间和主要道具；
- 光源、色调和材质；
- 可运动元素；
- 从静止进入运动的自然方向。

### 尾帧

重点提取：

- 目标姿态；
- 动作落点；
- 镜头最终位置；
- 表情和情绪结果；
- 道具、场景和光影最终状态。

### 角色参考

重点提取：

- 脸部、年龄感、体型；
- 发型、服装、配色和配饰；
- 不可变化的身份特征；
- 允许随动作变化的头发、衣物和表情。

### 场景参考

重点提取：

- 空间结构；
- 前中后景；
- 出入口和行动路线；
- 主要道具位置；
- 光源方向；
- 镜头可移动范围。

### 关键帧 / 分镜

重点提取：

- 当前动作阶段；
- 前一阶段可能来自哪里；
- 下一阶段应如何继续；
- 镜头任务；
- 与相邻镜头的承接需求。

### 风格参考

只提取光影、色彩、构图、材质和媒介机制，不默认复制图片中的人物、场景或剧情。

---

## 3. 图像分析结构

```text
图片职责：
主体锚点：
当前姿态与重心：
场景与空间：
构图、景别与机位：
光影与色调：
材质与风格：
可运动元素：
必须保持稳定：
允许变化：
禁止新增：
```

不要把图片当小说重写。只提取影响运动和一致性的内容。

当图片是**唯一首帧 / 唯一视觉锚点**时，额外提取一份继承清单，供任务层写进全局锁，而不是每段复述：

```text
人数与左右身份：
每人外貌 / 身材比例 / 服装 / 饰品：
当前姿态与接触状态：
场景骨架：建筑、地面、摊位、人群、天空、电线、招牌等可见结构
构图 / 景别 / 机位高度 / 透视：
光源方向、色温、整体色彩：
画面媒介：二维厚涂 / 赛璐璐 / 写实真人 / 插画电影感 等
```

如果画面已经处于出拳接触、失衡、腾空或闪避中途，把该姿态标为 **动作中点**，不是静止开场。

---

## 4. 从图片到运动

先写主体运动，再写镜头运动：

```text
当前状态
→ 起始微动作
→ 核心动作或表演
→ 环境响应
→ 镜头跟随或观察
→ 最终状态
```

图片提供了视觉起点时，Prompt 的重点是“从当前状态接下来发生什么”。

- 画面是静止站位：先写起始微动作，再进入主动作。
- 画面已是动作中点：第 0 秒直接接续该接触 / 受力 / 运动，不重新摆姿势、不停顿、不先“保持一秒”。

---

## 5. 保留与变化边界

### 默认保留

- 人物身份；
- 服装主结构；
- 场景主结构；
- 光源方向；
- 画面风格；
- 主要道具和空间位置。

### 可以自然变化

- 眼神、表情和呼吸；
- 姿态和重心；
- 头发、衣物和饰品的动态；
- 道具因动作产生的合理变化；
- 镜头距离和构图。

### 默认禁止

- 无关人物或物体；
- 人物换脸、换装或年龄变化；
- 场景瞬移；
- 光源无原因改变；
- 动作阶段重置；
- 背景结构随机重绘。

---

## 6. 输出给任务层

```text
输入类型：单张图片
图片职责：
必须保留锚点 / 首帧继承清单：
动作中点接续：是 / 否
可运动元素：
主体运动起点：
镜头起点：
允许变化：
禁止变化：
主要连续性风险：
指定模型：
```

如果图片职责可从用户要求和画面推断，不追问用户。
