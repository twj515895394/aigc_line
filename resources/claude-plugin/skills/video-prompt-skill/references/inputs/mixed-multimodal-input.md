# Mixed Multimodal Input

## 1. 适用范围

用户同时提供图片、视频、音频中的两种或以上模态时读取本页。

本页作为唯一主输入 Reference，不再同时读取单图、多图、视频和音频输入页。

核心原则：

> 每份素材必须绑定职责；同一维度只能有一个主真源。

---

## 2. 素材职责矩阵

```text
素材编号：
素材类型：图片 / 视频 / 音频
主要职责：
次要职责：
时间或局部范围：
必须继承：
禁止继承：
保留强度：高 / 中 / 低
是否该维度主真源：是 / 否
```

常见职责维度：

- 人物身份和面部；
- 发型、服装和配色；
- 场景、空间和道具；
- 首帧、尾帧和关键帧；
- 主体动作；
- 表演和微表情；
- 运镜和镜头路线；
- 剪辑节奏；
- 转场和特效；
- 对白、音色和口型；
- BGM、环境音和拟音；
- 光影、材质和风格。

---

## 3. 推荐职责分配

示例：

```text
图片 1：人物身份和服装
图片 2：场景和空间
视频 1：动作编排
视频 2：运镜和转场
音频 1：对白、音色和时间骨架
```

不要写：

```text
综合参考所有图片、视频和音频。
```

这种写法没有说明冲突如何裁决，也无法稳定保持身份和空间。

---

## 4. 主真源规则

每个维度只能指定一个主真源：

```text
人物身份真源：
服装真源：
场景真源：
动作真源：
镜头真源：
节奏真源：
声音真源：
风格真源：
```

辅助素材只补充该维度未覆盖的信息，不能覆盖主真源。

---

## 5. 冲突裁决

优先级：

```text
用户明确指定职责
→ 待编辑 / 待延长主体素材
→ 人物、场景等主真源
→ 当前任务 Playbook
→ 辅助素材
→ 自动补全
```

### 常见冲突

- 图片人物与视频人物不同：保留图片身份，只借视频动作或运镜。
- 图片场景与视频场景不同：保留图片场景，只借视频动态机制。
- 音频节奏与参考视频节奏不同：明确哪一个决定时间骨架，另一个只提供局部参考。
- 首帧与尾帧差异过大：拆镜或加入关键过渡，不强行单镜头变形。
- 多个视频都提供动作：选择一个主动作参考，其他只提供局部阶段。

---

## 6. 时间轴统一

不同模态必须映射到同一时间轴：

```text
时间段：
视觉主体状态：
动作参考来源：
镜头参考来源：
声音参考来源：
场景和身份固定项：
该段结束状态：
```

音频或视频可以作为主时间骨架，但不能让多个素材同时定义互相冲突的节奏。

---

## 7. 模型适配前的标准化输出

```text
输入类型：混合多模态
任务候选：
素材职责矩阵：
各维度主真源：
全局固定项：
时间骨架：
主体动作来源：
镜头来源：
声音来源：
允许变化：
禁止继承：
冲突裁决：
主要连续性风险：
指定模型：
```

Seedance 的 `@图片 / @视频 / @音频` 语法由模型适配页添加；输入层只输出语义职责。

---

## 8. 追问条件

只有以下情况才需要交互确认：

- 两份素材在人物身份上冲突，且用户未说明保留谁；
- 两个视频同时被要求完整复刻，但动态结构互斥；
- 音频和视频都被指定为唯一时间骨架；
- 首尾状态在目标时长内明显不可达。

每次只问当前最影响结果的一个问题，并提供推荐答案。
