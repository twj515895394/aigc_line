# Inputs Index

输入层只负责判断用户提供了什么素材、每份素材承担什么职责，以及素材之间如何处理冲突；不负责决定视频任务流程。

每次只读取一份主 input Reference。混合素材统一进入混合输入路线，不再同时读取多份单模态输入页。

## 纯文字

读取：`text-input.md`

适用：没有图片、视频或音频参考，需要从文字建立初始画面、动作和时间信息。

## 单张图片

读取：`single-image-input.md`

适用：首帧、尾帧、角色图、场景图、关键帧或单张分镜图。若图片是唯一首帧锚点，提取继承清单，并判断要从静止起动还是从动作中点接续。

## 多张图片

读取：`multi-image-input.md`

适用：多张图片分别承担人物、服装、场景、动作、首尾帧、构图或风格职责。

禁止平均融合。必须明确主参考、辅助参考和每张图的职责边界。

## 视频输入

读取：`video-input.md`

适用：视频作为动作、运镜、节奏、特效、表演、声音或待编辑主体。

单视频和多视频共用此入口，由正文继续判断主视频和辅助视频。

## 音频输入

读取：`audio-input.md`

适用：对白、旁白、音色、环境音、BGM、节拍或口型驱动。

## 图片 / 视频 / 音频混合输入

读取：`mixed-multimodal-input.md`

适用：两种或以上模态共同参与结果。

该路线必须建立素材职责表，至少区分：

- 视觉身份与外观；
- 场景和空间；
- 动作和表演；
- 运镜和剪辑节奏；
- 对白、音色、BGM 与环境音；
- 首帧、尾帧和关键过渡状态。

## 冲突优先级

```text
用户当前明确要求
→ 用户指定的素材职责
→ 主参考素材
→ 当前任务 Playbook
→ 辅助素材
→ 自动补全
```

模型专属的素材数量、格式和引用语法不放在输入层，统一由 `references/models/` 处理。
