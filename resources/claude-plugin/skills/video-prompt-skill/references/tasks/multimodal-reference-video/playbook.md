# Multimodal Reference Video Playbook

## 1. 适用范围

图片、视频、音频中的至少两种共同决定最终视频时读取本页。

输入 Reference：`inputs/mixed-multimodal-input.md`。

本任务重点不是增加素材数量，而是把每份素材稳定映射到人物、场景、动作、镜头、节奏和声音等职责。

---

## 2. 核心目标

```text
素材职责绑定
→ 确定各维度主真源
→ 统一时间骨架
→ 组装主体、镜头和声音
→ 保持跨模态连续性
→ 转换为模型专属引用语法
```

---

## 3. 必须锁定的变量

```text
主任务：
人物身份真源：
服装真源：
场景真源：
动作真源：
镜头真源：
节奏真源：
声音真源：
首帧 / 尾帧：
目标时长：
禁止继承：
模型：
```

同一维度只能有一个主真源。

---

## 4. 执行流程

### 4.1 读取素材职责矩阵

使用混合输入 Reference 的标准化结果，不重新把所有素材全文分析一遍。

### 4.2 选择时间骨架

优先级通常为：

1. 用户明确指定的音频或视频；
2. 待编辑 / 待复刻的主视频；
3. 故事板或明确时间轴；
4. 根据目标时长自动设计的通用时间轴。

不能让音频和视频同时作为互相冲突的唯一时间骨架。

### 4.3 组装视觉身份和空间

先固定人物、服装、场景和主要道具，再加入动作、运镜和特效。

素材只提供局部职责时，明确“不继承其中的人物 / 背景 / 风格”等边界。

### 4.4 映射动作和镜头

分别建立：

```text
主体动作来源与阶段：
镜头来源与运动节点：
环境响应：
```

参考视频的动作和运镜可以来自不同素材，但必须在统一时间轴上兼容。

### 4.5 映射声音

说明：

- 对白和说话人；
- 音色；
- BGM 和节拍；
- 环境音和拟音；
- 视觉事件与声音节点的对应关系。

### 4.6 建立全局固定项

至少包括：

- 人物身份；
- 服装；
- 场景结构；
- 道具状态；
- 光源与风格；
- 不允许继承的参考内容。

---

## 5. 时间轴结构

```text
[时间段]
主体状态与动作：
动作参考来源：
镜头状态与运动：
镜头参考来源：
声音与节拍：
固定项：
该段落点：
```

不需要在最终 Prompt 中暴露内部“真源”术语，但模型输入必须能看出每份素材的用途。

## 8. 常见失败

- 只罗列素材，不说明用途；
- 多份素材争夺同一人物或场景；
- 参考视频中的人物和背景被错误继承；
- 音频和视频节奏冲突；
- 动作、运镜和特效来源过多，结果失焦；
- 素材之间的首尾状态不可达；
- 把所有模态都写成高强度控制，导致 Prompt 过载。

---

## 9. 模型适配

### Generic

使用“参考图片 A / 参考视频 A / 参考音频 A”的语义化职责描述。

### Seedance 2.0

转换为 `@图片N / @视频N / @音频N`，并在引用后紧跟职责说明。该模型是本任务的主要适配目标。

### LTX-2.3

LTX 最终 Prompt 以连续自然语言为主。参考素材先在内部完成职责标准化，再重点描述视觉和声音如何在时间中发展，避免堆砌素材标签。
