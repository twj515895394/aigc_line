# Cinematic Wuxia Playbook

## 1. 适用范围与职责

用于电影武侠 / 武术动作，包括空手武术与刀、剑、枪、棍交锋。

默认是**电影武侠，不是仙侠**。

本页只负责把：

- `core-playbook.md` 的 State / Continuity；
- `choreography-playbook.md` 的 Coverage / Rhythm / Phrase / Identity / Contact / Signature / Execution Budget；

实例化为**电影武侠**的动作语言、物理尺度、身法、兵器轨迹与音画表现。

本页不重新定义 Core / Choreography 的通用质量合同，也不把现代格斗的重拳物理直接套到武侠。

---

## 2. 电影化物理尺度

可按用户意图选择：

- Level 1｜写实武术：基本不超出现实人体合理范围；
- Level 2｜电影武侠（常用）：允许短距离腾跃、踏墙、滑步、借力飞身、轻微滞空，但必须有起点、路径与落地；
- Level 3｜高武武侠：允许更长飞跃、更强滞空和更夸张的身法节奏，但仍不自动进入剑气、能量波、御剑、法器和长距离无支撑飞行。

物理尺度可以电影化，但状态连续性仍必须成立。

> **电影化 ≠ 无因果漂浮。**

---

## 3. Coverage / Rhythm 的武侠实现

武侠允许更明显的节奏留白，但留白必须服务下一次爆发、读招、空间重建或人物关系；短视频不能让长对峙吞掉主要 Active Combat。

可实现为：

- 重击 / 爆发型：少量更明显的重招、落点和空间变化；
- 均衡拆招型：攻防往复、化解、借力、换位；
- 高手高速交换型：连续拆招、兵器交错、Counter / Re-counter；
- 混合型：高速拆招与一次明显身法 / 兵器 / 环境 Payoff 交替。

“对峙 → 试招 → 拆招 → 身法转折 → 高潮 → 收势”只能作为可能的宏观节奏，不是固定阶段模板。

---

## 4. Wuxia Combat Character Identity

角色打法需要动态推导，例如：

- 进攻更凌厉还是更克制；
- 重视直线爆发还是圆转化解；
- 依赖近身短打、身法换位还是兵器距离控制；
- 防守后倾向借力、偏转、退让、贴身还是反抢主动权；
- 力量、速度、技术、兵器长度、空间利用哪个是主要优势。

门派 / 身份 / 职业只能作为背景知识，不应直接决定固定招式模板。

最终 Character Identity 应通过实际动作、距离和节奏看出来，而不是只写“某某门派风格”。

---

## 5. Action Phrase：武侠拆招与身法

武侠 Action Phrase 的关键不是招式名，而是**读招 → 接招 / 化解 → 改变线路 → 反击 / 借力 → 空间或主动权结果**。

示例结构：

### 拆招型 Phrase

```text
对方攻击建立线路
→ 防守者以身法 / 兵器偏转化解
→ 偏转改变双方角度
→ 防守者借新线路反击
→ 原进攻方继续拆招 / 换距
→ Phrase Payoff
```

### 身法换位 Phrase

```text
攻击压力逼近边界
→ 角色借环境 / 脚步 / 短跃改变身体轴线
→ 对手追击调整方向
→ 新角度产生反击窗口
→ 双方重新建立 Range / Advantage
```

### 兵器距离 Phrase

```text
长兵器保持距离优势
→ 短兵器 / 空手角色偏转兵器主线
→ 顺着偏转窗口贴近
→ 长兵器角色回收 / 改握 / 退步重建距离
→ 形成新主动权关系
```

这些只是因果结构示例，不要求复刻传统套路。

---

## 6. Wuxia Tactical Interaction

高手武侠可按需使用：

- Feint：虚招诱导防守；
- Probe & Read：用轻招测试反应；
- Bait：故意暴露线路；
- Anticipation：提前封住身法 / 兵器回路；
- Counter-to-Counter：拆招之后继续被反拆；
- Pattern Break：连续相似节奏后突然改变；
- Forced Response：用距离 / 兵器角度 / 环境边界逼出固定反应。

最终 Prompt 只写动作线路与时机，不写抽象“内心判断”。

---

## 7. 武侠 Range

可根据任务使用：

- 远距离观察 / 身法切入；
- 长兵器控制距离；
- 中距离兵器交换；
- 刀剑近距；
- 空手近距；
- 缠斗 / 擒拿；
- 脱离 / 重建距离。

长短兵器距离优势必须在动作中看出来。

例如：

- 长枪通过长度与线路保持压制；
- 剑手通过偏转枪头或贴身换距消除长度优势；
- 刀剑近距交换与长兵器中远距离控制采用不同 Phrase 节奏；
- 缴械后自然转入空手近距，而不是状态瞬间重置。

---

## 8. 兵器连续性与 Contact Solidity

兵器场景必须持续维护：

- 当前持握者；
- 必要时的握持方式；
- 大致方向和攻击 / 防守线路；
- 当前攻防距离；
- 格挡 / 招架 / 偏转后的兵器落位；
- 是否脱手、掉落、被夺或重新拾取；
- Beat 结束时兵器位置。

### Blade / Edge / Thrust

质量重点不是“打得越重越好”，而是：

- 危险线路清楚；
- Range 可信；
- 躲避 / 偏转 / 格挡改变线路；
- 接触结果改变下一拍选择；
- 刀剑不会像钝器一样统一产生大幅飞退。

### Weapon Clash / Parry

重点：

- 接触点与角度；
- 偏转 / bind / 滑开；
- 手腕 / 手臂 / 身体随兵器反馈；
- 兵器线路变化；
- 主动权 / Range 改变。

### 枪 / 棍等长兵器

重点：

- 长度与惯性；
- 挥扫 / 刺击线路；
- 回收与改线需要时间 / 空间；
- 被贴身后需要改变握持、步法或主动脱离。

禁止兵器无原因变形、消失、长度跳变、凭空换手或从错误方向重新出现。

---

## 9. 身法与腾跃

身法必须改变至少一项：

- Position；
- Range；
- Angle；
- Advantage；
- Height Relation；
- Attack / Defense Line；
- Target Handoff。

Level 2 / 3 可以使用短跃、踏墙、越桌、滑步、借力飞身等，但要明确：

```text
起点
→ 发力 / 借力点
→ 空间路径
→ 目标 / 作用
→ 落地 / 接触状态
```

禁止无起跳悬空、无落点漂浮或下一拍突然恢复地面初始姿态。

---

## 10. 主 Martial / Weapon Profile + 辅助 Profile

支持主 Profile + 辅助 Profile，但 Profile 是专业动作知识，不是 Character Identity 本身。

例如：

- 近距短打主导，反转节点短暂加入借力 / 擒拿；
- 爆发型武术主导，环境边界处出现身法换位；
- 剑法主导，失去兵器后切空手；
- 长枪主导，被贴身后短暂改变握持 / 用枪杆防守再重建距离。

Profile 用于决定距离、发力、线路与动作倾向，不要求模型复刻完整传统套路。

---

## 11. 1vN

武侠多人战允许更强的空间流动，但仍必须保持 Primary Target 与 Handoff。

Target Handoff 可以由：

- 兵器轨迹自然带向下一目标；
- 腾跃 / 落位后形成新主关系；
- 击退旧目标后顺势面对新威胁；
- 柱体、门窗、桌案、屋檐等形成空间遮挡；
- 对手主动切入迫使转向。

其他对手必须有明确状态，不能全部同时无序进攻。

模型多人稳定性不足时，优先降低同一窗口独立动作数量与 Camera Complexity，而不是把整场 Combat Coverage 压低。

---

## 12. Environment Affordance：武侠场景

常见环境：竹林、石阶、屋顶、廊柱、桌案、门窗、栏杆、树干、高低地形。

环境参与应改变：

- 站位；
- Range；
- 高低位；
- 兵器轨迹；
- 追击路线；
- Target Handoff；
- Phrase Payoff。

例如：

- 廊柱改变兵器线路并迫使绕位；
- 桌案改变站位 / 支撑 / 越障；
- 石阶改变高低位与步法；
- 门窗形成狭窄通路；
- 栏杆 / 屋檐成为边界或短暂借力点。

环境不是为了“武侠感”随机破坏。

---

## 13. Signature Moment：武侠动作

适合的 Signature Moment 可以来自：

- 高速拆招后一次清楚的借力反转；
- 兵器距离优势被突然消除或重建；
- 环境边界 / 高低位改变主导权；
- 身法换轴后形成干净反击；
- 假破绽引出兵器线路 Trap；
- 双方连续 Counter / Re-counter 后形成清楚视觉 Payoff。

Signature Moment 不等于慢动作、转圈或无来源腾空。

必须由前后 Action Phrase 因果支撑。

---

## 14. Camera 专项倾向

武侠 Camera 优先展示：

- 双方招式关系与兵器轨迹；
- 身法的完整空间路径；
- 高低位变化；
- 关键拆招 / 借力节点；
- Signature Moment 的身体轴线与环境关系；
- 高潮后的自然收束。

高动作复杂度时优先 medium / medium-wide 保持双方关系；不要为了华丽让 Camera 与人物同时高速旋转。

镜头复杂度不应迫使动作导演层把有效攻防大幅削减。

---

## 15. Audio 专项倾向

可使用：

- 脚步 / 落点；
- 衣袂与发丝破风；
- 兵器挥动；
- 刀剑碰撞 / 滑开；
- 枪棍撞击；
- 木板 / 瓦片 / 石阶反馈；
- 呼吸；
- 风声 / 竹叶 / 空间回声。

不同兵器材质和 Contact Modality 应有不同声音证据，禁止所有武器都使用统一夸张金属声。

Audio Accent Density 不等于 Action Density；关键 Contact、Phrase Payoff、Signature Moment 获得更明显声音层级。

---

## 16. 常见失败

- 短视频长时间对峙导致 Coverage 过低；
- 只写“剑法凌厉 / 身法飘逸”而缺少 Action Phrase；
- 每次格挡后双方位置重置；
- 长兵器与短兵器没有距离差；
- Blade Contact 被写成重拳式飞退；
- 兵器轨迹 / 持握 / 长度不连续；
- Level 2 无原因变成长距离飞行；
- 无起跳直接悬空或无落地；
- 频繁跨轴导致攻防方向翻转；
- 华丽 Camera 抢走兵器 / 身法可读性；
- 非高武场景出现仙侠能量效果；
- 每个 Phrase 都强制放一个腾跃 / 慢动作“高潮”。
