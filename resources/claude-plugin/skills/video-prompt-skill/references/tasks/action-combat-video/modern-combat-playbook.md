# Modern Combat Playbook

## 1. 适用范围与职责

用于现代写实 / 电影化近身格斗，包括拳击、泰拳、散打、MMA、摔跤 / 缠斗、战术近身动作语言及其合理混合。

本页只负责把：

- `core-playbook.md` 的 State / Continuity；
- `choreography-playbook.md` 的 Coverage / Rhythm / Phrase / Identity / Contact / Signature / Execution Budget；

实例化成**现代格斗**的动作语言与物理尺度。

本页不重新定义 Battle Beat、Coverage、Action Phrase、Exchange Depth、State Contract，也不把职业直接映射固定 Fighting Profile。

---

## 2. 电影化尺度

可按用户意图选择：

- Level 1｜写实近身格斗：动作短、重心真实、防守和恢复明确；
- Level 2｜电影化现代动作（常用）：保留真实物理，同时增强连续攻防、节奏层次和视觉 Payoff；
- Level 3｜强化动作片：更密集、更强环境利用和更明显 Signature Moment，但禁止超级英雄式无重量飞打。

Level 只是表现尺度，不决定固定动作数量。

---

## 3. Coverage / Rhythm 的现代实现

现代格斗可实现为：

- 重击型：少量更重的接触与明显恢复代价；
- 均衡型：攻防交换、换距、短组合与控制交替；
- 高手高速交换型：短促 Attack / Defense / Counter / Re-counter 连续发生；
- 混合型：高速交换与重型 Payoff / Control / Environment Reversal 交替。

高手 1v1、短时长、用户明确要求持续打斗时，通常应让 Active Combat 占主体，而不是用长时间观察、抓腕僵持或 Pose 填时长。

“快速观察 → 接触 → 压迫 → 反转 → 控制 → 终结”只能作为可能的宏观节奏参考，不能当固定阶段模板；同一个 Battle Beat 可以包含多个连续 Action Phrase。

---

## 4. Modern Combat Character Identity

现代角色打法应从当前人物设定和战斗关系动态推导，例如：

- 主动压迫还是后发反制；
- 直线切入还是侧向移动；
- 更偏 Boxing 距离、踢击距离、clinch、wrestling 还是混合；
- 更依赖速度、力量、距离、节奏打断还是控制；
- 防守后倾向立即 Counter、拉开重置还是进入抓控。

### 禁止职业模板化

以下映射**不成立**：

```text
assassin → Tactical Close Combat
soldier → Tactical Close Combat
police → joint control
fighter → one fixed martial profile
```

职业只能提供背景线索，不能替代 Character Identity 推导。

例如两名“职业杀手”可以一个偏主动切线压迫、短打连续反制，另一个偏防守读取、侧移、Counter-to-Counter；不应因为职业相同就都写成快速抓腕 / 关节控制。

---

## 5. Modern Range

可按需要理解为：

- 远距离 / 踢击距离；
- 拳击距离；
- 肘膝近距离；
- clinch；
- grappling / takedown transition；
- ground control；
- disengage / reset。

Range 变化必须通过可见动作实现。

典型转换：

- jab / front kick 建立或测试距离；
- slip / parry 后压入短打；
- body contact 后进入 clinch；
- underhook / body lock / level change 进入 takedown；
- frame / hip turn / wall use 脱离控制；
- 被推开 / 击退后重新建立 punching / kicking range。

禁止从远距离无过渡瞬间进入抱摔或地面控制。

## 6. Action Phrase 的现代实现

现代 Action Phrase 应强调**连续窗口**，而不是招式清单。

示例逻辑类型：

### 压迫型 Phrase

```text
逼近切线
→ 对手用短防守阻断
→ 进攻方顺势改目标 / 改角度
→ 对手 Counter
→ 进攻方压住 Counter 窗口
→ Payoff / 换距 / 控制
```

### Counter-to-Counter Phrase

```text
试探攻击
→ 防守者读到线路并反击
→ 原进攻方预判反击继续截击
→ 防守者被迫改变角度 / 重心
→ 形成新的攻击窗口
```

### Strike-to-Grapple Phrase

```text
短打迫使高位防守
→ 身体接触建立
→ clinch / underhook / body lock
→ 破坏重心
→ takedown / wall pressure / disengage
```

这些只是因果结构示例，不是固定招式模板。

## 7. Tactical Interaction

现代高手对决可按需使用：

- Feint：假动作诱导防守；
- Probe & Read：用低风险攻击读取反应；
- Bait：主动暴露可控窗口；
- Anticipation：提前拦截对方常见响应；
- Counter-to-Counter：反击继续被反制；
- Pattern Break：前几次形成节奏后主动变换；
- Forced Response：通过角度 / Range / Guard Pressure 逼出特定反应。

最终 Prompt 写可见动作和时机，不解释抽象“心理博弈”。

经验不足、纯力量压制、重型硬派场景可以降低 Tactical Interaction。

---

## 8. Combat Contact Solidity：现代格斗

现代格斗尤其强调接触后的**身体链条与持续后果**。

### Strike

重点：

- 发力来自脚下、髋部、躯干或短距离身体驱动；
- 防守 / 命中点清楚；
- 接触后 Guard、头部 / 躯干、重心、呼吸或脚步产生反馈；
- Solid / Heavy Contact 不应下一帧完全重置。

不要每一下都写 Heavy。轻试探、短阻挡、快速 parry 可以是 Light；关键 Counter / Payoff 再获得更明显 Solidity。

### Grapple / Control

重点：

- 身体持续连接；
- 压力方向与控制点清楚；
- leverage / underhook / frame / body lock 改变可用动作；
- 被控制者必须付出转髋、立架、找支点、破握或换位等挣脱代价。

避免“抓住手腕然后双方站着不动”。

### Takedown / Throw

重点：

- 先破坏平衡；
- 有进入角度和身体轨迹；
- 落地改变 Position / Range / Advantage；
- 落地不是单纯飞出去再立即站稳。

### Environment Impact

撞墙、桌沿、地面等必须体现具体材质和位置后果，不把环境碰撞写成统一爆炸式冲击。

## 9. 主 Profile + 辅助 Profile

允许 Fighting Profile 混合，但 Profile 是**专业知识来源**，不是 Character Identity 本身。

例如：

- Boxing 主导，出现明确身体连接窗口后短暂切 Wrestling；
- Muay Thai 主导，贴身后进入 clinch；
- Sanda 主导，在抓到 timing 后完成摔法；
- Tactical Close Combat 只在当前 Intent、距离、角色打法确实需要快速打断 / 控制 / 脱离时使用。

不要因为用户写“杀手 / 特工 / 军人”就默认选择 Tactical Close Combat。

Profile 切换必须有 Range / Position / Tactical 触发，不在每一个动作里频繁换体系。

---

## 10. 1vN

现代多人战强调：

- 主角持续移动，尽量制造单线 / 有主次的接触；
- 当前 Primary Target 清楚；
- 其他对手有明确状态；
- Target Handoff 由击退、转身、新威胁入画、空间换位、环境阻隔或连续动作动线触发；
- Camera 优先让当前目标和下一个威胁可读。

High Coverage 不等于所有人同时无序出拳。

当多人稳定性是模型风险时，优先简化同一窗口的独立角色动作和 Camera Complexity，不把核心打斗时长压成很少。

---

## 11. Environment Affordance：现代场景

常见环境：墙、门框、桌椅、柱体、楼梯、栏杆、走廊、车辆、狭窄出入口。

环境只有在改变战斗关系时才值得进入 Action Phrase，例如：

- 墙限制后撤并改变 clinch / pressure；
- 桌子改变进攻线路 / 绕位路线；
- 椅子短暂扰乱脚步 / 追击；
- 柱体切断多人同时接触；
- 楼梯改变高低位和移动速度；
- 门框限制横向动作。

禁止为了“丰富”随机砸烂环境。

---

## 12. Signature Moment：现代动作

适合的 Signature Moment 可以来自：

- 高速 Counter / Re-counter 后形成干净 Payoff；
- 环境边界辅助反制；
- 体型 / 力量差异形成明显视觉反转；
- 假破绽引出 Counter Trap；
- 一次 momentum redirection 改变双方位置与主导权；
- Strike-to-Grapple 或 Grapple-to-Strike 的关键转换。

Signature Moment 必须被前后 Phrase 因果支撑，不通过无来源慢动作 / 大幅 Camera Shake 伪造高潮。

---

## 13. Camera 专项倾向

现代格斗优先：

- 重心、接触点和双方身体关系可见；
- 高 Exchange Depth 时使用稳定 medium / medium-wide 跟随；
- 关键重击 / Signature Moment 可以短暂更近；
- 不长期只拍碎片特写；
- 快切时继承攻击方向、受击方向或空间锚点；
- 动作复杂时先降低 Camera Complexity，而不是先减少有效攻防。

---

## 14. Audio 专项倾向

可使用：

- 鞋底摩擦 / 急停；
- 短促呼气与呼吸压力；
- 衣料拉扯；
- 拳脚破风；
- 身体接触；
- 抓控摩擦；
- 墙面 / 桌面 / 地面反馈；
- 空间回声。

Audio Accent Density 不等于 Action Density。关键 Contact / Phrase Payoff / Signature Moment 获得更明显声音落点，普通微动作保持基础声音层即可。

---

## 15. 常见失败

- 长时间观察 / 对峙占掉主要 Combat Coverage；
- 高手对决只有 2–3 次有效交换；
- 职业身份导致双方都变成同一种 Tactical Close Combat；
- 每拳都完整命中，没有真实防守与 Counter；
- 命中后没有重心 / Guard / 呼吸 / Position 后果；
- 长时间抓腕或僵持，没有压力变化和挣脱代价；
- 从远距直接进入抱摔；
- 站立 / clinch / ground 无过渡；
- 1vN 中所有对手同时成为主目标；
- Camera Shake / 大音效掩盖接触不成立；
- Level 3 变成超人式飞打和无重量落地。
