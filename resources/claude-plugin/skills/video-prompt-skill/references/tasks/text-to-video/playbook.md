# Text To Video Playbook

## 1. 适用范围

没有视觉参考，需要从文字建立完整画面、运动、镜头、表演和声音时读取本页。

输入 Reference：通常为 `inputs/text-input.md`。

---

## 2. 核心目标

文生视频不是扩写故事梗概，而是建立一段可以被拍摄的连续影像：

```text
视觉起点
→ 主体运动或表演
→ 镜头观察与推进
→ 环境和声音响应
→ 自然落点
```

---

## 3. 必须锁定的变量

```text
视频时长：
单镜头 / 多镜头：
主体：
场景和时间：
初始画面：
唯一主动作或叙事任务：
镜头主任务：
结尾状态：
声音需求：
主风格：
模型：
```

缺少非关键细节时自动补全，不因服装小配件、具体焦段等轻微空缺中断执行。

---

## 4. 执行流程

### 4.1 建立初始画面

明确：

- 主体在哪里；
- 身体或物体处于什么状态；
- 场景主要空间关系；
- 镜头从哪里观察；
- 光源和声音从哪里来。

### 4.2 选择唯一主任务

单片段通常只承载：

- 一个主要动作；
- 一个情绪变化；
- 一次信息揭示；
- 一个产品卖点；
- 一条连续镜头路线。

复杂内容进入多镜头任务，不在一个镜头里塞完整剧情。

### 4.3 组织主体运动

按自然顺序写：

```text
起始状态
→ 起始微动作
→ 核心动作 / 表演
→ 反馈或变化
→ 恢复 / 停住
```

### 4.4 组织镜头运动

先说明镜头为什么要动，再选择主运镜。镜头运动应服务主体动作，不能一直与主体同时满强度。

### 4.5 组织声音

按需补充：

- 对白；
- 环境音；
- 拟音；
- BGM；
- 声音的进入和退出。

### 4.6 形成结尾

结尾必须给出：

- 主体最终姿态；
- 镜头最终位置；
- 情绪或信息结果；
- 声音落点。

---

## 5. 时间轴策略

### 简单单镜头

优先使用自然动作顺序，不必机械切成每秒一段。

### 多步动作或 8–15 秒内容

使用绝对时间：

```text
0–3 秒：建立与起始动作
3–7 秒：推进与变化
7–结束：高潮、反馈和收束
```

每段必须同时说明主体状态、镜头状态和节拍变化。

---

## 6. 推荐控制页

按需读取：

- `controls/timeline-rhythm/`
- `controls/subject-motion/`
- `controls/camera-direction/`
- `controls/performance-expression/`
- `controls/audio-visual-sync/`
- `controls/realism-quality/`

最多读取当前真正需要的 `0-3` 份。

---

## 7. 输出结构

```text
视频概述：
全局固定项：
镜头 / 时间轴：
表演与声音：
连续性与失败限制：
模型适配后的最终 Prompt：
```

用户直接要 Prompt 时，只展示最终可复制结果和必要的全局约束。

---

## 8. 常见失败

- 只有故事，没有首帧和镜头；
- 只有风格，没有主体运动；
- 动作和镜头同时过多；
- 时间轴只有事件，没有人物和镜头状态；
- 光影、声音和环境变化没有来源；
- 没有结束状态；
- 为了填满时长擅自新增剧情。

---

## 9. 模型适配

- 未指定模型：读取 `models/generic.md`。
- Seedance 2.0：读取 `models/seedance-2.md`，按需要转为分时段结构。
- LTX-2.3：读取 `models/ltx-2-3.md`，转为详细、连续的自然语言导演段落。
