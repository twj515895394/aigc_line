# Video Editing Playbook

## 1. 适用范围

用户希望保留原视频的大部分内容，只修改指定角色、物体、服装、背景、动作、文字、声音、特效或局部剧情时读取本页。

输入 Reference：

- 仅视频：`inputs/video-input.md`
- 视频加图片或音频：`inputs/mixed-multimodal-input.md`

如果用户要整体重做视频动态结构，进入 `video-reference-and-video-to-video`。

---

## 2. 核心约束结构

```text
必须保留
+ 必须修改
+ 必须删除
+ 必须增加
+ 允许变化
+ 禁止变化
+ 时间与空间范围
```

局部编辑的默认规则是：未被指定的内容保持不变。

## 4. 执行流程

### 4.1 定位编辑范围

明确：

- 哪个时间段；
- 画面中的哪个人物、物体或区域；
- 修改持续多久；
- 修改前后的状态。

### 4.2 锁定原视频骨架

默认保留：

- 时长；
- 镜头数量和顺序；
- 主体动作；
- 镜头运动；
- 场景布局；
- 光影和风格；
- 未指定声音。

用户明确允许变化时才放开对应维度。

### 4.3 描述目标变化

使用可验证的描述：

```text
把什么
→ 在哪里
→ 从什么状态
→ 改成什么状态
→ 从何时开始
→ 如何与原动作和光影融合
```

### 4.4 处理参考素材

如果图片提供新人物、服装或物体，只借用指定内容；不继承图片背景、构图和无关元素。

如果音频替换对白或声音，明确原声音删除范围和新声音同步节点。

### 4.5 检查连带影响

例如换服装时，需要同步处理：

- 布料运动；
- 遮挡；
- 光影和反射；
- 身体接触；
- 跨帧一致性。

不能只改某一帧的静态外观。

---

## 5. 编辑类型

### 角色替换

保持原动作、站位、镜头和节奏，替换身份与外观。

### 物体替换 / 增删

明确数量、位置、大小、朝向、接触关系和出现时间。

### 服装或发型修改

保持人物身份，控制跨帧形态和动态响应。

### 背景或场景修改

明确是否保留原人物光线、镜头路线和空间关系。整体换场景可能升级为视频转视频任务。

### 动作或剧情局部修改

只重写指定时间段，并说明修改如何接回原视频后续状态。

### 声音修改

指定删除、替换或新增的音轨，以及与口型和动作的同步关系。

## 8. 常见失败

- 没写“其他内容保持不变”；
- 编辑范围不清，导致整片重绘；
- 新参考图的背景或构图被错误继承；
- 替换人物后动作和接触关系失真；
- 删除物体后留下残影或遮挡错误；
- 新声音没有删除原声音；
- 局部剧情修改无法接回原视频后续状态。

---

## 9. 模型适配

- Generic：使用结构化保留 / 修改 / 禁止变化协议。
- Seedance 2.0：以 `@视频1` 为待编辑主体，图片或音频引用后紧跟职责。
- LTX-2.3：仅在具体接口支持对应编辑方式时使用；否则输出自然语言重生成方案，并明确其不是像素级传统编辑。
