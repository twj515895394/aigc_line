# false-opening-trap / 假破绽诱导反制

## Pattern Intent

通过主动暴露一个可控攻击窗口，引导对手做出可预测响应，再完成一次有因果支撑的战术反制。

## Trigger Conditions

- 角色具备较高战术能力；
- 对手会对明显窗口作出主动响应；
- 当前 Phrase 有足够 Exchange Depth；
- Camera 能看清“窗口出现 → 对手响应 → Trap 成立”。

## Character Relationship

适合：高手对决、读招能力强、双方都具备主动 Counter 能力。

## Core Mechanism

> **Controlled Opening → Expected Response → Prepared Intercept / Redirect → Payoff**

## Action Causality Skeleton

```text
A 故意留下一个看似可利用的线路 / Range 窗口
→ B 识别并快速进攻该窗口
→ A 在 B 承诺动作后立即改变角度 / 防守结构 / 兵器线路
→ B 的原攻击因 momentum 或路线承诺难以及时收回
→ A 完成预设 Counter / 换位 / 控制
→ Advantage 明显变化
```

## Environment Role

可选。环境可以帮助限制 B 的响应路线，但不应让 Trap 完全依赖突然出现的道具。

## Payoff Type

Tactical Reversal / Skill Display。

## Rhythm / Exchange Fit

Expert Continuous Exchange、Mixed、Wuxia Flow。

## Camera Readability Hint

Opening 必须真实可见但不要通过文字解释；镜头要让观众在 Counter 发生后回看得懂“原来这是一个可控窗口”。

## Adaptation Variables

- 空手 / 兵器；
- Opening 类型：Guard、Range、Line、Position；
- Counter 类型：Intercept、Redirect、Grapple、Weapon Bind；
- Payoff：Contact、Range、Advantage、Position。

## Do Not Copy

- 不把角色写成故意“站着挨打”；
- 不让 Trap 在对手尚未真正承诺动作前就无因果生效；
- 不在经验不足角色身上默认使用复杂诱导；
- 不把每个 Phrase 都写成假动作套路。
