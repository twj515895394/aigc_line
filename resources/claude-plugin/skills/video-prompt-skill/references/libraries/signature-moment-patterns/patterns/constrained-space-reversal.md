# constrained-space-reversal / 狭窄空间反制

## Pattern Intent

让原本限制行动的狭窄空间，从劣势来源转化为一次清楚的反制机会与主导权翻转。

## Trigger Conditions

- 至少一方正被墙、门框、走廊、桌边等空间边界压迫；
- 当前 Range 偏近；
- 空间限制已经真实影响移动或攻击线路；
- 角色具备利用角度 / 支点 / 线路反制的能力。

## Character Relationship

适合：势均力敌、被压迫者具备反制能力、力量差但技术 / 角度占优。

## Core Mechanism

> **Boundary Pressure → Forced Line → Angle / Support Use → Counter Window → Dominance Reversal**

## Action Causality Skeleton

```text
A 利用狭窄空间持续压迫 B
→ B 的后撤 / 横移被边界限制
→ A 因空间优势形成更可预测的攻击 / 控制线路
→ B 借边界、支点或有限角度改变身体轴线
→ A 的原有压力线被偏开 / 过冲
→ B 在 A 尚未恢复前完成 Counter / 换位
→ 双方位置与 Advantage 反转
```

## Environment Role

环境不是“撞一下墙”装饰，而是：

- 限制路线；
- 迫使攻击线变得可预测；
- 提供支点 / 转轴；
- 形成换位后的新边界关系。

## Payoff Type

Dominance Reversal + Spatial Payoff。

## Rhythm / Exchange Fit

- Mixed；
- Expert Continuous Exchange；
- Heavy Hard-Hitting。

## Camera Readability Hint

优先保留双方与边界同框，让观众先看懂“B 被压住”，再看懂换轴 / 换位如何发生。不要在反转前切成碎片特写。

## Adaptation Variables

- 边界类型：墙 / 门框 / 桌边 / 走廊 / 车辆；
- 反制方式：侧轴、借力、框架支撑、脚步换位、兵器偏转；
- Contact Modality：Strike / Grapple / Weapon / Environment；
- Payoff：反击、脱离、换位、摔投、夺回距离。

## Do Not Copy

- 不固定“背靠墙后转身”动作；
- 不要求角色一定撞墙；
- 不把环境边界变成随机可破坏特效；
- 不忽略换位后的 Position / Range / Advantage 状态更新。
