# environment-assisted-counter / 环境辅助反击

## Pattern Intent

让环境改变攻击线路、支点或追击路径，使一次 Counter 成为当前场景独有的动作记忆点。

## Trigger Conditions

- 场景已有可参与战术的物体 / 结构；
- 当前 Environment Affordance 能真实改变路线、Range、Advantage 或支撑；
- 角色具备顺势利用环境的空间意识；
- 环境参与不会让单个 Phrase 过载。

## Character Relationship

适合：灵活型 vs 压迫型、势均力敌、1vN 中需要切断多人同时接触。

## Core Mechanism

> **Incoming Pressure → Environment Alters Route / Support → Counter Angle Appears → Payoff**

## Action Causality Skeleton

```text
A 追击 / 压迫 B
→ B 被迫接近一个已有环境锚点
→ B 利用该锚点改变移动线 / 支撑 / 防守角度
→ A 为继续攻击必须调整路线
→ 调整瞬间暴露新的攻击窗口
→ B 完成 Counter / Target Handoff / 脱离
→ Environment State 与双方位置被更新
```

## Environment Role

可包括：

- 桌椅改变绕位；
- 柱体切断多人接触；
- 栏杆 / 台阶改变支点与高低位；
- 门框限制攻击幅度；
- 车辆改变追击线路。

## Payoff Type

Environment Payoff + Counter / Handoff / Escape。

## Rhythm / Exchange Fit

Mixed、Expert、Environment-Skilled。

## Camera Readability Hint

先建立人物与环境锚点的空间关系，再让 Counter 发生。环境不能在 Payoff 前突然“凭空出现”。

## Adaptation Variables

- Environment Anchor；
- 主动 / 被动利用；
- Strike / Grapple / Weapon；
- 1v1 / 1vN；
- Counter / Escape / Target Handoff。

## Do Not Copy

- 不固定踢椅子、翻桌等具体动作；
- 不为了使用 Pattern 强行新增场景中不存在的物体；
- 不让环境破坏只产生视觉噪音；
- 不忘记环境动作后的 State 更新。
