# momentum-redirection / 动量重定向

## Pattern Intent

不与来力机械硬碰，而是利用角度、支点、借力或身体轴线，把对方已有 momentum 转化为换位、失衡或反击机会。

## Trigger Conditions

- 一方已经明显承诺前冲、挥击、推压、抓控或兵器线路；
- 当前动作具有可利用的方向性 momentum；
- 另一方具备角度变化 / leverage / 借力能力；
- 当前空间允许形成新 Position / Range。

## Character Relationship

适合：力量差、速度差、技巧型 vs 压迫型、武侠借力、grappling / throw。

## Core Mechanism

> **Committed Momentum → Angle / Support Change → Force Redirection → Position / Balance Consequence**

## Action Causality Skeleton

```text
A 承诺一条明显推进 / 攻击线路
→ B 不正面对撞，而改变接触角度 / 支点 / 身体轴线
→ A 原本的 momentum 被带向新的方向
→ A 需要额外步法 / 支撑才能恢复，或直接进入失衡
→ B 利用恢复窗口换位 / Counter / Takedown
→ Position / Advantage 更新
```

## Environment Role

可选。墙、桌边、栏杆、高低差可成为支点 / 边界，但环境必须在动作发生前已经建立。

## Payoff Type

Spatial Payoff / Balance Break / Momentum Reversal。

## Rhythm / Exchange Fit

Mixed、Heavy Hard-Hitting、Wuxia Flow、Grappling。

## Camera Readability Hint

镜头要看得见 A 的原来方向和 B 改变方向的关键节点；只拍接触特写会丢失“动量被重定向”的意义。

## Adaptation Variables

- Strike / Charge / Grapple / Weapon；
- 角度变化大小；
- 是否借环境；
- 最终结果：换位、摔投、脱离、Counter；
- Modern / Wuxia 物理尺度。

## Do Not Copy

- 不等于每次都“借力打力”；
- 不让轻微接触产生不成比例的巨大飞出；
- 不跳过 A momentum 的建立过程；
- 不忘记重定向后的 Position / Range / Advantage。
