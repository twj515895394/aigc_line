# rapid-counter-recounter / 高速反制再反制

## Pattern Intent

用一段高 Exchange Depth 的连续攻防，让观众清楚看到“高手不是轮流出招，而是在阅读和反制对方的反制”。

## Trigger Conditions

- 双方能力接近或至少都具备快速反应能力；
- 当前 Rhythm 允许高速连续交换；
- Camera Readability 足以同时看清双方身体关系；
- 单个 Phrase 的模型执行复杂度仍可承载。

## Character Relationship

适合：skilled-vs-skilled、expert duel、势均力敌或短时间能力碰撞。

## Core Mechanism

> **Attack → Defensive Answer → Counter → Anticipated Re-counter → Continuation / Payoff**

## Action Causality Skeleton

```text
A 用一拍攻击建立威胁
→ B 以最小必要防守化解并立即 Counter
→ A 已预判 B 的常见反击线路，顺势截断 / 改角度
→ B 再次改变响应，不让 A 轻易完成命中
→ 双方在未完全重置前继续一到数拍交换
→ 某一方通过更好的时机 / 角度 / Range 得到 Phrase Payoff
```

## Environment Role

可选。若环境参与，只应帮助换轴、限制线路或形成 Payoff，不应在高 Exchange Depth Phrase 中同时加入多个独立环境事件。

## Payoff Type

Exchange Climax / Skill Display / Advantage Shift。

## Rhythm / Exchange Fit

Expert Continuous Exchange、Sharp Cinematic Action、Mixed。

## Camera Readability Hint

优先 medium / medium-wide 连续跟随；减少切镜和独立 Camera Move。真正的高潮来自动作因果，而不是快切。

## Adaptation Variables

- Strike / Empty-hand；
- Weapon Clash / Parry；
- Counter 方向；
- 是否包含 Feint / Anticipation；
- 最终 Payoff 是 Contact、Range、Position 还是 Advantage。

## Do Not Copy

- 不固定拳拳脚脚的具体组合；
- 不要求每个动作都命中；
- 不把“高速”写成动作动词堆叠；
- 如果模型执行预算不足，拆成多个无缝 Phrase，而不是保留一串不可读动作。
