# dominance-reversal / 主导权瞬间翻转

## Pattern Intent

用一个可读、可解释的 Turning Event，让原本压制的一方在很短时间内失去主导权，形成清楚的战斗高潮。

## Trigger Conditions

- 当前 Advantage 已经建立且观众能看懂；
- 被压制方仍具备合理反转资源：时机、角度、技术、环境、兵器或对手失误；
- 反转事件能真实改变 Advantage 来源；
- 前后 Position / Range / Condition 可以连续继承。

## Character Relationship

适合：pressure-vs-counter、underdog-vs-dominant、势均力敌但一方短暂压制。

## Core Mechanism

> **Established Dominance → Earned Turning Event → Advantage Source Collapses → Roles Reverse**

## Action Causality Skeleton

```text
A 已通过 Range / Position / Pressure / Weapon 建立清楚优势
→ B 在持续防守 / 读取中找到一个真实窗口
→ A 的一次承诺动作、失衡、线路被偏转或环境位置变化触发 Turning Event
→ B 立即利用，不给 A 完整 reset
→ A 被迫进入防守 / 失衡 / 退让
→ 新 Advantage 由 B 的位置、Range 或时机支撑
```

## Environment Role

可选。环境可以成为 Turning Event 的来源之一，但不能随机“救场”。

## Payoff Type

Dominance Reversal / Climax / Character Payoff。

## Rhythm / Exchange Fit

Mixed、Heavy、Expert、Wuxia。

## Camera Readability Hint

反转前必须先让观众看懂 A 为什么占优；反转瞬间优先保持动作与位置关系完整，不用过多 Cut 破坏因果。

## Adaptation Variables

- Advantage 来源：Range / Strength / Position / Weapon / Numbers；
- Turning Event：Counter、Slip、Disarm、Environment、Balance Break；
- Payoff：Contact、Takedown、Escape、Weapon Reversal、Position Swap。

## Do Not Copy

- 不做无来源“突然变强”；
- 不让双方每几秒机械轮流反转；
- 不用慢动作 / 音效替代真正 Turning Event；
- 反转后新 Advantage 必须有真实来源。
