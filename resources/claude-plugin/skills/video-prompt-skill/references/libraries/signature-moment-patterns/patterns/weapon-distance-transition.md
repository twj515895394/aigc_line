# weapon-distance-transition / 兵器距离切换

## Pattern Intent

把兵器长度与 Range 优势的变化设计成一次清楚、可记忆的 Signature Moment。

## Trigger Conditions

- 至少一方使用兵器；
- 双方兵器长度、动作线路或当前 Range 存在明显差异；
- 当前 Advantage 部分来自距离；
- 角色有合理方式偏转、贴身、回收或重新拉开。

## Character Relationship

适合：长兵器 vs 短兵器、Weapon vs Empty-hand、不同武器节奏对抗。

## Core Mechanism

> **Range Advantage → Line Disruption → Distance Collapse / Rebuild → Initiative Shift**

## Action Causality Skeleton

```text
A 用兵器长度 / 线路维持优势
→ B 通过偏转、绕位、环境遮挡或时机压缩安全线路
→ B 进入 A 原本不舒服的距离
→ A 必须回收、改握、横架、转身或后撤重建距离
→ 双方在新的 Range 下改变动作语言
→ Advantage / Initiative 明显变化
```

也可反向：短兵器角色贴身占优后，长兵器角色通过支点、横架或脱离重新建立长度优势。

## Environment Role

可选。柱体、门框、桌案、狭窄空间可以帮助压缩 / 重建线路，但不能替代兵器自身距离逻辑。

## Payoff Type

Range Reversal + Initiative Shift。

## Rhythm / Exchange Fit

Mixed、Wuxia Flow、Expert Weapon Duel。

## Camera Readability Hint

先让观众看见“为什么长 / 短距离有优势”，再展示距离如何被改变。避免只拍兵器特写而看不到双方全身距离关系。

## Adaptation Variables

- Long vs Short Weapon；
- Weapon vs Empty-hand；
- 偏转 / 绕位 / 贴身 / 回收 / 脱离；
- 现代 / 武侠物理尺度；
- Environment 是否参与。

## Do Not Copy

- 不固定“拨开枪头然后贴身”单一动作；
- 不忽略兵器回收所需空间 / 时间；
- 不让兵器长度无原因变化；
- 不让 Range 改变后动作语言仍完全一样。
