# Transition And Visual Effects Library

## 1. 作用

提供镜头切换、场景过渡、时间变化、空间穿越、材质变形和视觉特效的可选结构。这里回答“可以用什么转场或效果”；是否应使用、如何控制强度和连续性，分别读取时间轴、镜头、空间和连续性控制页。

## 2. 选择原则

```text
转场目的 → 共享视觉条件 → 触发动作 → 变化过程 → 新场景落点
```

转场必须服务叙事、节奏、空间或概念，不为炫技单独存在。

## 3. 基础剪辑转场

| 类型 | 实现条件 | 适用 |
|---|---|---|
| 直接切 | 前后镜信息清楚 | 对话、动作、常规叙事 |
| 动作匹配切 | 前后镜共享动作方向或姿态 | 打斗、运动、日常动作 |
| 形状匹配切 | 物体轮廓、构图或色块相似 | 广告、蒙太奇、时间跨越 |
| 视线匹配切 | 角色看向目标，下一镜显示目标 | 悬疑、关系、发现 |
| 声音先行切 | 下一场声音先进入 | 转场预告、空间连接 |
| 声音延续切 | 上一场声音延续到下一场 | 回忆、情绪和场景反差 |
| 反打切 | 保持视线轴的正反方向 | 对话、审问、对峙 |
| 跳切 | 故意省略连续时间 | 时间压缩、焦虑、喜剧 |
| 蒙太奇切 | 多个短镜围绕同一目标 | 训练、制作、旅行、成长 |

## 4. 镜头内转场

### 遮挡转场

主体、人物、墙面、车辆、衣物或其他前景完全遮住画面，遮挡移开时进入新空间。

关键条件：

- 遮挡方向一致；
- 遮挡覆盖足够完整；
- 新场景第一帧构图可承接；
- 不在遮挡前后无理由改变主体身份。

### 甩镜转场

镜头快速横甩或竖甩形成运动模糊，在方向和速度相近的新镜头中接续。

适用：动作、音乐卡点、地点快速切换。

风险：甩镜过多导致方向混乱和游戏感。

### 穿越转场

镜头穿过门、窗、隧道、屏幕、物体孔洞、人群或烟雾后进入新空间。

适用：场景探索、梦境、世界切换、产品内部展示。

### 拉焦转场

前景失焦或背景逐渐清晰，利用焦点变化把注意力引到新信息，必要时接入下一镜。

### 推近到黑/白

镜头推进到暗部、物体表面、眼睛、灯光或天空，画面被单一颜色占满，再从相似颜色中退出。

### 旋转或翻转转场

以相同旋转方向连接前后镜，适合舞蹈、运动、梦境和概念广告。必须控制旋转次数和落点。

## 5. 时间转场

| 类型 | 可见机制 | 使用场景 |
|---|---|---|
| 光影移动 | 阳光、阴影或灯光跨越空间 | 日夜、等待、时间流逝 |
| 延时摄影 | 云、车流、人群、建筑光线快速变化 | 城市、自然、制作过程 |
| 物体状态变化 | 食物、植物、文件、建筑逐步变化 | 生长、制作、年代 |
| 同位置人物变化 | 构图固定，人物服装/年龄/状态变化 | 成长、回忆、时间跨越 |
| 日历/时钟线索 | 只作为辅助证据 | 明确时间推进 |
| 天气过渡 | 晴、阴、雨、雪按过程变化 | 情绪和季节转换 |
| 速度渐变 | 动作逐渐加速或减速 | 回忆进入、高潮、收束 |

时间变化需要选择可见证据，不只写“多年后”。

## 6. 空间转场

- 门窗连接：前后空间通过同一入口或出口关系连接。
- 走廊纵深：镜头沿同一方向穿过多个空间。
- 地图到实景：从地图、屏幕或模型推进到真实地点。
- 宏观到微观：从世界/城市下降到人物或物体细节。
- 微观到宏观：从纹理、粒子或产品内部拉出完整场景。
- 反射切换：镜面、玻璃、水面反射逐渐成为新空间。
- 屏幕内外：进入手机、电视、监控或虚拟界面。
- 前景物体接力：相似物体在不同地点承接画面位置。

## 7. 材质和形态变化

### 溶解/融化

物体边缘逐步失去结构，转成液体、光、烟雾或颗粒。需要写清变化起点、传播方向和最终材质。

### 生长/生成

结构从骨架、线条、颗粒、植物或机械部件逐步出现。需要明确生成顺序，而不是整物瞬间弹出。

### 破碎/重组

主体分裂为碎片，碎片沿可见轨迹移动并重组成新形态。必须保持质量、方向和视觉中心。

### 粒子化

主体从局部开始变成灰尘、光点、像素或花瓣，粒子受风、重力或吸引力影响。

### 液态变形

表面产生波纹和流动，形态沿连续体变化，适合产品、字体、梦境和超现实。

### 机械展开

部件按结构旋转、滑动、折叠和锁定，适合产品、车辆、机器人和建筑。

### 生物变形

身体结构变化必须分阶段，并保持前后形态的连接逻辑。避免无中间状态的随机肢体增生。

## 8. 视觉特效类型

| 类型 | 关键变量 |
|---|---|
| 光效 | 来源、方向、强度、颜色、遮挡和衰减 |
| 能量效果 | 发射点、路径、速度、接触和环境反馈 |
| 烟雾/火焰 | 来源、气流、温度感、扩散和消散 |
| 水体 | 流向、波纹、折射、飞溅和重力 |
| 天气 | 粒子方向、密度、风、地面与衣物反馈 |
| 速度线/运动模糊 | 主体速度和方向，不能掩盖动作结构 |
| 时间冻结 | 冻结对象、仍运动对象、镜头行为和恢复触发 |
| 空间扭曲 | 作用区域、变形规则、人物与背景关系 |
| 全息/界面 | 空间位置、交互方式、光照和信息层级 |
| 魔法/超自然 | 触发、规则、代价、视觉反馈和结束状态 |

## 9. 音乐卡点转场

- 在强拍切镜、甩镜、闪光、遮挡完成或动作命中。
- 弱拍用于小动作、焦点变化、光线变化和细节出现。
- 不必每拍都切镜；先选择结构拍点。
- 转场前后动作方向、色块或构图至少共享一项。
- 最后一个拍点需要落到完整画面或品牌/剧情结果。

## 10. 广告转场组合

### 产品材质揭示

```text
微距纹理 → 光线掠过 → 形状匹配切 → 完整产品
```

### 场景变装

```text
人物动作遮挡/旋转 → 服装在遮挡中切换 → 相同动作落地
```

### 多场景使用

```text
产品保持画面位置 → 背景通过甩镜、遮挡或色块变化连续切换
```

### 内部结构展示

```text
推进产品表面 → 穿越进入内部 → 机械/材料结构运动 → 拉出回到完整外观
```

## 11. 悬疑与梦境组合

- 反射空间逐渐取代真实空间。
- 声音先进入，镜头慢摇揭示异常。
- 同一走廊重复但细节变化。
- 角色转身后空间结构改变，但保留一个连续锚点。
- 画面短暂失焦或遮挡后进入记忆。
- 时间冻结中只有特定人物或物体运动。

## 12. 转场强度等级

- 低：直接切、声音桥、动作匹配、轻遮挡。
- 中：甩镜、穿门、反射、拉焦、速度渐变。
- 高：材质变形、空间扭曲、粒子重组、连续世界穿越。

同一短片应有主强度。高强度转场不宜每镜使用。

## 13. 常见失败

- 转场没有共享形状、方向、动作或声音条件。
- 前后场景空间关系完全不明。
- 变形没有起点、过程和终态。
- 特效抢走主体动作和叙事信息。
- 所有镜头都使用不同转场，缺少统一语言。
- 遮挡没有完全覆盖却突然换景。
- 甩镜方向不一致。
- 粒子和烟雾无物理来源或无法结束。
