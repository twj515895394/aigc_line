# Genre Pattern Library

## 1. 作用

提供题材级叙事节拍、镜头倾向、表演、声音和风格组合。这里回答“这一类片通常怎样组织”；具体风格怎样执行读取 `references/styles/`，任务流程读取 `references/tasks/`。

## 2. 使用结构

```text
题材目标 + 核心情绪/卖点 + 典型节拍 + 镜头倾向 + 表演/动作 + 光影声音 + 收尾方式
```

一次选择一个主题材模板。其他题材只能作为局部修饰。

## 3. 写实关系短剧

### 核心目标

让人物关系、信息和情绪变化可读，空间和表演可信。

### 常用节拍

```text
空间建立 → 人物关系建立 → 触发信息 → 微表情/动作反应 → 对话或选择 → 自然停顿
```

### 镜头

- 全景/中景交代位置；
- 中近景和过肩处理对白；
- 近景处理情绪变化；
- 结尾使用停顿、轻拉远或空镜。

### 风格组合

自然光或实景灯、35-85mm、固定或轻手持、真实环境声、克制 BGM。

## 4. AI 漫剧/动态漫画

### 核心目标

依赖稳定角色、分镜构图、有限动画、表情变化和动作反馈推进剧情。

### 常用节拍

```text
角色/场景建立 → 关系或冲突 → 表情特写 → 动作/信息爆点 → 反应帧 → 悬念或情绪落点
```

### 镜头

- 利用画格构图、推近、拉焦和有限横移；
- 关键动作拆分为准备、接触、反馈；
- 避免所有镜头都让全身大幅运动。

### 风格组合

角色线条与渲染一致、发丝和衣物小幅动态、清楚音效、章节式节拍。

## 5. 动作/体育

### 核心目标

让观众看清技巧、路线、对抗关系和命中反馈，而不只感到镜头很快。

### 常用节拍

```text
空间与对手建立 → 技巧准备 → 连续动作推进 → 失位/接触/爆点 → 结果反馈 → 落地恢复
```

### 镜头

- 中远景/全景保留脚步和路线；
- 跟拍或侧前方移动；
- 爆点可切近景，但必须回到结果；
- 主体动作复杂时镜头减弱。

### 声音

脚步、球、碰撞、呼吸、场地和观众反应与动作同步。

## 6. 悬疑/调查

### 核心目标

控制信息释放，让异常在空间、视线、声音和细节中逐步出现。

### 常用节拍

```text
正常状态 → 微小异常 → 人物察觉 → 搜索/靠近 → 线索揭示 → 新问题或危险落点
```

### 镜头

前景遮挡、慢摇预兆、拉焦转移、长焦观察、固定空间和少量手持。

### 光影声音

冷灰或冷蓝、局部实景光、低频脉冲、画外声和静默。

## 7. 情绪/关系短片

### 核心目标

以一个清楚情绪变化为主，不追求复杂剧情。

### 常用节拍

```text
稳定情绪 → 触发记忆/人物/声音 → 内在反应 → 小动作或选择 → 余韵
```

### 镜头

长焦旁观、玻璃反射、极慢推近、固定近景、缓慢后撤和空镜。

### 声音

环境声、低能量对白、内心旁白或简洁音乐动机。

## 8. 商业广告

### 核心目标

产品/品牌识别、卖点证据、使用价值和最终记忆点清楚。

### 常用节拍

```text
需求/视觉钩子 → 产品出现 → 材质/功能证据 → 使用体验 → 结果 → 品牌落点
```

### 镜头

微距、滑轨、环绕、拉焦、形状匹配切、动作匹配和干净主视觉。

### 声音

节拍型 BGM、材质拟音、转场音效和品牌声音标识。

## 9. 纪录片/UGC/Vlog

### 核心目标

让画面像真实设备在真实空间中记录到的过程。

### 常用节拍

```text
自然进入 → 行动/观察 → 真实反应 → 信息或体验 → 自然离开/停住
```

### 镜头

手机、微单、固定机位、轻手持、跟随和有限变焦；曝光和构图允许轻微不完美。

### 声音

真实环境声优先，自然对白，BGM 少量或不用。

## 10. 科普/教育

### 核心目标

概念、步骤和因果关系可视化。

### 常用节拍

```text
提出问题 → 展示对象 → 分步骤解释 → 关键机制特写/透视 → 结果与总结
```

### 镜头与视觉

固定说明镜头、微距、剖面、X 光/透明结构、图形化空间和清楚旁白。

### 风险

不要用过度电影化镜头遮挡信息；特效必须服务解释。

## 11. 美食/制作过程

### 核心目标

步骤、材质变化、手部操作和最终结果有触觉和节奏。

### 常用节拍

```text
原料/工具 → 关键处理 → 质地变化 → 火候/组装 → 成品揭示 → 品尝/品牌落点
```

### 镜头声音

微距、俯拍、侧面特写、稳定移动；切、煎、沸腾、酥脆和倒液体拟音。

## 12. 旅行/城市/自然

### 核心目标

建立空间、路线、人物体验和地点记忆点。

### 常用节拍

```text
大景建立 → 进入空间 → 人物/交通移动 → 地点细节 → 情绪高光 → 远景或夕阳收尾
```

### 镜头

航拍、稳定器跟拍、广角空间、长焦细节和自然环境声。

## 13. 奇幻/科幻世界观

### 核心目标

先让世界规则和空间可信，再展示奇观、角色和特效。

### 常用节拍

```text
尺度建立 → 文明/环境证据 → 角色进入 → 规则或异常展示 → 奇观/冲突 → 目标方向
```

### 镜头与声音

大景、低角、穿越和长镜头；工业、自然、能量或机械声音与世界材质一致。

## 14. 恐怖/惊悚

### 核心目标

通过等待、空间不确定性、声音和局部信息建立压力。

### 常用节拍

```text
正常空间 → 异常声音/影子 → 搜索 → 暂时平静 → 突发或揭示 → 逃离/未知收尾
```

### 镜头

固定机位、前景遮挡、主观视角、慢摇、长停顿和有限手持。

### 风险

不要从第一秒就连续强刺激；需要安静段形成对比。

## 15. 喜剧/反差短片

### 核心目标

建立预期，再用行为、信息或反应打破预期。

### 常用节拍

```text
正常建立 → 预备动作/台词 → 停顿 → 反差事件 → 角色反应 → 二次落点
```

### 镜头

稳定构图通常优于过度运镜；保留完整动作和反应时间。

## 16. 实验/超现实

### 核心目标

用一条明确视觉规则推进概念，而不是随机堆叠奇观。

### 常用节拍

```text
现实基准 → 规则第一次出现 → 规则升级 → 主体被影响 → 视觉高潮 → 新稳定状态
```

### 规则示例

- 所有物体逐步液化；
- 空间在人物每次转身后改变；
- 时间只作用于背景；
- 材质按声音频率变化；
- 同一动作连接不同世界。

## 17. 题材选择表

| 用户重点 | 主模板 |
|---|---|
| 人物关系和对白 | 写实关系短剧 |
| 角色一致和分镜驱动 | AI 漫剧/动态漫画 |
| 技巧与冲击 | 动作/体育 |
| 信息控制和危险 | 悬疑/调查或恐怖 |
| 单一情绪变化 | 情绪短片 |
| 产品和卖点 | 商业广告 |
| 真实记录 | 纪录/UGC |
| 解释知识 | 科普/教育 |
| 世界规则和奇观 | 奇幻/科幻或实验视觉 |

## 18. 使用边界

- 题材模板不是最终 Prompt。
- 风格执行读取 `references/styles/`。
- 镜头、动作、表演、声音的具体选项读取相应 library。
- 任务是文生、图生、编辑或延长仍由 `references/tasks/` 决定。
- 不因题材不同复制任务 Playbook。
