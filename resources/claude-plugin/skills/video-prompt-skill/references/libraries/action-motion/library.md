# Action And Motion Library

## 1. 作用

提供人物、动物、物体和环境动作的可选结构。这里回答“动作可以怎样拆”；如何控制强度、物理、镜头协调和时序，读取 `references/controls/subject-motion/control.md`。

## 2. 通用动作四阶段

```text
蓄力/准备 → 执行/接触 → 反馈/结果 → 恢复/落点
```

不是所有动作都需要强烈接触，但必须有起始状态、状态变化和结束状态。

| 阶段 | 需要描述 | 关键视觉证据 |
|---|---|---|
| 准备 | 重心、视线、身体预备、目标 | 动作从哪里开始 |
| 执行 | 路线、速度、关节和道具关系 | 主变化怎样发生 |
| 反馈 | 受力、表情、衣物、环境或物体反应 | 动作是否真正产生结果 |
| 恢复 | 重心回收、呼吸、停顿、下一姿态 | 视频能否自然停住或承接 |

## 3. 人体运动基础变量

- 目标：人物为什么动。
- 起始姿态：站、坐、蹲、趴、奔跑中或动作中段。
- 支撑点：哪只脚、哪只手或哪个物体承重。
- 重心：向前、向后、向左、向右、上升或下降。
- 动作链：髋部、躯干、肩、肘、腕、头部的先后关系。
- 路线：直线、弧线、旋转、上下、往返。
- 速度：缓慢、均匀、加速、急停、爆发后减速。
- 幅度：细微、小幅、中等、大幅。
- 接触：身体与人物、道具、地面或环境的接触点。
- 反馈：受力方向、衣物、发丝、尘土、水、道具和声音反应。
- 结束姿态：最终站位、视线、手部、呼吸和重心。

## 4. 日常人物动作库

### 头部与视线

- 眼神先移、头部随后轻转。
- 听见声音后停顿，再缓慢回头。
- 短暂低头，视线落在手中物品。
- 抬眼确认对方，保持半拍凝视。
- 视线回避，嘴角或下颌轻微收紧。

### 手部动作

- 手指轻敲桌面后停住。
- 抬手整理头发，手自然落回身侧。
- 拿起杯子、停顿、轻抿、放回原位。
- 翻开文件、指尖压住纸角、视线跟随。
- 伸手递出物品，对方接住后松手。

### 身体动作

- 从椅子前倾、双脚发力、平稳起身。
- 迈出一步后调整站姿和重心。
- 靠墙站立，肩膀逐渐放松。
- 转身前先改变视线，再带动肩髋。
- 走到目标位置后减速、停住、回正身体。

## 5. 对话与关系动作

- 双人面对：保持清楚视线轴和距离。
- 并肩交流：一个人先转头，另一个延迟回应。
- 谈判：手部动作克制，身体微前倾或后靠显示态度。
- 争吵：动作升级应分阶段，不让双方同时无序挥动。
- 暧昧：距离、眼神、呼吸和小动作比大幅动作更重要。
- 告别：动作完成后保留回望、停顿或离场路线。

## 6. 跑步与追逐

### 跑步结构

```text
起跑准备 → 重心前移 → 蹬地加速 → 稳定步频 → 减速/转向/停下
```

关键字段：

- 步频和步幅；
- 手臂摆动与腿部节奏；
- 身体前倾角度；
- 落脚点与地面反馈；
- 转弯时内外侧脚和上身倾斜；
- 停下后的惯性、喘息和重心回收。

### 追逐结构

- 明确追逐者和被追逐者的位置。
- 保持同一行动方向，避免镜头轴线导致方向反转。
- 设置一个空间障碍或路线变化，不要连续堆很多障碍。
- 高潮可以是逼近、失去目标、翻越或急停。
- 结尾必须说明谁停在哪里、谁离开画面。

## 7. 打斗与打击帧

### 打击字段

```text
攻击目标：
攻击者起势：
动作路线：
接触点：
受力方向：
受击反馈：
环境反馈：
停顿感：
恢复姿态：
```

### 拳击/徒手

- 出拳由脚、髋、躯干、肩、手臂依次传力。
- 接触点必须可见，受击者身体沿受力方向反应。
- 命中瞬间可有极短停顿，不要持续冻结。
- 衣物、头发、汗水或灰尘可作为次级反馈。
- 攻击后手臂回收，身体恢复防守或进入下一动作。

### 踢击

- 支撑脚稳定，髋部转动明确。
- 抬膝、伸展、接触、回收四步清楚。
- 不要让支撑脚位置无理由瞬移。

### 武器动作

- 明确握持方式、攻击路线和武器重量。
- 武器先动还是身体先动必须符合类型。
- 接触或挥空后都需要惯性和回收。
- 禁止武器长度、手持位置和数量漂移。

## 8. 体育动作

### 篮球

- 运球：手掌控制、球落点、球的反弹节奏和身体低重心。
- 变向：先用假动作诱导，再完成脚步和球路切换。
- 突破：肩髋通过防守者侧面，防守者出现失位反馈。
- 投篮：屈膝、起跳、抬肘、拨腕、落地。
- 扣篮：助跑、起跳脚、持球路线、篮筐接触和落地保护。

### 足球

- 带球：触球脚和步幅协调，球不能黏在脚上。
- 变向：支撑脚、触球方向和上身假动作清楚。
- 射门：助跑、支撑脚、摆腿、触球、随摆和身体平衡。
- 扑救：守门员判断、蹬地、飞扑路线、手套接触或扑空反馈。

### 滑板/极限运动

- 明确板面、脚位和重心。
- 起跳、腾空、板体旋转和落地顺序清楚。
- 落地时膝盖吸收冲击，不要漂浮。
- 镜头应保留完整动作路线和落点。

### 舞蹈

- 用音乐拍点组织动作，不按动作名堆叠。
- 明确主导部位、重心转换、停顿和造型落点。
- 群舞需要队形、同步级别和主次人物。

## 9. 动物运动

- 先确认物种步态和关节结构。
- 四足行走需要前后肢交替，不使用人类步态。
- 奔跑包括身体伸展和收缩阶段。
- 尾巴、耳朵和毛发作为平衡和情绪反馈。
- 起跳和落地必须有支撑与重量感。
- 飞行动物需要振翅、滑翔、转向和气流反馈。

## 10. 物体运动

### 机械和车辆

- 启动、加速、匀速、制动和停止。
- 车轮、悬挂、车身惯性和路面反馈一致。
- 转弯时车身和镜头路线不可互相冲突。

### 抛掷和坠落

- 起始力、抛物线、旋转、重力加速和碰撞结果。
- 落地后应弹跳、滚动、破裂或停住，取决于材质。

### 液体、布料和颗粒

- 液体：流向、黏度、飞溅、表面张力和容器关系。
- 布料：固定点、重力、风向和身体牵引。
- 烟雾：来源、扩散、气流和消散。
- 尘土/碎屑：由接触或速度触发，方向与冲击一致。

## 11. 动作节奏类型

| 类型 | 结构 | 适用 |
|---|---|---|
| 缓慢递进 | 小动作逐渐增强后停顿 | 情绪、悬疑、产品揭示 |
| 突发反应 | 平静状态后单一爆点 | 惊吓、发现、喜剧 |
| 连续技巧 | 多个动作共用一条目标路线 | 体育、舞蹈、手工 |
| 蓄力爆发 | 准备较长，执行短而强，反馈明确 | 打斗、起跳、冲刺 |
| 往返循环 | 重复动作有节拍变化 | 机械、劳动、音乐卡点 |
| 慢—快—慢 | 建立、爆发、恢复 | 广告、动作高光、情绪转折 |

## 12. 动作拆分尺度

- 单镜头内只承载一个主动作目标。
- 一个复杂动作可拆为 2-4 个阶段，但阶段必须连续。
- 多镜头动作应在切镜点保留同一身体状态或动作方向。
- 需要展示技巧时，镜头应能看到脚步、重心、道具和对手反馈。
- 不用快速切镜掩盖动作逻辑缺失。

## 13. 常见失败

- 只有动作名，没有起始和结束状态。
- 人物动作和镜头都达到最大强度。
- 接触没有反馈，动作像穿过目标。
- 重心、脚位或手部突然跳变。
- 道具与手没有真实接触。
- 动作完成后仍持续无意义运动。
- 体育技巧被过近特写或过度运镜遮挡。
