# Combat Fighting Profiles Library

本库只回答“现代格斗有哪些可选专业动作语言，以及它们通常如何表现”。不决定 Battle Beat、Coverage、Action Phrase、Character Identity、镜头、状态机或输出流程。

> **Fighting Profile ≠ Combat Character Identity ≠ 职业。**

Character Identity 由当前人物设定、体型能力、Combat Intent、对手、空间与 Choreography Profile 动态推导；本库只在该 Identity 已经明确后提供专业动作知识。

选择一个主 Profile，必要时再加一个辅助 Profile。不要在同一短时间窗口同时混入多套互相冲突的动作语言。

---

## Boxing

- 典型距离：拳击中近距离；
- 重心：稳定、脚步持续调整角度；
- 发力：脚—髋—肩链路明显；
- 进攻倾向：刺拳建立 / 测试距离，直拳 / 摆拳 / 勾拳完成压迫和反击；
- 防守倾向：格挡、偏头、后撤、侧移、抱架；
- Counter 倾向：防守后立刻用角度或时机反击；
- Contact Solidity：命中 / 格挡后 Guard、头部 / 躯干、呼吸、重心或脚步发生反馈；
- 连续性重点：每次出拳后有回收、防守和脚步调整；
- 镜头重点：肩髋发力、拳路、双方距离和接触反馈。

## Muay Thai

- 典型距离：踢击距离到肘膝近距离；
- 重心：更适合踢击、膝击和 clinch；
- 发力：髋部旋转、支撑腿和身体整体参与；
- 进攻倾向：低扫、中高踢、膝、肘、直拳组合；
- 防守倾向：提膝 / 抬腿检查、抱架、后仰、clinch 控制；
- Counter 倾向：check / block 后反击、clinch 内抢位置；
- Contact Solidity：踢击落脚、支撑腿、身体转动与受击区域反馈必须连续；
- 连续性重点：踢击后必须有落脚和重心恢复；
- 镜头重点：髋部旋转、踢击轨迹、肘膝接触和落脚。

## Sanda

- 典型距离：中距离到短暂贴身；
- 重心：兼顾拳腿与快速摔法；
- 发力：步法、踢击和抓摔转换直接；
- 进攻倾向：拳腿组合、接腿、扫摔、快速摔出后脱离；
- 防守倾向：移动、格挡、抓接、反摔；
- Tactical 倾向：适合通过击打 / 接腿窗口快速转换；
- Contact Solidity：从 Strike 到 Throw 必须先有抓握、失衡与方向改变；
- 连续性重点：从击打到摔法必须有真实转换窗口；
- 镜头重点：换距、抓接时机、摔出方向和落地反馈。

## MMA

- 典型距离：远距打击 → 拳击距离 → clinch → 地面；
- 重心：随阶段明显改变；
- 发力：站立打击与摔跤 / 地面控制连续转换；
- 进攻倾向：打击制造进入、抱摔、压制、地面打击或控制；
- 防守倾向：架手、防摔、贴笼 / 借墙、起身；
- Contact Solidity：clinch / takedown / ground control 强调持续连接、压力方向和支撑点；
- 连续性重点：站立到地面的姿态、Range 与 Advantage 过渡必须清楚；
- 镜头重点：换层、抓握、身体位置、地面控制关系。

## Wrestling / Grappling

- 典型距离：贴身和地面；
- 重心：低、强调身体接触和支撑点；
- 发力：抱腿、抱腰、转髋、杠杆、压重心；
- 进攻倾向：进入、破坏平衡、摔倒、控制；
- 防守倾向：降重心、防摔、转身、建立支撑、挣脱；
- Tactical 倾向：通过 grip / frame / angle 逼迫对手改变可用动作；
- Contact Solidity：必须表现持续连接、leverage、balance capture、escape cost；
- 连续性重点：抓握位置、身体朝向和支撑点不能跳变；
- 镜头重点：双方身体关系与重心变化，而不是只拍手脚特写。

## Tactical Close Combat

- 典型距离：极近距离；
- 重心：稳定、直接、目标导向；
- 发力：短动作、快速打断、控制与环境借位；
- 进攻倾向：快速中断威胁、控制手臂、推离、压制、脱身；
- 防守倾向：保护头部和中心线、解除抓握、快速重建距离；
- Contact Solidity：抓控必须有压力方向、限制结果与挣脱代价；
- 连续性重点：动作服务制服 / 脱身 / 保护，不追求表演性长连招；
- 镜头重点：威胁来源、手臂控制、出口和空间关系。

### Tactical Close Combat 使用边界

不要因为角色是：

- assassin；
- soldier；
- police；
- agent；
- bodyguard；

就自动选择 Tactical Close Combat。

只有当当前 Combat Intent、Character Identity、Range 和环境真正需要“快速打断 / 控制 / 脱离”时才选择。

如果观看目标是高手持续对决、高 Exchange Depth 或更强电影动作观感，过度 Tactical Close Combat 可能导致：

- 抓腕 / 控制时间过长；
- 双方打法同质；
- 有效交换太少；
- 动作观感过平。

## 混合建议

可用“主 Profile + 辅助 Profile”：

- Boxing + Wrestling；
- Muay Thai + Clinch / Grappling；
- Sanda + Boxing；
- MMA 内部按 Range 自然切换；
- Tactical Close Combat + Wrestling 控制（只有 Intent 真正需要时）。

辅助语言只在明确的：

- Range Transition；
- 抓握成功；
- 失衡；
- Turning Event；
- Tactical Opportunity；

之后进入。

Profile 混合不能替代 Character Identity。两个角色即使加载同一 Profile，也应通过压迫 / 反制、步法、节奏、攻击偏好和防守选择表现不同。

## 与 Choreography 的关系

本库只提供 Technique / Execution Knowledge。

以下内容不在本库决定：

- Active Combat Coverage；
- Action Exchange Rhythm；
- Action Phrase 数量 / 结构；
- Exchange Depth；
- Signature Moment；
- Action Execution Budget；
- Camera Readability Budget。

这些由 `action-combat-video/choreography-playbook.md` 决定，再用本库填充专业动作语言。

## 使用边界

- Profile 是动作语言，不是必须复刻的真实比赛规则；
- 不凭流派名自动生成一长串招式；
- 不用职业直接选择 Profile；
- 用户明确动作设计优先于 Profile 默认倾向；
- 不把体育规则、评分体系和胜负判定写进视频 Prompt，除非用户需要赛事场景；
- 不把 Profile 当作固定 Action Phrase 模板；
- Contact 反馈必须与实际 Contact Modality 相匹配。
