# Audio And Sound Library

## 1. 作用

提供对白、旁白、环境音、拟音、动作音效、BGM、节拍和声音空间的可选结构。这里回答“可以使用哪些声音层”；音画事件如何绑定，读取 `references/controls/audio-visual-sync/control.md`。

## 2. 声音层级

```text
对白/旁白 + 主环境音 + 关键拟音 + BGM + 特效声音 + 静默与余韵
```

一条短视频不必使用全部层级。先确定叙事主声音，再补支持层。

## 3. 对白类型

| 类型 | 声音特征 | 适用 |
|---|---|---|
| 自然对白 | 日常音量、真实停顿、口型幅度适中 | 短剧、关系戏、采访 |
| 耳语 | 低音量、气息明显、近距离空间 | 暧昧、秘密、悬疑 |
| 低声独白 | 稳定、克制、句间留白 | 情绪、回忆、作者化短片 |
| 激烈争执 | 音量和语速分阶段升级 | 冲突、危机、家庭关系 |
| 命令/宣言 | 稳定、清楚、节奏控制强 | 权力、动作、广告 |
| 喜剧对白 | 节奏清楚，预备和反应停顿重要 | 反差、包袱、短剧 |
| 群体对白 | 主说话者清楚，其余作为背景反应 | 聚会、会议、街头 |
| 电话/设备声 | 频段受限、带设备空间 | 通话、广播、对讲机 |

## 4. 旁白结构

### 叙事旁白

- 补充画面无法直接表达的信息。
- 不逐字重复画面动作。
- 句子长度与镜头节拍匹配。

### 第一人称内心

- 与人物表面动作形成补充或反差。
- 声音可更近、更干，环境音适当降低。

### 品牌旁白

- 卖点、证据、结果和品牌落点顺序清楚。
- 避免在短时长内塞入过多信息。

### 科普说明

- 术语与画面步骤同步。
- 关键概念出现时安排局部特写、标示或结构变化。

## 5. 环境音库

### 室内

- 空调和通风低频；
- 键盘、纸张、杯子、椅子；
- 房间混响和远处人声；
- 电器、时钟、门锁、脚步；
- 餐具、厨房火焰、水流。

### 城市

- 远近车流；
- 路口提示音、刹车、喇叭；
- 商店和人群底噪；
- 地铁、站台广播和轨道声；
- 雨水落在地面、伞和车窗。

### 自然

- 风穿过树叶、草地或建筑；
- 水流、海浪、雨、雷；
- 鸟鸣、蝉鸣、昆虫；
- 火焰、木材燃烧；
- 雪地和沙地脚步。

### 特殊空间

- 教堂/大厅：长混响；
- 狭窄走廊：脚步反射明显；
- 车内：发动机低频和封闭空间；
- 水下：高频衰减和低沉冲击；
- 太空/真空：不直接传播环境声，声音应来自设备或主观设计。

## 6. 拟音与动作音效

| 动作 | 声音证据 |
|---|---|
| 走路/奔跑 | 地面材质、步频、重量和空间混响 |
| 服装动作 | 布料摩擦、拉链、皮革或护具 |
| 手部道具 | 拿起、放下、碰撞、开关、翻页 |
| 打击 | 起势风声、接触、身体/材质反馈、落地 |
| 体育 | 球反弹、鞋底摩擦、篮筐、球网、观众反应 |
| 车辆 | 启动、换挡、加速、轮胎、风噪、制动 |
| 机械 | 电机、齿轮、锁定、气压、金属碰撞 |
| 液体 | 倾倒、滴落、飞溅、沸腾、吞咽 |
| 火焰/能量 | 来源声、移动声、接触和消散 |

拟音时间应与接触或状态变化一致，不提前或延迟无理由发生。

## 7. BGM 功能分类

| 功能 | 音乐结构 | 场景 |
|---|---|---|
| 氛围托底 | 低强度持续纹理 | 日常、情绪、纪录 |
| 情绪递进 | 逐步增加乐器、音量或和声张力 | 告白、发现、成长 |
| 悬疑脉冲 | 低频、重复动机、留白 | 调查、等待、危机 |
| 动作驱动 | 清晰节拍和结构重拍 | 体育、追逐、广告 |
| 喜剧节奏 | 短促动机和停顿 | 反差、包袱 |
| 史诗抬升 | 低频、铜管/合唱或大动态 | 登场、战争、奇观 |
| 品牌记忆 | 简洁主题动机或声音标识 | 广告、片尾 |
| 梦境/实验 | 纹理、反向声、非传统节拍 | 超现实、意识流 |

## 8. 音乐节拍结构

- 引子：建立速度和情绪，不急于切镜。
- 第一拍点：主体或产品首次明确出现。
- 发展：动作、镜头或场景按乐句推进。
- 主重拍：命中、变装、转场、卖点或反转。
- 尾奏：动作完成，声音减弱或留下声音标识。

### 卡点方式

- 强拍：切镜、命中、甩镜完成、品牌出现。
- 弱拍：眨眼、手势、拉焦、光线变化。
- 连续节奏：步伐、舞蹈、运球、机械循环。
- 休止：定格、情绪反应、悬疑停顿。

不需要每一拍都绑定视觉事件。

## 9. 声音空间

- 距离：近声清楚、低环境比例；远声更弱并有空间反射。
- 方向：左、右、前、后或画外声应与人物反应一致。
- 室内外：混响、低频和高频衰减不同。
- 遮挡：门、墙、玻璃和水体会改变声音。
- 镜头位置：主观镜头可强化呼吸、心跳和身体声音。
- 画外声：可以先引发人物视线，再揭示声源。

## 10. 静默与留白

静默不是没有设计，而是：

- 在关键信息前降低 BGM；
- 台词后保留呼吸和环境声；
- 打击或反转后短暂抽走音乐；
- 结尾只留下一个环境音或声音标识；
- 用静默强化尴尬、悲伤、恐惧和真实感。

## 11. 常见声音组合

### 写实关系短剧

```text
自然对白 + 房间环境音 + 少量关键拟音 + 低强度 BGM + 对白后留白
```

### 动作体育

```text
节拍型 BGM + 脚步/球/碰撞拟音 + 环境观众声 + 高潮重拍 + 落地喘息
```

### 悬疑

```text
低频脉冲 + 稀疏环境音 + 画外异常声 + 静默 + 关键声源揭示
```

### 产品广告

```text
节拍型音乐 + 材质拟音 + 转场声音 + 卖点出现音效 + 品牌声音标识
```

### 纪录/UGC

```text
真实环境声优先 + 自然对白 + 少量或无 BGM + 不过度清理的空间声
```

## 12. 对白与口型注意

- 台词长度必须适配时长。
- 说话时嘴部动作适度，停顿时嘴巴停止。
- 呼吸、吞咽、笑和叹气可以成为表演节点。
- 多人对白明确说话顺序，不让多人同时持续开口。
- 口型困难时优先缩短台词、降低语速和镜头距离。
- 画外旁白不要求角色持续口型。

## 13. 常见失败

- BGM、对白和环境音都处于最高强度。
- 声音没有空间距离，所有声源都像贴近麦克风。
- 拟音与动作接触不同步。
- 音乐每一拍都切镜，画面无法阅读。
- 台词超出视频时长，口型机械或语速异常。
- 环境变化但环境声不变。
- 结尾声音被硬切，没有尾音或环境余韵。
