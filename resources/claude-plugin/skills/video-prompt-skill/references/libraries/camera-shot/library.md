# Camera And Shot Library

## 1. 作用

提供视频 Prompt 可选的景别、机位、焦段、观看位置、运镜和镜头组合。这里回答“有哪些镜头可以选”；如何判断、限制强度和处理轴线，读取 `references/controls/camera-direction/control.md`。

## 2. 基础镜头描述结构

```text
景别 + 机位/观看位置 + 焦段/空间感 + 主运镜 + 速度 + 聚焦对象 + 情绪或叙事作用
```

一段通常只选一个主运镜，最多增加一次焦点变化或速度变化。

## 3. 景别库

| 景别 | 画面范围 | 主要用途 |
|---|---|---|
| 超远景 | 人物极小，世界占主导 | 世界观、旅程、宏大开场、灾难规模 |
| 远景 | 人物与环境关系清楚 | 建立场景、孤独、行动路线 |
| 全景 | 人物全身和周边空间 | 动作、站位、群像、出场 |
| 中远景 | 膝部以上，空间仍可读 | 行走、双人关系、轻动作 |
| 中景 | 腰部以上 | 对话、互动、动作与表情兼顾 |
| 中近景 | 胸部以上 | 情绪推进、关系变化、短剧对白 |
| 近景 | 头肩或局部动作 | 眼神、表情、手部、关键道具 |
| 特写 | 面部或单一物件占主导 | 情绪爆点、线索、证据、品牌细节 |
| 大特写 | 眼、嘴、指尖、材质细节 | 紧张、微表情、触感和冲击瞬间 |
| 微距 | 极小纹理与局部变化 | 产品、液体、机械、食物、自然细节 |

## 4. 机位与观看位置

| 类型 | 视觉作用 | 常见场景 |
|---|---|---|
| 平视 | 平等、自然、纪实 | 日常、对白、采访 |
| 低角度仰拍 | 权力、体量、英雄或威胁 | 登场、宣言、建筑、动作 |
| 高角度俯拍 | 脆弱、孤立、空间关系 | 失败、围困、群像 |
| 鸟瞰/顶视 | 图形化空间、路线与队列 | 战场、城市、桌面、舞蹈编排 |
| 荷兰角 | 失衡、不安、危险 | 悬疑、心理崩溃、突发危机 |
| POV 主观视角 | 强代入、发现和行动 | 追逐、探索、惊吓、运动 |
| 过肩镜头 | 对话关系和视线 | 谈判、审问、暧昧、冲突 |
| 侧面观察 | 身体动作与距离 | 行走、竞技、双人互动 |
| 背后尾随 | 跟踪、未知、任务感 | 潜行、进入空间、旅程 |
| 前景遮挡 | 窥视、真实偷拍、空间层次 | 卧底、观察、街拍、悬疑 |
| 设备记录视角 | 明确画面来源 | 手机、Bodycam、CCTV、车载、GoPro |
| 反射视角 | 双层空间和心理距离 | 车窗、玻璃、镜子、都市夜景 |

## 5. 焦段与镜头类型

| 选择 | 空间效果 | 适用方向 |
|---|---|---|
| 14-20mm 超广角 | 强烈纵深、近大远小 | 极限运动、狭窄空间、主观冲击 |
| 24mm 广角 | 空间拉伸、动感强 | 环境、跟拍、动作、城市 |
| 35mm | 接近纪实观看感 | 街头、短剧、生活流、长镜头 |
| 50mm | 自然稳定 | 通用人像、对白、情绪 |
| 85mm | 背景压缩、主体分离 | 肖像、关系距离、情绪特写 |
| 135mm 及以上长焦 | 强压缩、远距离旁观 | 追踪、城市孤独、体育 |
| 鱼眼 | 边缘弯曲、夸张速度 | 滑板、街头、派对、实验影像 |
| 变形宽银幕 | 横向光晕和宽画幅 | 电影化夜景、科幻、广告 |
| 移轴 | 微缩和图形化城市 | 城市展示、创意转场 |
| 微距镜头 | 纹理与微小动作 | 产品、食物、机械、自然 |

景深选项：

- 浅景深：孤立主体、情绪和产品细节。
- 中等景深：人物与环境兼顾，适合常规短剧。
- 深景深：群像、空间调度、动作路线和世界观。
- 拉焦：前后景信息发生叙事转移。

## 6. 基础运镜库

| 运镜 | 核心作用 | 推荐用途 |
|---|---|---|
| 推镜 | 靠近、聚焦、压迫或情绪进入 | 发现、觉醒、秘密、产品卖点 |
| 拉镜 | 远离、揭示关系、疏离和收尾 | 反转、孤独、世界展开 |
| 横摇 | 浏览空间或跟随视线 | 场景介绍、多人关系 |
| 俯仰摇镜 | 建立高低和体量 | 建筑、人物登场、失落 |
| 横向移镜 | 平行跟随并展开空间 | 行走、队列、产品展示 |
| 跟镜 | 持续跟随主体 | 追逐、运动、任务执行 |
| 升镜 | 抬升视野和格局 | 开场、胜利、场面揭示 |
| 降镜 | 从全局回到人物或细节 | 登场、发现、落点 |
| 环绕 | 展示关系与气势 | 告白、英雄、产品、心理波动 |
| 滑轨 | 稳定精确的线性移动 | 广告、室内、空间展示 |
| 稳定器跟拍 | 流畅穿行和连续调度 | 长镜头、活动、行进 |
| 手持 | 临场、危险、纪实 | 冲突、采访、街头、逃亡 |
| 航拍 | 大空间、地理关系 | 城市、自然、旅行、开场 |
| FPV 穿行 | 高速空间穿越 | 场景奇观、动作、转场 |
| 甩镜 | 快速转移关注点 | 动作、卡点、突然反应 |
| 变焦 | 改变空间压缩和视觉注意 | 反应、线索、广告 |
| 推拉变焦 | 空间扭曲和心理冲击 | 恐惧、真相、危机 |
| 穿越运镜 | 穿门窗、人群、物体或空间层 | 转场、探索、梦境 |
| 前景遮挡运镜 | 以前景掠过形成层次和转场 | 窥视、空间切换 |
| 抽离镜头 | 缓慢远离留下余韵 | 告别、结局、空镜收尾 |
| 长镜头调度 | 不切镜完成复杂路线 | 群戏、空间叙事、沉浸过程 |

## 7. 叙事镜头组合

### 建立空间

```text
远景/全景 + 固定或缓慢移动 + 清楚入口和人物位置
```

### 推进关系

```text
中景/中近景 + 过肩或侧面 + 轻推/轻移 + 视线关系
```

### 情绪爆点

```text
近景/特写 + 极慢推近或定格 + 微表情 + 背景弱化
```

### 信息揭示

```text
前景主体 + 拉焦到背景线索，或从局部回撤揭示全局
```

### 空间反转

```text
退让式让位、反向包抄、回撤揭示或穿越障碍
```

### 结尾余韵

```text
人物动作完成后，镜头停住、轻拉远或留在空镜
```

## 8. 情绪镜头词组

- 推近压迫：快速或持续逼近，压缩心理空间。
- 后撤疏离：人物留在原地，镜头缓慢离开。
- 俯拍孤立：高机位强调人物与环境的不对等。
- 低角压强：低机位强化控制和权力。
- 侧移窥视：沿遮挡物横移，保留秘密感。
- 定格凝视：较长停留在眼神或表情。
- 长焦抽离：远距离观察，压扁空间和关系。
- 慢摇预兆：缓慢揭示异常信息。
- 空镜余韵：人物离开后继续停留环境。
- 剪影决绝：强逆光隐藏细节，强化选择和离别。

## 9. 动作镜头词组

- 贴地掠行：低机位高速贴地跟随。
- 侧向切入：从画面侧缘突然进入主体。
- 弧线跟进：沿弧形靠近，兼顾动作和空间。
- 反向包抄：从背后绕到正面，形成局势翻转。
- 交叉穿行：在人群或障碍间持续穿行。
- 斜向俯冲：斜线快速进入，形成攻击性。
- 顶视旋落：从顶视旋转下降到人物层。
- 急停凝视：运动中突然停止并锁定主体。
- 节奏点爆发：在音乐或动作节点瞬间加速。
- 回撤揭示：从局部快速退开显示完整局面。

## 10. 设备与媒介质感

- 手机原相机：轻微自动曝光、自然锐度、有限动态范围。
- 微单/电影机：更稳定的曝光、可控景深、明确镜头调度。
- GoPro：超广角、主观速度、边缘畸变。
- Bodycam：胸前第一人称、不稳定且受身体动作影响。
- CCTV：固定高位、冷静旁观、画质和帧率可受限。
- 车载/行车记录：固定前向视野、路面震动和玻璃反射。
- 红外夜视：单色夜间观察、噪点和有限层次。
- 热成像/X 光：信息可视化设备视角，只在题材需要时使用。

## 11. 快速选择表

| 目标 | 推荐组合 |
|---|---|
| 生活化对白 | 35-50mm，中景/中近景，固定或轻微手持 |
| 都市孤独 | 85-135mm，长焦旁观，玻璃反射，缓慢抽离 |
| 悬疑发现 | 前景遮挡，慢摇预兆，拉焦转移 |
| 权力登场 | 24-35mm，低角度，缓慢推进或升镜 |
| 动作追逐 | 24mm，跟镜/侧背尾随，短距离快速移动 |
| 体育技巧 | 中远景或全景，侧前方机位，稳定跟拍，动作读清 |
| 产品广告 | 微距/50-85mm，滑轨、环绕、拉焦和材质高光 |
| 世界观开场 | 超远景/航拍，缓慢推进或下降揭示 |
| 情绪结尾 | 近景停顿后缓慢拉远，或人物离场后的空镜 |

## 12. 使用边界

- 镜头选择方法读取 `controls/camera-direction/control.md`。
- 人物和道具站位读取 `controls/spatial-blocking/control.md`。
- 具体题材组合读取 `libraries/genre-patterns/library.md`。
- 设备真实感读取 `controls/realism-quality/control.md`。
- 不在一段中堆叠多个互相竞争的主运镜。
