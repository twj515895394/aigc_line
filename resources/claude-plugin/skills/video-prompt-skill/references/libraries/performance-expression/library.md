# Performance And Expression Library

## 1. 作用

提供人物表演、表情、微表情、眼神、呼吸、对白反应和关系情境的可选结构。这里回答“可以演什么、有哪些可见信号”；如何控制变化过程与身份稳定，读取 `references/controls/performance-expression/control.md`。

## 2. 表演描述结构

```text
情境目标 + 眼神落点 + 眉眼变化 + 嘴角/下颌 + 呼吸 + 小动作 + 时间变化 + 最终状态
```

优先写可见变化，不只写“开心、愤怒、悲伤”。

## 3. 基础表情信号

| 情绪 | 眼神 | 眉眼 | 嘴部/下颌 | 身体与呼吸 |
|---|---|---|---|---|
| 开心 | 目光明亮、主动看向目标 | 眼尾轻弯 | 嘴角自然上扬 | 肩颈放松、呼吸顺畅 |
| 害羞 | 视线短暂避开后偷看 | 眼皮轻垂 | 抿唇或轻咬下唇 | 呼吸变浅、手指小动作 |
| 悲伤 | 目光下沉或失焦 | 眉头内侧轻抬、眼尾泛红 | 嘴角下压、下颌轻颤 | 呼吸停顿或变慢 |
| 愤怒 | 目光锁定 | 眉头压低 | 嘴角绷紧、咬肌收紧 | 鼻翼轻张、肩膀紧绷 |
| 恐惧 | 视线快速寻找出口 | 瞳孔放大、眉毛上抬 | 嘴唇微张 | 呼吸急促、身体后缩 |
| 惊讶 | 目光突然停住 | 眼睛睁大 | 嘴巴短暂张开 | 动作冻结半拍 |
| 厌恶 | 目光侧移 | 眉峰不对称 | 上唇轻提、鼻梁收紧 | 身体稍微远离 |
| 怀疑 | 目光停留并观察细节 | 单侧眉轻挑 | 嘴角拉平 | 头部轻偏、回答前停顿 |
| 冷漠 | 眼皮半垂、视线稳定 | 眉眼变化很少 | 嘴角平直 | 呼吸均匀、身体少动 |
| 紧张 | 视线来回或固定过久 | 眉间轻皱 | 抿唇、吞咽 | 呼吸不均、手指收紧 |

## 4. 微表情情境库

### 情绪压抑

- 强忍委屈：眼尾泛红，嘴角向下压，吸气后短暂停住。
- 假装镇定：视线保持稳定，但下颌和手指轻微紧张。
- 秘密被戳破：瞳孔轻缩，嘴角停顿，随后移开视线。
- 强装冷漠：眼皮半垂，回答前停顿，呼吸比表情更明显。
- 病弱强撑：脸色疲惫，呼吸浅，身体轻晃后重新站稳。

### 关系拉扯

- 欲言又止：吸气、嘴唇微动、没有说出口，视线落回对方。
- 识破谎言：先保持礼貌，再让眼神变冷，嘴角弧度消失。
- 心疼不敢靠近：身体向前半步又停住，手指收回。
- 轻微吃醋：视线短暂看向第三者，嘴角收紧后假装无所谓。
- 旧爱重逢：先认出、短暂冻结、呼吸变深，再恢复克制。

### 权力与反派

- 礼貌疏离：嘴角有礼貌弧度，眼神没有温度。
- 压迫审视：视线从上到下短暂评估，头部几乎不动。
- 邪魅试探：单侧嘴角轻抬，眼神停留时间略长。
- 黑化前一秒：表情逐渐归零，呼吸停止半拍，再抬眼。
- 伪装无辜：眉眼柔和但视线回避关键问题。

### 告别与回忆

- 忍痛告别：努力微笑，眼眶湿润，转身前停顿。
- 默默守护：远距离注视，确认对方安全后轻轻松气。
- 听见熟悉声音：先停止动作，眼神缓慢转向声音来源。
- 记忆苏醒：眼神从失焦逐渐聚焦，呼吸和表情慢慢变化。
- 最终释然：肩膀放松，嘴角极轻上扬，目光不再回避。

## 5. 微笑类型

| 类型 | 可见特征 | 适用 |
|---|---|---|
| 元气微笑 | 眼尾弯、苹果肌上提、嘴角对称 | 日常、校园、胜利 |
| 害羞笑 | 低头、视线闪躲、嘴角轻抬 | 暧昧、被夸 |
| 偷笑 | 单侧或克制嘴角、眼神狡黠 | 秘密、恶作剧 |
| 苦笑 | 嘴角勉强上扬、眉头微蹙 | 无奈、失败、告别 |
| 假笑 | 嘴角上扬但眼神不参与 | 社交、权谋、伪装 |
| 冷笑 | 单侧嘴角、下颌微抬 | 对峙、反派、嘲讽 |
| 释然笑 | 呼吸放松后出现很轻的笑 | 结尾、和解、成长 |

## 6. 对白表演选项

### 低能量对白

- 音量低，口型幅度小。
- 句子之间保留自然停顿。
- 眼神和呼吸承担主要情绪。
- 适合暧昧、秘密、疲惫和克制关系。

### 冲突对白

- 情绪分阶段升级，不从第一句就达到顶点。
- 台词前后安排身体停顿和反应。
- 一方说话时另一方要有听觉反应，不同时持续大动作。
- 爆发后保留喘息、沉默或退让。

### 权力对白

- 说话者动作少、节奏稳，视线控制更强。
- 被压制者可通过吞咽、移开视线、后退显示压力。
- 不依赖夸张喊叫建立权威。

### 喜剧对白

- 笑点需要预备、停顿和反应镜头。
- 反应可以比台词更重要。
- 不要让所有角色同时夸张表演。

## 7. 时间分段写法

### 3 秒微表情

```text
0-1s：保持起始状态，视线先发生变化。
1-2s：眉眼、嘴角或呼吸出现主变化。
2-3s：动作停住，形成可读终态。
```

### 5-8 秒关系表演

```text
开场：人物维持表面状态。
触发：听见或看见关键信息。
内在反应：眼神、呼吸和小动作先变化。
外在回应：说话、转身或靠近。
落点：保持沉默、离开、回望或恢复镇定。
```

## 8. 身体小动作库

- 指尖轻敲、收紧、松开。
- 拇指摩擦杯沿或衣角。
- 吞咽、喉结滚动。
- 肩膀抬起后缓慢落下。
- 身体轻微前倾又收回。
- 手抬到一半后改变主意。
- 轻轻整理头发、袖口或领口。
- 脚尖改变方向，显示想离开或靠近。
- 呼气后视线重新聚焦。

小动作只选 1-2 个与剧情有关的信号，避免同时堆叠。

## 9. 动画与漫剧表演

- 允许比写实真人更清楚的眼神、眉眼和姿态变化。
- 夸张必须保留起始、变化和恢复阶段。
- 发丝、服装边缘和符号化效果只能辅助情绪。
- 动态漫画可用有限动画：眨眼、呼吸、发丝、镜头推近、局部表情变化。
- 强情绪镜头之后要安排较弱反应或静止帧，避免全程表情顶格。

## 10. 表情与镜头搭配

| 表演目标 | 推荐镜头 |
|---|---|
| 微妙心动 | 中近景/近景，极慢推近，浅景深 |
| 秘密被发现 | 特写，短暂停顿，拉焦或快速推近 |
| 强忍悲伤 | 固定近景或缓慢后撤 |
| 权力审视 | 低角中近景，镜头少动 |
| 争吵升级 | 中景建立身体关系，再切近景反应 |
| 告别 | 中近景完成动作，长焦抽离或空镜余韵 |
| 惊吓反应 | 中景保留身体后缩，再切表情特写 |
| 喜剧反应 | 稳定机位，保留预备和反应停顿 |

## 11. 常见失败

- 只写情绪名，没有可见信号。
- 每个镜头都使用强表情，像表情包合集。
- 眼神、嘴角、呼吸和身体动作同时过多。
- 表情变化导致脸型和五官比例漂移。
- 对白口型幅度过大或机械重复。
- 角色没有听取对方台词的反应。
- 表演变化没有触发原因和结束状态。

## 12. 使用边界

- 表演变化控制读取 `controls/performance-expression/control.md`。
- 对白、口型和声音同步读取 `controls/audio-visual-sync/control.md`。
- 身份与脸部稳定读取 `controls/continuity-consistency/control.md`。
- 发型完整选择器不在视频 Skill 重复维护；视频只保留其动态与一致性作用。
