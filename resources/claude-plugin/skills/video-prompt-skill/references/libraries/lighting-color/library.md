# Lighting And Color Library

## 1. 作用

提供光源方向、光影类型、色调结构、时间天气光和主体分离方式。这里回答“有哪些光影和色调可选”；如何与空间、连续性和真实感协调，读取对应控制页。

## 2. 光影描述结构

```text
主光来源 + 方向 + 软硬 + 辅光/环境光 + 阴影色 + 高光色 + 主体分离 + 随时间的变化
```

色调不是滤镜。视频中还要说明光线是否移动、闪烁、被遮挡或随场景改变。

## 3. 九类基础光影

| 类型 | 视觉特征 | 情绪与用途 |
|---|---|---|
| 平光 | 阴影弱、信息清楚 | 日常、电商、轻松关系、说明性画面 |
| 侧光 | 一侧亮一侧暗，立体清楚 | 人物性格、冲突、写实肖像 |
| 逆光 | 边缘光、主体轮廓和空气感 | 回忆、浪漫、离别、登场 |
| 顶光 | 面部下方阴影明显 | 审判、压迫、舞台、神秘空间 |
| 底光 | 五官受下方光影响 | 异常、怪诞、惊悚 |
| 轮廓光 | 边缘与背景分离 | 登场、广告、舞台、剪影 |
| 伦勃朗光 | 面部三角光和成熟戏剧感 | 严肃人物、电影肖像、权力关系 |
| 明暗对比光 | 强亮暗分区 | 犯罪、动作、危机、黑色电影 |
| 丁达尔光 | 可见光束和空气颗粒 | 森林、教堂、废墟、仪式、诗意 |

## 4. 常见真实光源

### 室内

- 窗光：方向稳定，随人物和窗帘遮挡变化。
- 顶灯：办公室、商场、医院和家庭常见，容易产生眼窝阴影。
- 台灯：局部暖光，适合桌面和夜间关系戏。
- 屏幕光：偏冷、靠近面部，强度随画面变化但不能剧烈乱闪。
- 实景灯具：落地灯、壁灯、霓虹和招牌，应能在场景中找到来源。

### 户外

- 正午太阳：硬光、短阴影、高对比。
- 阴天散射光：柔和、低反差、情绪冷静。
- 黄金时刻：暖高光、长阴影、轮廓清楚。
- 蓝调时刻：冷蓝环境光和少量暖灯形成色温对比。
- 路灯/车灯：局部光池、移动光斑和真实遮挡。
- 月光模拟：通常由冷色环境光和轮廓光建立，不把夜晚照得像白天。

## 5. 色调三结构

```text
阴影色 + 高光色 + 主体分离
```

主体分离方式：

- 亮暗分离；
- 冷暖分离；
- 饱和度分离；
- 轮廓光；
- 景深和背景层次；
- 局部保色。

## 7. 时间与天气光

### 时间变化

- 清晨：低角度柔光、偏冷环境和暖阳边缘。
- 上午：清晰自然光，色彩相对中性。
- 正午：硬光、高亮、短阴影。
- 下午：方向性增强，色温逐渐变暖。
- 黄金时刻：暖轮廓、长阴影、空气透亮。
- 蓝调时刻：环境冷蓝，实景灯逐渐成为主体。
- 深夜：低照度、局部光源和更强空间黑位。

### 天气

- 晴天：方向明确，阴影边缘清楚。
- 阴天：大面积柔光，适合关系与纪实。
- 雨天：湿地反射、天空散射光、车灯和招牌高光。
- 雪天：环境反射增强，整体更亮更冷。
- 雾天：对比降低，远景层次消失，光束更明显。
- 沙尘/烟尘：暖灰空气、可见颗粒和距离衰减。

## 8. 动态光影

- 人物经过窗格，光影在脸和服装上移动。
- 车辆灯光掠过墙面和人物。
- 火焰或电视产生轻微但有来源的变化。
- 云层遮挡太阳，整体亮度缓慢改变。
- 门打开，走廊或室外光进入室内。
- 舞台灯按节拍移动，但主体可读性始终保持。

动态光不能无来源随机闪烁。

## 9. 人物肤色与产品颜色

### 人物

- 首先保证肤色在主光下可读。
- 强色调主要进入阴影、环境和高光边缘。
- 避免所有面部区域被同一霓虹颜色覆盖。
- 多镜头中保持相近白平衡和曝光逻辑。

### 产品

- 产品主色是高优先级锚点。
- 高光应说明材质，而不是改变产品颜色。
- 透明、金属、玻璃和液体需要环境反射证据。
- 转场或场景变化不能让品牌色随机漂移。

## 10. 风格组合建议

| 题材 | 光影 + 色调 |
|---|---|
| 家庭克制现实 | 窗光/实景灯 + 暖黄或中性纪录色 |
| 都市孤独 | 玻璃反射 + 都市夜景蓝灰与暖灯 |
| 悬疑调查 | 侧光/顶光 + 冷蓝低饱和 |
| 权力登场 | 轮廓光/低调明暗 + 黑金或深冷色 |
| 青春夏日 | 逆光/自然光 + 日系清透或夏日清爽 |
| 末世废墟 | 丁达尔光 + 低饱和冷灰/灰黄 |
| 产品广告 | 精确轮廓和材质高光 + 商业广告色调 |
| 纪录/UGC | 可见真实光源 + 中性色和自然曝光 |

## 11. 常见失败

- 只写色调名，没有光源方向和阴影关系。
- 同一镜头堆叠互斥色调。
- 所有区域统一染色，人物和背景无法分离。
- 光线变化没有场景来源。
- 夜景主体完全不可读，或被照得像白天。
- 跨镜白平衡和光源方向突然变化。
- 产品和服装颜色被风格化高光改变。
- 颗粒、光晕和雾效过强，遮挡主要信息。

## 12. 使用边界

- 光影的空间可信与去 AI 感读取 `controls/realism-quality/control.md`。
- 跨镜光影稳定读取 `controls/continuity-consistency/control.md`。
- 具体风格如何使用色调读取对应 `styles/*/style.md`。
- 不把所有色调方向一次性提供给模型，最终只选择一条主路线。
