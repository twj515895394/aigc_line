# Camera Chaos Diagnostic

## 适用现象

- 镜头漂浮、乱绕、乱推、乱摇；
- 主体动作和镜头运动互相竞争；
- 焦点丢失，看不清叙事重点；
- 画面像游戏自由镜头或无物理稳定器。

## 优先根因

1. 一段同时写多个主运镜；
2. 没有说明镜头为何移动；
3. 镜头缺少起点、路线、速度和停止点；
4. 主体强动作与镜头强动作同时满强度；
5. 风格词或“高级运镜”替代具体镜头任务。

## 检查顺序

```text
本段叙事任务
→ 唯一主镜头任务
→ 起点和观看位置
→ 路线与速度
→ 主体动作强度
→ 焦点对象
→ 停止点和新构图
```

## 最小修复

- 每段只保留一个主运镜；
- 无必要时改为固定机位、轻推或短距离跟拍；
- 主体动作大时降低镜头幅度；
- 明确镜头停止后的构图和主体位置；
- 删除环绕、甩镜、推进、变焦等互相竞争命令；
- 负向限制只保留与当前失败直接相关的 2-4 项。

## 重写骨架

```text
镜头从...位置开始，以...景别观察...
本段唯一镜头任务是...
镜头沿...方向以...速度移动，始终保持焦点在...
当主体完成...时镜头停止，最终构图为...
```
