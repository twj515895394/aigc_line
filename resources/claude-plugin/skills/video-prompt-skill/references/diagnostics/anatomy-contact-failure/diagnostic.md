# Anatomy And Contact Failure Diagnostic

## 适用现象

- 手指、手臂、腿部或关节畸形；
- 人物与人物、手与物体、脚与地面接触不成立；
- 双人互动穿模、抓握错位或接触后无反馈；
- 打击、拿取、拥抱、递交等动作像彼此穿过。

## 优先根因

1. 接触前姿态和接触点未定义；
2. 同一时间安排多个复杂肢体动作；
3. 镜头遮挡关键接触关系；
4. 手部承担过多精细动作且速度过快；
5. 接触后没有受力、位移或恢复反馈。

## 检查顺序

```text
参与主体
→ 接触前姿态
→ 接触部位
→ 接触方向与速度
→ 支撑点和重心
→ 接触反馈
→ 分离或稳定状态
```

## 最小修复

- 一段只保留一个核心接触动作；
- 明确哪只手、哪个部位接触什么位置；
- 使用中景或近景保证接触关系可读；
- 降低高速复杂手势，必要时拆镜；
- 写清受力方向、身体和道具反馈；
- 接触后必须有停顿、反弹、抓稳、松开或新平衡。

## 重写骨架

```text
接触前：主体 A 的...靠近主体/物体 B 的...
接触：以...方向和...速度发生接触，接触点清晰可见。
反馈：A 的重心...，B 出现...位移/形变/反应。
结束：双方在...状态稳定，手部和关节结构清楚。
```
