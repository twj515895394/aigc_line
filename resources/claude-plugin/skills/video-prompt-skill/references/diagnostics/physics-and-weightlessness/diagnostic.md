# Physics And Weightlessness Diagnostic

## 适用现象

- 人物、头发、服装、道具或镜头像没有重量；
- 起步、停止、转向、碰撞和落地缺乏惯性；
- 物体漂浮、弹性错误或环境没有反馈；
- 运动速度与体型、材质和场景不匹配。

## 优先根因

1. 只写位移结果，没有加速、减速和支撑过程；
2. 没有重心、摩擦、重量和受力描述；
3. 主体、服装、头发和环境响应彼此独立；
4. 镜头运动也采用无惯性的“丝滑漂移”；
5. 风格化被误写成无物理限制。

## 检查顺序

```text
质量与材质
→ 支撑和接触面
→ 起步动力
→ 速度变化
→ 惯性和次级运动
→ 碰撞/落地反馈
→ 稳定状态
```

## 最小修复

- 明确重心、支撑脚或接触面；
- 写出加速、减速、转向和停下过程；
- 让头发、衣摆、尘土、水面或道具按主动作延迟响应；
- 补摩擦、压缩、反弹、震动或声响；
- 镜头也要有起步和停止惯性；
- 删除 `weightless`, `ultra smooth floating` 等与目标冲突的描述。

## 重写骨架

```text
主体重量与支撑：...
起步动力：...
运动过程中速度由...变为...，重心沿...移动。
次级响应：头发/服装/道具/环境在...之后产生...
接触或停止时出现...反馈，最终稳定在...
```
