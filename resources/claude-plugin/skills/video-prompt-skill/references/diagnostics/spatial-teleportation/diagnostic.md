# Spatial Teleportation Diagnostic

## 适用现象

- 人物、道具、门窗、背景结构或镜头位置突然跳变；
- 角色进入和离开方向不一致；
- 场景只有地点名，没有前中后景、周边物件或光来源；
- 相邻镜头的左右关系、视线轴和前后景互换；
- 多人物场景中站位与距离失去逻辑。

## 优先根因

1. 没有建立空间骨架和固定参照物；
2. 人物站位、朝向、视线和行动路线未明确；
3. 切镜时违反轴线但没有过渡镜头；
4. 道具状态只写结果，没有移动过程；
5. 多参考场景结构互相冲突。

## 检查顺序

```text
场景骨架
→ 固定参照物
→ 人物和道具初始位置
→ 朝向与视线
→ 行动路线
→ 镜头所在侧
→ 结束位置与下一镜起点
```

## 最小修复

- 固定入口、桌面、窗户、道路、球门等空间锚点；
- 用左/右、前/后、近/远和相对主体的位置描述关系；
- 相邻镜头共享人物朝向、行动方向和道具状态；
- 必须换轴时加入中性镜头、正面镜头或可见过轴过程；
- 删除互相冲突的场景参考；
- 道具变化写出拿起、移动、放下或交接过程。
- 先补空间最小模型：地点 + 前中后景 + 光来源；简单场景 2–4 个有位置物件，复杂场面继承可见场景骨架。不要靠压词数修。

## 重写骨架

```text
空间骨架：...
人物 A 位于...，面向...；人物 B 位于...
关键道具位于...
行动路线：从...经过...到达...
镜头始终位于轴线...侧；若换侧，通过...完成过渡。
结束状态：人物、道具和镜头分别停在...
```
