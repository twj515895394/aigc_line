# Motion Discontinuity Diagnostic

## 适用现象

- 动作突然跳步、重置或反向；
- 人物重心、手脚位置和速度前后不连续；
- 首帧到终态之间缺少可达过程；
- 多镜头之间动作无法自然衔接。

## 优先根因

1. 只写动作名，没有动作阶段；
2. 起始姿态与目标姿态物理不可达；
3. 同一时间安排过多独立动作；
4. 镜头切换掩盖了必要的中间状态；
5. 前后镜没有共享交接姿态、方向和速度。

## 检查顺序

```text
起始姿态
→ 重心和支撑点
→ 动作阶段
→ 速度与方向
→ 接触和反馈
→ 结束姿态
→ 下一镜起点
```

## 最小修复

- 将动作拆成起势、推进、接触或转折、反馈、恢复；
- 每段只保留一个主动作；
- 明确脚步、肩线、手部和视线的阶段变化；
- 需要时增加中间关键帧或拆成两镜；
- 相邻镜共享结束/开始姿态和运动方向；
- 删除与主动作竞争的镜头运动。

## 重写骨架

```text
起始：主体处于...，重心落在...，手部位于...
推进：先...，随后...，速度由...变化为...
转折/接触：...
反馈：身体、衣物、道具和环境出现...
结束：主体稳定在...，为下一镜保留...方向与姿态。
```
