# Audio Visual Mismatch Diagnostic

## 适用现象

- 音效、对白、BGM 重拍与画面事件错位；
- 环境声与场景空间不匹配；
- 音乐始终满强度，压过叙事；
- 画面没有对应声音来源；
- 声音结束后画面仍在错误节奏中推进。
- 没写 BGM 决定，或环境 / 拟音 / 对白层整段空白。

## 优先根因

1. 音频没有被当作时间骨架；
2. 视觉事件未绑定明确声音节点；
3. BGM、对白、环境音和拟音层级不清；
4. 声音空间与镜头距离不一致；
5. 同时服从多个互相冲突的节拍参考。

## 检查顺序

```text
声音主真源
→ 时间节点
→ 对白/BGM/环境音/拟音职责
→ 视觉事件绑定
→ 声音远近和方向
→ 进入、持续、退出
→ 最终落点
```

## 最小修复

- 指定唯一节奏主参考；
- 把声音拆成节点而不是一句“跟随音乐”；
- 每个关键视觉事件只绑定一个明确拍点或对白节点；
- 让环境声和拟音随镜头距离、空间和遮挡变化；
- BGM 在对白和关键动作处让位；
- 删除没有画面来源的装饰音效。
- 显式写 BGM 决定：无 BGM 要写原因；有 BGM 写进入 / 让位 / 退出。不要把“没写 BGM”当成“无 BGM”。

## 重写骨架

```text
声音主真源：...
0-X 秒：环境底噪...，视觉事件...
X-Y 秒：对白/重拍出现，主体在节点...完成...
Y-结束：BGM 减弱/退出，保留...拟音，画面和声音共同停在...
```

## 完成标准

关闭任一声音层后仍能说明其原本服务的视觉节点，所有保留声音都有来源、时间和空间关系。
