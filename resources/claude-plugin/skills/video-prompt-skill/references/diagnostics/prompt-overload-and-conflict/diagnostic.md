# Prompt Overload And Conflict Diagnostic

## 适用现象

- 指定时长里要完成多套互不连续的主事件，时间装不下；
- 多个互斥主目标、运镜、风格或限制互相竞争；
- 模型忽略核心任务；
- 正向描述和负向限制互相否定。

同一镜头把画面、动作、光色、镜头写细，**不是**本诊断的适用现象。那种情况不要当过载修。

## 优先根因

1. 没有唯一主目标；
2. 全局固定项与本段变化混写；
3. 同义风格词和质量词重复；
4. 互斥镜头、光影、动作或节奏并列；
5. 负向词过多，主描述不足；
6. 模型专属语法污染通用导演方案。

## 检查顺序

```text
唯一主目标
→ 任务与时长
→ 必须保留/修改/禁止
→ 全局固定项
→ 时间轴变化
→ 主体运动
→ 镜头任务
→ 风格和声音
→ 高风险限制
→ 模型适配
```

## 最小修复

- 先分清：是独立主事件过多，还是画面维度写细。后者不修；
- 主事件过多：提醒用户加时长、拆段或取舍，不静默删用户要的主内容，也不把细节压糊；
- 用一句话锁定唯一主目标；
- 全局固定项只写一次；
- 互斥要求按信息优先级裁决，不并列保留；
- 负向限制只留当前最危险的 3-8 项；
- 通用方案完成后再进入 Generic、Seedance 或 LTX 转换。

## 冲突示例

- 固定机位 vs 大幅环绕；
- 深景深 vs 背景完全虚化；
- 角色保持静止 vs 连续复杂动作；
- 慢节奏长镜头 vs 每秒多次切镜；
- 写实纪录感 vs 无物理漂浮运动；
- 无对白 vs 精准口型。

## 重写骨架

```text
主目标：...
必须保留：...
必须修改：...
全局固定项：...
时间轴：每段仅保留主体动作、镜头状态和结束状态。
风格与声音：只保留服务主目标的实现变量。
高风险限制：...
目标模型：最后一步转换。
```

## 完成标准

删除任何一个保留项都会明显影响主目标；剩余要求之间不存在未裁决的互斥关系。
