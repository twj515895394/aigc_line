# Reference Role Conflict Diagnostic

## 适用现象

- 多张图片生成出混合脸、混合服装或混合场景；
- 动作参考视频错误带入原人物、服装和背景；
- 多个视频的运镜和节奏互相覆盖；
- 音频、视频和文字给出不同时间结构；
- 首帧、尾帧或关键帧之间物理不可达。

## 优先根因

1. 素材没有明确职责；
2. 同一关键维度存在多个主真源；
3. 辅助参考没有禁止继承项；
4. 用户目标与自动推断的素材用途冲突；
5. 多模态素材的时间结构不一致。

## 检查顺序

```text
用户明确要求
→ 素材清单
→ 每个维度的唯一主真源
→ 辅助职责
→ 保留强度
→ 禁止继承
→ 时间和物理兼容性
→ 模型引用语法
```

## 最小修复

- 为人物、服装、场景、动作、运镜、节奏和声音分别指定唯一主真源；
- 将其他素材降为局部参考或删除；
- 明确动作视频只借动作，不继承人物和背景；
- 写清每份素材的强保留、允许适配和禁止继承；
- 首尾帧不可达时增加中间帧、简化动作或拆段；
- 先完成通用职责绑定，最后才转换成模型专属引用语法。

## 重写骨架

```text
人物身份主真源：...
服装主真源：...
场景主真源：...
动作主真源：...
运镜主真源：...
节奏/声音主真源：...
辅助参考仅用于：...
禁止继承：...
冲突裁决：...
```

## 完成标准

每份素材都有明确用途，每个关键维度只有一个主真源，辅助参考不会覆盖身份、场景或时间结构。
