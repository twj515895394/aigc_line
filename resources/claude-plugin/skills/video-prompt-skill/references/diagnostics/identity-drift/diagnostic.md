# Identity Drift Diagnostic

## 适用现象

- 人脸、年龄感、发型、服装或主体类别跨帧变化；
- 多镜头里像换了角色；
- 开场只有职业 / 身份词，没有每人角色卡；
- 耳环、项链、拳套等饰品复制、消失或两人互换；
- 服装覆盖范围改变、无故走光或画风逐渐变成另一种媒介；
- 表情变化同时带动五官比例漂移；
- 多参考素材生成出混合身份。

## 优先根因

1. 人物身份没有唯一主真源；
2. 脸部、发型、服装锚点过多或互相冲突；
3. 每镜重复改写完整人物设定，产生版本差异；
4. 动作、表情和镜头幅度同时过大；
5. 辅助参考错误覆盖人物主参考。

## 检查顺序

```text
人物主参考
→ 身份锚点
→ 服装和发型主轮廓
→ 表情变化边界
→ 动作和镜头强度
→ 跨镜交接状态
```

## 最小修复

- 指定唯一人物身份主参考；
- 全局只写一次脸型、发型、服装和主配色；
- 每镜只写本镜变化，不重写完整身份；
- 把情绪改成眼神、呼吸、眉眼和嘴角过程；
- 降低大幅转头、快速遮挡和强环绕同时发生的概率；
- 明确禁止辅助参考继承人物身份。
- 开场补角色卡：几个人，每人一行外貌 / 穿着 / 当前状态；不要靠压词数修。
- 锁饰品归属、服装覆盖和画面媒介，禁止复制、互换和媒介漂移。

## 重写骨架

```text
唯一人物主参考：...
全局身份锚点：脸型...，眼型...，发型主轮廓...，服装主识别点...
本段只变化：表情 / 姿态 / 视线...
跨帧保持：五官比例、发际线、服装轮廓和主配色不变。
禁止：融合其他人物身份、无原因换装、表情变化引起脸型重构。
```

## 完成标准

相邻帧和相邻镜头仍能明确识别为同一主体，变化只发生在用户允许的表情、姿态和镜头距离上。
