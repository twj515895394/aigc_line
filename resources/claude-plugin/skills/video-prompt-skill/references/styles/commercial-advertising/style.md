# Commercial Advertising Style

## 1. 定位

用于产品、品牌、时尚、美妆、食品、汽车和概念广告。核心是产品识别准确、卖点有视觉证据、材质可信、节拍清楚，并以品牌或结果落点收束。

## 2. 核心结构

```text
视觉钩子 + 产品出现 + 卖点/材质证据 + 使用或变化 + 结果体验 + 品牌落点
```

广告不是单纯把产品拍得漂亮。每个镜头应回答：产品是什么、为什么值得关注、结果是什么。

## 3. 产品锚点

必须锁定：

- 产品形状、比例、颜色、Logo 和文字；
- 包装结构、按钮、接口、镜头、标签等识别点；
- 材质：金属、玻璃、塑料、织物、皮革、液体或食物；
- 使用方向、开合方式和功能状态；
- 同一产品跨镜不增加、删除或移动关键结构。

## 4. 镜头语言

- 英雄镜头：中近景/特写，产品完整可辨，背景简洁。
- 材质镜头：微距、滑轨、光线掠过和焦点转移。
- 功能镜头：保持操作过程、接触关系和结果可见。
- 使用镜头：人物、场景和产品关系自然，不让人物遮挡卖点。
- 多场景镜头：产品保持位置或形态稳定，背景通过匹配转场变化。
- 品牌落点：产品最终姿态、品牌信息或使用结果停住。

## 5. 材质实现

### 金属

- 清楚边缘、高光带和环境反射；
- 避免全表面镜面反光或塑料质感。

### 玻璃/透明材质

- 轮廓、折射、内部结构和背景反射；
- 保持透明度，不让高光把形状抹掉。

### 液体

- 黏度、流向、飞溅、气泡和容器接触；
- 食品饮料强调真实重力和表面张力。

### 织物/皮革

- 褶皱、拉伸、纹理和光泽符合材质；
- 人物运动时材质反馈自然。

### 食品

- 温度、蒸汽、油脂、酥脆、切面和新鲜度；
- 拟音和镜头节奏增强触感，但颜色保持真实。

## 6. 节拍类型

### 卖点揭示

```text
局部悬念 → 完整产品 → 功能动作 → 可见结果 → 品牌停顿
```

### 生活方式

```text
需求情境 → 产品自然进入 → 使用体验 → 人物反应 → 结果画面
```

### 高概念视觉

```text
现实基准 → 单一视觉规则 → 产品受规则影响但外观稳定 → 奇观高潮 → 产品回到英雄镜头
```

### 多卖点

- 每个卖点一个清楚镜头单元；
- 通过统一动作、色块、声音或产品位置连接；
- 不在一个镜头里同时演示所有功能。

## 7. 转场

推荐：

- 形状匹配；
- 动作匹配；
- 产品位置锁定，背景切换；
- 遮挡、甩镜和光线掠过；
- 微距进入材质/内部结构，再拉出；
- 节拍点完成变装、场景或功能切换。

转场不能让产品比例、颜色和 Logo 漂移。

## 8. 光影与色彩

- 主色围绕品牌和产品，不让背景抢夺识别度。
- 主体分离可用亮暗、冷暖、轮廓光和景深。
- 高光展示材质，不把产品表面照成死白。
- 黑金适合奢侈和科技，但暗部仍保留纹理。
- 清透高键适合美妆、日化、食品和生活方式。
- 强色彩概念广告需要一条稳定配色规则。

## 9. 人物表演

- 人物动作服务产品使用，不做无关大动作。
- 手部握持、打开、佩戴、涂抹、倒入和操作必须准确。
- 反应自然，避免夸张“惊艳脸”。
- 美妆和时尚可强化姿态、视线和节奏，但产品仍是主信息。

## 10. 声音设计

- 材质拟音：开盖、点击、喷雾、液体、布料、机械锁定。
- BGM：清楚乐句和关键重拍。
- 转场音效与画面触发同步。
- 旁白只讲关键卖点，不逐镜复述。
- 品牌声音标识在结尾清楚但不过长。

## 11. Prompt 实现骨架

```text
生成一段 [时长] 的 [产品/品牌类型] 广告。
核心卖点：[唯一主卖点或按顺序列出的少量卖点]。
产品锚点：[外观、颜色、材质、Logo、关键结构]。
时间轴：[钩子 → 产品 → 证据/使用 → 结果 → 品牌落点]。
镜头：[英雄镜头、材质/功能镜头、主运镜和转场]。
光影色彩：[品牌主色、材质高光、主体分离]。
声音：[BGM、拟音、旁白和品牌声音]。
限制：[外观不漂移、文字准确、操作物理正确、转场不改变产品]。
```

## 12. 常见失败

- 产品漂亮但卖点不清楚。
- Logo、包装文字和结构跨镜变化。
- 反光和光晕遮挡产品轮廓。
- 手与产品接触错误。
- 转场太多、产品出现时间太短。
- 每个镜头采用不同色调和视觉语言。
- 结尾没有完整产品和品牌停顿。
- 旁白和画面信息重复过多。
