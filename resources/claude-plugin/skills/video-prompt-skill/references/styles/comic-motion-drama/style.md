# Comic Motion Drama Style

## 1. 定位

用于 AI 漫剧、动态漫画、韩漫感、国漫短剧、分镜驱动视频和有限动画叙事。核心是以稳定角色和清楚画格推进剧情，而不是把静态漫画随机做成全画面运动。

## 2. 核心结构

```text
角色锚点 + 分镜构图 + 有限而明确的局部运动 + 表情节拍 + 镜头推进 + 音效/对白 + 镜间连续性
```

## 3. 画格与镜头

- 每镜有唯一信息：空间、关系、表情、动作或线索。
- 通过推近、横移、拉焦、前景遮挡和画格切换增强动态。
- 不要求每镜角色全身持续运动。
- 重要情绪使用近景/特写，重要动作先用中景或全景读清。
- 多格故事板转视频时保持镜号和承接状态。

## 4. 有限动画层

可用：

- 眨眼和眼神移动；
- 呼吸和嘴角变化；
- 发丝、衣角、烟雾和背景粒子；
- 手部轻微动作；
- 镜头慢推、轻移和局部拉焦；
- 光线、阴影和氛围层变化。

有限动画应服务剧情信号，不让每个区域同时循环。

## 5. 角色一致性

锁定：

- 脸型、眼型、发型和主配色；
- 服装轮廓、纹样、配饰和道具；
- 线条、上色、阴影和画面纹理；
- 不同表情下仍保持同一五官比例。

跨镜改变服装、伤痕、武器或发型时，必须有剧情触发和状态记录。

## 6. 表演

- 使用眼神落点、眉眼、嘴角、呼吸和手指小动作。
- 强情绪可更符号化，但需要前一镜铺垫和后一镜反馈。
- 对白镜头安排说话者和倾听者反应。
- 反派、权谋和关系戏强调视线与停顿，而不只依赖夸张笑容。
- 泪水、脸红、黑线、速度线等符号只在对应情绪节点出现。

## 7. 动作戏

```text
起势格 → 动作路线格 → 接触/爆点格 → 受击反馈格 → 恢复/局势格
```

- 接触点和受力方向清楚。
- 可使用冲击线、背景简化和短时变形强化命中。
- 爆点后恢复正常比例和空间。
- 动作不能只靠白光、模糊和快速切镜掩盖。

## 8. 常用题材方向

### 权谋/登场

低角、对称、冷静推近、黑金或冷蓝、少动作强视线。

### 废墟/末世

大空间、低饱和、风和尘埃、角色比例较小、缓慢镜头。

### 恋爱/关系

中近景、过肩、微表情、发丝小幅运动、柔和环境声和对白停顿。

### 打斗/对峙

站位先建立，动作按阶段拆分，冲击后保留反应帧。

### 奇幻/仙侠

角色和法器锚点稳定，衣袖、发丝和特效遵守风向与能量路线。

## 9. 光影和色彩

- 画面色块应服务角色识别和情绪。
- 强色调不改变肤色、服装和道具主颜色。
- 光效与能量特效可以影响局部环境和角色边缘。
- 多镜头保持统一上色方法和阴影层数。

## 10. 声音

- 对白和旁白承担剧情信息。
- 页面/画格切换可使用轻量转场声。
- 动作使用清楚起势、命中和反馈音效。
- 环境声避免让画面像完全静止插画。
- BGM 按章节和情绪变化，不每镜重新开始。

## 11. Prompt 实现骨架

```text
生成一段 [时长] 的 AI 漫剧/动态漫画视频。
角色锚点：[外貌、发型、服装、配色、线条和渲染]。
场景与分镜：[镜号、构图、站位和关键道具状态]。
时间轴：[每镜唯一任务、局部运动、表情/动作、镜头变化、承接状态]。
动画方式：[有限动画层 + 关键动作阶段]。
声音：[对白/旁白、环境、动作和章节音乐]。
限制：[不重绘变脸、不随机换装、不跳动作、不让所有画格同时运动]。
```

## 12. 常见失败

- 角色在不同镜头像不同人或不同画风。
- 只对整张画面做缩放，没有角色表演和空间层次。
- 每个元素都循环运动，画面廉价且嘈杂。
- 情绪符号持续出现，没有触发和消失。
- 动作只剩速度线和闪光，看不清接触关系。
- 跨镜道具、伤痕、服装和位置失去连续。
