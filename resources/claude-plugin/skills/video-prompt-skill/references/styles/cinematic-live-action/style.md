# Cinematic Live Action Style

## 1. 定位

用于电影化真人影像、剧情短片、情绪片、悬疑、动作和作者化写实视频。

电影感不是单一滤镜，而是：

```text
可信主体与场景 + 明确摄影位置 + 有目的的镜头 + 可见光源 + 自然表演 + 声音空间 + 节奏与收尾
```

## 2. 核心执行变量

### 摄影位置

- 先确定观众是旁观、跟随、窥视、主观参与还是被设备记录。
- 镜头距离随叙事变化，不从头到尾只用特写。
- 一段只保留一个主运镜，镜头停止也是设计。

### 空间

- 开场至少提供一个空间证据：入口、桌面、街道、窗、人物站位或环境声。
- 人物运动有明确路线和落点。
- 前中后景和光源位置保持可理解。

### 表演

- 眼神、呼吸、嘴角和小动作优先于夸张表情。
- 情绪必须由事件触发，并有恢复或停顿。
- 对白保留听取反应和自然停顿。

### 光影

- 使用可见或可推断的光源。
- 阴影色、高光色和主体分离服务同一情绪。
- 不用无来源的动态闪光制造“高级感”。

### 声音

- 环境声建立空间。
- 拟音与动作接触同步。
- BGM 支撑节奏，不覆盖对白和关键反应。
- 结尾保留尾音、呼吸或环境余韵。

## 3. 常用子方向

### 都市孤独现实

- 长焦压缩或玻璃反射；
- 蓝灰环境与暖路灯；
- 旁观距离和留白；
- 缓慢抽离或人物离场后的空镜。

### 家庭克制现实

- 自然窗光和实景灯；
- 稳定中景、中近景和过肩；
- 日常空间和收敛表演；
- 环境声与对白后停顿。

### 冷调悬疑

- 前景遮挡、规则构图、慢摇预兆和焦点转移；
- 低饱和冷蓝或阴天冷灰；
- 画外声、低频和静默；
- 信息逐步揭示，不持续炫技。

### 权力与仪式

- 低角、对称、明确队列和空间纵深；
- 深阴影、轮廓光和有限色块；
- 人物动作少而稳定；
- 声音节奏厚重但保留语言清晰度。

### 废墟与诗意

- 长镜头、缓慢移动、水面/尘埃/风的环境变化；
- 低饱和、潮湿或时间侵蚀材质；
- 稀疏对白和空间声；
- 人物在大空间中保持较小比例。

## 4. 推荐镜头节奏

### 单片段

```text
建立可信初始状态 → 推进一个动作或情绪 → 关键反应/信息 → 动作完成与余韵
```

### 多镜头

```text
远景/全景建立 → 中景关系 → 近景推进 → 特写爆点 → 中远景或空镜收束
```

顺序可变化，但必须覆盖空间、关系、变化和结果。

## 5. Prompt 实现骨架

```text
生成一段 [时长] 的电影化写实视频。
观看位置与摄影来源：[旁观/跟随/主观/设备]。
场景与初始状态：[可信空间、人物位置、可见光源]。
时间轴：[每段主体动作、镜头状态、表演、声音和结束状态]。
摄影语言：[主景别、机位、焦段倾向、唯一主运镜]。
光影色调：[光源、阴影、高光和主体分离]。
声音：[对白/环境音/拟音/BGM 的主次]。
限制：[身份、物理、镜头和空间的高风险项]。
```

## 5.5 媒介锁定

有首帧或明确写实锚点时，全程保持真人摄影媒介：皮肤、布料、汗水和环境光服从同一光源。

禁止无理由漂成二维动画、塑料 CG、光滑游戏模型或插画厚涂。运动模糊只在高速掠过时短促出现，不替代接触和重量。

## 6. 真实感要求

- 保留微小不完美：自然曝光变化、衣物褶皱、呼吸和真实停步。
- 主体动作和镜头不能同时最大化。
- 环境必须对人物动作有反馈。
- 皮肤、布料、玻璃、金属和地面反光符合光源。
- 每一帧不必都像精修海报。

## 7. 常见失败

- 只写“cinematic masterpiece”，没有摄影和动作。
- 所有镜头都使用强逆光、霓虹、颗粒和浅景深。
- 人物一直做微动作，镜头也不断漂移。
- 只有氛围，没有事件和收尾。
- 导演名堆叠代替可执行变量。
- 风格化色调破坏肤色和空间可读性。
