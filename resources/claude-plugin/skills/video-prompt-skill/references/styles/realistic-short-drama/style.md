# Realistic Short Drama Style

## 1. 定位

用于家庭、都市、职场、关系、生活流和竖屏短剧。核心不是堆电影术语，而是让空间、人物关系、信息变化和表演都能快速读懂。

## 2. 核心目标

```text
可信场景 + 清楚人物关系 + 单一剧情变化 + 可读表演 + 简洁镜头 + 自然收尾
```

## 3. 场景执行

- 开场快速交代地点、人物位置和关系距离。
- 使用真实日常道具建立职业或生活语境。
- 门、桌、窗、走廊和座位关系保持连续。
- 竖屏画面优先保证人物和关键道具可读，不把主体放在过宽空间边缘。

## 4. 镜头策略

- 建立：全景/中景说明空间和双人关系。
- 对话：中近景、过肩和稳定反打。
- 情绪：近景或特写只用于关键变化。
- 动作：保持身体和道具接触可见。
- 收尾：动作完成后的停顿、视线落点、轻拉远或环境空镜。

默认使用固定机位、轻微手持、短距离滑动或缓慢推进。除非剧情需要，不使用大幅环绕和连续穿越。

## 5. 表演策略

- 角色先听见或看见触发信息，再产生反应。
- 对白不同时配合多个无关动作。
- 用眼神、吞咽、手指、身体前倾/后靠和呼吸表现关系变化。
- 冲突分阶段升级，爆发后安排沉默或恢复。
- 不把每一句台词都演成强情绪特写。

## 6. 常用场景组合

### 家庭关系

- 自然窗光、暖实景灯、中性色；
- 餐桌、沙发、厨房或门口作为关系空间；
- 固定中景让人物走位和沉默发挥作用；
- 餐具、脚步、门和房间环境声建立真实感。

### 都市关系

- 办公室、咖啡店、电梯、街口、车内；
- 35-85mm，玻璃反射或长焦可辅助距离感；
- 屏幕光、顶灯、路灯和招牌属于真实光源；
- 结尾可用人物离开、消息提示音或车窗外空镜。

### 职场短剧

- 先明确职位关系、文件/屏幕/会议桌等证据；
- 对话镜头以信息可读为优先；
- 权力变化通过站坐关系、距离、视线和说话节奏表达；
- 避免无意义走廊慢动作和过度商业灯光。

### 竖屏强情节

- 关键人物和道具始终在安全构图区；
- 前 1-2 秒提供清楚冲突钩子；
- 镜头切换少而明确；
- 字幕不是视频 Prompt 的默认依赖，剧情本身应可视化。

## 7. 推荐节拍

```text
0-20%：交代人物、空间和当前状态
20-55%：出现触发信息或动作
55-80%：人物反应、对白或关系变化
80-100%：决定、停顿、离开或新的悬念落点
```

短视频中可以只保留三段，但必须有明确结果状态。

## 8. 光影与色调

- 家庭：自然光、暖黄或中性纪录色。
- 职场：顶灯与窗光混合，保持肤色自然。
- 都市夜景：蓝灰环境 + 暖路灯/室内灯，面部仍可读。
- 悬疑关系：冷灰、侧光和局部暗区，不让画面整体死黑。

## 9. 声音

- 对白是主信息时降低 BGM。
- 房间和街道环境声保持空间连续。
- 手机、门、杯子、文件等关键道具提供拟音。
- 台词后保留 0.2-0.8 秒自然反应和环境声。
- 结尾不要把对白、音乐和画面同时硬切。

## 10. Prompt 实现骨架

```text
生成一段 [时长] 的写实短剧。
场景与关系：[地点、人物身份、站位和关键道具]。
剧情主变化：[本段唯一冲突/信息/选择]。
时间轴：[建立 → 触发 → 反应/对白 → 落点]。
镜头：[稳定、可读、少量主运镜，关键处使用近景]。
表演：[眼神、呼吸、小动作和听取反应]。
光影声音：[真实光源、环境声、必要拟音和克制 BGM]。
连续性：[身份、服装、空间、道具和动作状态]。
```

## 11. 常见失败

- 只有人物特写，没有空间和关系。
- 台词很多但动作和表情没有听取反应。
- 每个镜头都慢推，节奏单调且假。
- 光影过度广告化，不像真实生活空间。
- 冲突一开始就顶格，缺少递进。
- 结尾仍在说话或做动作，像被硬截断。
- 为追求竖屏刺激不断快速切镜，反而看不懂关系。
