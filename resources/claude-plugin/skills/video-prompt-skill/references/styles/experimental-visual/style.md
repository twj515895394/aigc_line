# Experimental Visual Style

## 1. 定位

用于抽象、超现实、梦境、材质变形、概念短片、视觉特效和非现实空间。核心是先定义一条可执行视觉规则，再按时间升级，而不是随机堆叠奇观词。

## 2. 核心结构

```text
现实基准 + 单一异常规则 + 触发条件 + 分阶段升级 + 主体/空间反馈 + 新稳定状态
```

## 3. 视觉规则类型

### 材质规则

- 固体逐步变成液体、玻璃、金属、布料、纸张或粒子；
- 材质变化从一个清楚位置开始，并沿表面传播；
- 变化后保留质量、重力、反射和接触逻辑。

### 空间规则

- 人物每次转身后空间改变；
- 房间持续折叠、延伸或旋转；
- 门窗连接不可能地点；
- 前景、背景或反射空间逐步交换。

### 时间规则

- 只有背景加速，人物保持正常速度；
- 动作反向播放但环境正常；
- 同一地点显示不同时间层；
- 时间冻结中只有特定主体可以运动。

### 身份/形态规则

- 人物影子独立行动；
- 镜中人物和现实人物发生不同动作；
- 主体逐步分裂、重组或变成另一形态；
- 变化必须有中间状态，身份锚点按目标保留或明确消失。

### 音画规则

- 材质随声音频率变化；
- 每个重拍改变空间结构；
- 对白形成可见波纹、文字形态或环境反应；
- 静默时世界停止变化。

## 4. 时间推进

推荐结构：

```text
0-20%：建立正常世界和主体
20-40%：异常第一次出现，范围小且可辨
40-70%：规则扩大，影响主体或空间
70-90%：视觉高潮或规则反转
90-100%：形成清楚新状态、回归现实或留下概念余韵
```

短视频只使用一个主异常规则，最多增加一个辅助规则。

## 5. 镜头策略

- 固定或缓慢镜头适合让异常在画面内发生。
- 穿越运镜适合进入新空间或材质内部。
- 微距到宏观适合材质、生物和机械变化。
- 环绕适合形态变化，但不应持续无止境。
- 主观镜头适合梦境、记忆和感知改变。
- 高速镜头只在规则爆发或节拍节点使用。

## 6. 特效执行

### 粒子化

- 明确粒子类型、起始区域、传播方向、风/重力和消散或重组。

### 液态变形

- 明确黏度、流向、表面张力、反射和最终形态。

### 破碎与重组

- 碎片数量和尺度保持视觉一致；
- 碎片沿可见轨迹运动；
- 重组后形成清楚对象，不停留在随机噪点。

### 空间扭曲

- 定义作用区域和边界；
- 主体与背景的透视关系同步变化；
- 变化完成后镜头和空间重新稳定。

### 生长与生成

- 从骨架、线条、根系、机械结构或粒子逐步形成；
- 各部分有顺序，不整物瞬间出现。

## 7. 风格方向

### 梦境诗意

柔和时间、反射、漂浮但有规则的物体、稀疏声音和缓慢变化。

### 怪诞现实

真实场景中只有一个异常规则，表演保持克制，形成反差。

### 科技概念

机械展开、界面、透明结构、数据或材料变化，空间和产品结构清楚。

### 暗黑超现实

低光、高反差、非正常影子或空间，异常逐步揭示而非持续闪烁。

### 音乐视觉化

色彩、材质、镜头或空间按乐句和结构拍点变化，不机械逐拍切换。

## 8. 光影与声音

- 异常效果可以成为局部动态光源，但需影响附近材质和人物。
- 主色不宜超过 2-3 个主要方向。
- 声音需要解释变化：低频、材质声、反向声、空间混响或节拍触发。
- 高潮之后保留声音衰减、静默或单一环境声。

## 9. Prompt 实现骨架

```text
生成一段 [时长] 的实验/超现实视频。
现实基准：[正常主体、场景、光线和初始状态]。
唯一视觉规则：[什么发生变化、触发条件、传播方式和边界]。
时间轴：[首次异常 → 规则扩大 → 影响主体/空间 → 高潮 → 新稳定状态]。
镜头：[观看位置、主运镜、速度和停止点]。
材质/特效：[物理属性、环境反馈、消散或重组]。
声音：[规则与声音、节拍或静默的关系]。
限制：[不随机增加第二套规则、不无中间状态跳变、不让特效遮挡主变化]。
```

## 10. 常见失败

- 同时堆叠粒子、液体、火焰、空间折叠和多世界穿越。
- 只有形容词，没有视觉规则和时间过程。
- 异常从全画面同时发生，没有触发点。
- 形态变化没有中间状态和结束状态。
- 特效亮度、颜色和运动随机变化。
- 人物、镜头和空间同时高速运动，主概念无法阅读。
- 概念高潮后直接硬切，没有新稳定画面。
