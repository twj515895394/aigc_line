# Anime Animation Style

## 1. 定位

用于日漫、国漫、动画电影、角色动作、青春、奇幻和风格化世界。重点是角色造型锚点、线条与渲染连续、动作读得清、环境与特效遵守同一视觉规则。

## 2. 核心结构

```text
角色造型一致 + 动画媒介规则 + 清楚动作姿态 + 分层背景 + 可控镜头 + 光影色彩 + 声音节奏
```

## 3. 角色一致性

必须锁定：

- 脸型、眼型、发型轮廓和发色；
- 服装主轮廓、配色和配饰；
- 身体比例和年龄感；
- 线条粗细、阴影层级和高光方式；
- 关键道具外观。

发型在视频中既是身份锚点，也是动态元素。风吹、奔跑和旋转时可以运动，但长度、刘海结构和主轮廓不能漂移。

## 4. 动画运动层级

### 有限动画

- 眨眼、呼吸、嘴角变化；
- 发丝、衣角和环境小幅运动；
- 镜头推近、横移、拉焦；
- 适合对话、情绪和动态漫画。

### 常规角色动画

- 明确关键姿态、过渡姿态和结束姿态；
- 身体动作、发丝和服装有层级延迟；
- 表情变化与身体动作同步但不过载。

### 高动作动画

- 先保证动作剪影、重心和路线；
- 速度线、夸张透视和特效只强化主动作；
- 爆点之后必须有反馈帧或落地姿态；
- 镜头不应掩盖脚步、武器或接触点。

### 媒介锁定

图生或有明确画风锚点时，把首帧媒介写成全程合同，不只写风格名。

厚涂 / 动作动画电影至少锁：

- 可见笔刷或色块层级、手绘轮廓、非写实但结构准确的比例；
- 运动时笔触稳定附着在身体、头发和衣服上；
- 不得纹理爬动、线条闪烁、五官逐帧重画、画风逐渐写实。

禁止无理由转换成：真人照片、3D 渲染、塑料 CG、光滑游戏模型或低幼卡通。赛璐璐和 3D 动画各自锁自己的色块 / 模型规则，不混用。

### 动作冲击预算

真正命中、近身掠过或落地冲击时，才使用短促动画句法：

- 2–4 帧手绘残影或局部速度线；
- 约 0.2 秒 speed ramp 或一帧高对比；
- 短促 impact push-in 后立刻恢复正常动画速度。

禁止全程运动模糊、持续画面抖动或特效盖住接触点。速度线方向跟随打击或掠过方向。具体转场选项读取 `libraries/transition-effects/library.md`。

## 5. 视觉渲染方向

### 现代动画电影

- 清楚线条、柔和分层阴影；
- 环境光和角色色彩融合；
- 天空、反射、空气粒子和景深增强空间。

### 赛璐璐动画

- 明确色块、有限阴影层级；
- 动作轮廓清楚；
- 光影变化不应让角色颜色随机改变。

### 厚涂/国漫动画

- 更丰富材质和光影层次；
- 角色仍需保持清楚轮廓；
- 避免每帧笔触和脸部细节重绘漂移。

### 3D 动画

- 统一模型比例、材质和渲染；
- 关节运动和面部表情保持动画逻辑；
- 避免塑料材质和过度平滑运动。

## 6. 镜头策略

- 角色关系：中景、中近景、过肩和反打。
- 情绪：近景、特写、极慢推近和固定凝视。
- 动作：广角全景、低机位、侧向跟拍和短时爆发运镜。
- 世界观：超远景、航拍式下降、前景分层和大空间纵深。
- 结尾：角色姿态停住、发丝和环境保留轻微余动。

动画镜头可以比写实更夸张，但必须有主任务和清楚落点。

## 7. 表演

- 眼神和眉眼变化可以更清楚，但不必每镜都极端。
- 用身体剪影、肩颈、手部和站姿表达角色气质。
- 对白时口型、眨眼、呼吸和头部运动分层，不同时机械循环。
- 情绪爆发前安排压抑或停顿，爆发后安排恢复。

## 8. 特效

- 先定义特效来源、形状、颜色和运动规则。
- 能量、魔法、速度线和粒子应跟随动作方向。
- 特效不能遮挡角色脸、手部或接触点。
- 同一世界使用统一符号和色彩逻辑。
- 变形和世界切换必须有中间过程与新稳定状态。

## 9. 背景与空间

- 角色脚底、地面和投影建立接触。
- 前中后景运动速度不同，形成视差。
- 风、雨、树叶、水面和烟雾遵守统一方向。
- 室内门窗、道路、建筑和道具位置跨镜保持连续。
- 大场景不只依赖背景图，角色运动要真正影响空间。

## 10. 光影色彩

- 青春/治愈：清透天空、暖逆光和自然绿色。
- 奇幻：主色明确，魔法光作为局部动态光源。
- 动作：高对比、清楚轮廓和短时爆点高光。
- 悬疑：冷灰、局部暗区和有限色彩提示。
- 末世：低饱和、尘埃、废墟材质和长距离空气透视。

## 11. 声音

- 对白、呼吸和动作拟音增强角色活人感。
- 动作音效需要起势、接触和反馈层级。
- 环境声建立世界材质。
- 音乐可更明确地组织情绪和动作，但不覆盖关键台词。

## 12. Prompt 实现骨架

```text
生成一段 [时长] 的 [动画媒介/题材] 视频。
角色锚点：[外貌、发型、服装、比例、配色和渲染规则]。
场景与世界规则：[空间、材质、环境运动和光源]。
时间轴：[角色动作、关键姿态、表情、镜头和结束状态]。
动画方式：[有限动画/常规动画/高动作，发丝与服装次级运动]。
特效：[来源、路线、反馈和消散]。
声音：[对白、动作音效、环境声和音乐节拍]。
限制：[角色不漂移、媒介不爬动、动作不跳、特效不遮挡主体]。
```

## 13. 常见失败

- 角色每帧像不同画师重画。
- 发型、服装和配色随动作改变。
- 只有头发和背景在动，人物像静态立绘。
- 动作夸张但没有关键姿态和重心。
- 速度线、粒子和镜头同时过载。
- 3D 动画运动过度丝滑、材质像塑料。
- 厚涂逐渐变成真人 / 3D，或笔触在皮肤上爬动。
- 速度线和模糊全程开着，接触点不可读。
- 背景与角色没有接触和视差。
