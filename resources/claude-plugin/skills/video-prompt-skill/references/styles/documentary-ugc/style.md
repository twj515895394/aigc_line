# Documentary And UGC Style

## 1. 定位

用于纪录片、手机拍摄、Vlog、采访、街头、Bodycam、CCTV、车载和真实记录感。核心是明确设备位置、保留真实环境证据和自然不完美，而不是用随机抖动模拟真实。

## 2. 核心结构

```text
真实拍摄来源 + 可理解的拍摄者位置 + 自然事件 + 有限镜头干预 + 环境声 + 可信曝光与运动
```

## 3. 设备来源

### 手机原相机

- 自动曝光和对焦可能轻微调整；
- 手持运动由拍摄者身体和动作产生；
- 构图允许轻微偏移，但主体仍可读；
- 适合日常、街头、朋友视角和突发记录。

### 微单/纪录摄影

- 曝光和焦点更稳定；
- 可使用轻手持、肩扛、固定或小范围跟拍；
- 适合采访、过程记录和环境观察。

### Bodycam/头戴设备

- 运动与身体同步；
- 视野较广，手和行动对象常进入画面；
- 适合行动、执法、救援和第一人称体验。

### CCTV/监控

- 固定高位或角落机位；
- 画面不主动跟随人物；
- 时间、空间和事件完整性比美观更重要。

### 车载/行车记录

- 固定朝向、玻璃反射、道路震动和速度变化；
- 环境声来自车内、发动机、路面和外部交通。

### GoPro/运动相机

- 超广角和主观速度；
- 画面运动与身体、车辆或装备绑定；
- 不使用脱离设备的漂浮环绕。

## 4. 镜头行为

- 固定机位：等待事件进入和离开画面。
- 轻手持：自然呼吸和姿态带来的小幅运动。
- 观察性跟拍：保持一定距离，不频繁抢到主体正面。
- 采访：稳定中近景，允许少量重构图和焦点调整。
- Vlog：人物与镜头有明确交流，走动和转向可影响构图。
- 突发记录：先捕捉事件，再调整构图，不从第一帧就完美对准。

## 5. 真实运动

- 拍摄者走路会产生上下和侧向轻微节奏。
- 停下时镜头有短暂惯性后稳定。
- 转身和抬手会改变视野，但不是机械周期摇晃。
- 变焦和对焦应由观察目标变化触发。
- 主体离开画面时，拍摄者可以延迟半拍再跟随。

## 6. 曝光与画质

- 室内外切换允许短暂曝光适应。
- 逆光时主体可略暗，但仍保留可读信息。
- 夜间有真实噪点、局部过曝和有限动态范围。
- 不要求每帧皮肤、背景和高光都完美。
- 画质限制应与设备一致，不把手机画面写成大型电影机质感。

## 7. 表演与人物

- 纪录人物不应持续看镜头，除非采访或 Vlog。
- 对话允许打断、犹豫、呼吸和环境干扰。
- 动作自然完成，不为镜头摆出过度完美姿态。
- 情绪由事件触发，反应可能延迟或不完整。
- 群体场景保留背景人物的非同步自然行为。

## 8. 声音

- 环境声优先：风、车、人群、房间、脚步和设备摩擦。
- 麦克风距离影响清晰度和空间感。
- 风噪、衣物摩擦和轻微爆音可以有限保留。
- 采访主声音清楚，但不把环境完全抹掉。
- BGM 少量使用，突发记录和监控通常不需要 BGM。

## 9. 子方向

### 生活 UGC

手机视角、朋友/同事/路人拍摄、自然动作、简单场景和生活化落点。

### 观察纪录片

中远距离跟拍、较长镜头、环境声和不干预的空间调度。

### 采访

稳定构图、自然眼神方向、少量切入环境和手部细节，声音清楚。

### 街头/旅行 Vlog

广角、边走边讲、地点环境证据、自然曝光变化和路线连续。

### 监控/证据影像

固定视角、完整时间和空间，事件从画面外进入，不做电影化运镜。

### Bodycam 行动

第一人称、呼吸、脚步、手部和设备交互，运动强但必须与身体绑定。

## 10. Prompt 实现骨架

```text
生成一段 [时长] 的 [纪录/UGC/设备记录] 视频。
拍摄来源：[手机/微单/Bodycam/CCTV/车载/GoPro]，拍摄者位置和身份明确。
场景事件：[真实地点、人物初始状态和唯一主事件]。
镜头行为：[固定/轻手持/观察跟拍/主观行动，运动由设备和拍摄者产生]。
人物表现：[自然动作、真实反应、是否看镜头]。
光线画质：[环境真实光源、曝光适应和设备限制]。
声音：[环境声、对白、设备与动作声，BGM 主次]。
限制：[无漂浮运镜、无精修海报感、无机械抖动、无无来源灯光变化]。
```

## 11. 常见失败

- 用持续规律抖动模拟手持。
- 镜头脱离拍摄设备在空中平滑环绕。
- 所有人都像演员一样看镜头和摆姿势。
- 手机画面拥有不合理的极浅景深和完美灯光。
- 环境声音被完全消除，空间失去真实感。
- CCTV 主动推近、拉焦和追踪人物。
- 突发事件开始前镜头已完美等待在最佳位置。
- 为“纪录感”故意降低到无法阅读的画质。
