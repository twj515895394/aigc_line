# Spatial Blocking Control

## 目标

建立人物、道具、镜头和环境之间可持续的空间关系，使动作有路线、互动有距离、跨镜不发生无理由瞬移。

本页负责站位、朝向、视线、前中后景、出入口和动线，不负责提供场景美术选项。

## 何时读取

- 多人物对话、对峙、追逐或互动；
- 人物与道具接触关系复杂；
- 跨镜头左右位置、朝向或距离频繁变化；
- 场景入口、出口和路线不清楚；
- 参考图只展示局部，但视频需要扩展空间；
- 镜头容易穿墙、穿人或无理由换侧。

## 空间最小模型

每段至少明确：

```text
空间原点 + 主体位置 + 朝向/视线 + 目标位置 + 行动路线 + 镜头位置
```

简单场景至少写出 **2–4 个有位置的周边物件** 和光的来源，避免只有地点名。

首帧或复杂场面不要压成两三个名词。改为继承可见**场景骨架**：

- 建筑和地面结构；
- 摊位、遮阳棚、桌椅、招牌、电线等固定物；
- 前中后景与可走空地；
- 围观人群形成的空圈或让位通道；
- 光源方向。

镜头横移时，这些层次应形成视差。环境可被撞击晃动、掉落纸片或水果，但要给破坏上限：轻微晃动可以，无因爆炸或整片坍塌不行。

复杂场景再补：

- 前景遮挡；
- 中景主行动区；
- 背景环境和出口；
- 固定道具；
- 可移动道具；
- 禁止进入区域。

## 站位设计

### 单人

明确：

- 人物在画面和场景中的位置；
- 面向镜头、侧向还是背向；
- 与桌、门、墙、车辆等参照物的距离；
- 下一步可向哪里移动。

### 双人

至少明确：

- A 与 B 的左右关系；
- 面对、并肩、前后还是斜向；
- 谁主动接近、谁保持位置；
- 两人之间是否存在桌面、门框或道具；
- 视线是否互相锁定。

### 多人

先确定层级：

- 当前视觉中心；
- 主关系组；
- 辅助人物的站位和反应；
- 群体是否形成包围、队列、散点或前后层次。

不要让所有人同时在同一平面做同等级动作。围观者保持在主行动区外，只让位和反应，不加入主动作。

## 动线规则

一条动作路线必须回答：

- 从哪里出发；
- 经过什么；
- 是否绕过障碍；
- 到哪里结束；
- 路线方向是否与镜头和上一镜一致。

人物移动时，应保留至少一个稳定参照物帮助观众确认位置变化。

## 出入口与空间扩展

视频需要扩展参考图之外的空间时：

- 先推断可见建筑和场景结构；
- 只补满足行动所需的最小空间；
- 明确门、走廊、窗、街道或开放区域的方向；
- 不凭空增加与参考图结构冲突的大空间；
- 场景变化必须通过移动、切镜或转场完成，不直接瞬移。

## 视线与朝向

视线是最稳定的空间线索之一：

- 写清人物看向谁或什么；
- 视线目标变化应先于或伴随头部转动；
- 正反打需要保持视线方向匹配；
- 人物离开画面时保持行进方向；
- 下一镜若反向出现，必须有空间过渡依据。

## 道具状态与位置

重要道具必须记录：

- 初始位置；
- 由谁持有；
- 哪只手或哪个接触面；
- 当前朝向和开合状态；
- 在哪一镜被移动；
- 移动后的落点。

不要让道具在镜间自动换手、消失、复原或跳到另一位置。

## 镜头与空间关系

镜头位置也属于 blocking：

- 镜头位于人物哪一侧；
- 是否被前景遮挡；
- 是否会穿过实体障碍；
- 移动路线是否与人物动线冲突；
- 是否保持 180 度轴线；
- 何时通过中性镜头或明显环绕跨轴。

## 场景层次

使用前中后景让空间更可信：

- 前景：门框、肩部、桌角、植物、人群等层次证据；
- 中景：主要人物和动作；
- 后景：环境结构、其他人物、入口和光源。

前景遮挡应服务观察位置和空间深度，不应长期挡住主动作。

## 高频失败与修复

### 人物瞬移

修复：补起点、路线、经过点和结束位置。

### 左右关系翻转

修复：保持轴线；需要跨轴时加入中性正面或明确环绕过渡。

### 互动够不到

修复：在动作前明确距离变化，让人物先进入可接触范围。

### 道具自动换手

修复：写清哪只手持有、何时交接、交接接触点和完成状态。

### 背景结构变化

修复：锁定门窗、墙面、桌椅和主光源位置，只允许镜头角度造成合理可见差异。

### 镜头穿越实体

修复：重新规划镜头路线，使用门口、通道、可见绕行或切镜，不要求镜头无理由穿墙穿人穿摊。

### 布景被压没

修复：从首帧或开场继承场景骨架，不把复杂集市 / 街道压成“一个背景”。

## 输出模板

```text
空间原点：
主体 A 位置/朝向：
主体 B 位置/朝向：
关键道具位置与状态：
前中后景关系：
行动路线：
镜头所在侧与运动路线：
入口/出口：
必须保持的空间关系：
禁止出现的空间变化：
```

## 输出前检查

- 人物站位和朝向是否明确；
- 接触动作的距离是否成立；
- 行动路线是否绕开障碍；
- 重要道具是否有连续状态；
- 视线和正反打是否匹配；
- 镜头是否会跨轴或穿越实体；
- 场景结构是否在跨镜中稳定；
- 下一镜是否继承上一镜的空间条件。
