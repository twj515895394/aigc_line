# Subject Motion Control

## 目标

把“人物、动物、物体或环境在动”拆成具有起点、方向、阶段、受力、反馈和结束状态的可执行运动。

本页负责主体如何运动以及运动是否可信，不负责选择具体运镜术语。

## 何时读取

- 用户只写“跑起来、打得很爽、自然转身、风吹动头发”等模糊动作；
- 动作复杂、容易跳帧或肢体重组；
- 动作缺少重量、惯性、接触和反馈；
- 主体动作与镜头运动互相争抢；
- 需要设计打斗、追逐、体育、舞蹈或产品运动。

## 基础运动结构

```text
初始状态 + 动作意图 + 起势 + 推进 + 关键接触/变化 + 反馈 + 恢复/落点
```

简单动作可缩减为：

```text
起点 → 过程 → 终点
```

## 决策顺序

### 1. 明确动作目标

先回答主体为什么动：

- 抵达某个位置；
- 获取或放下某个物体；
- 与另一个主体接触；
- 展示某个技能；
- 表达情绪；
- 响应环境变化。

没有目标的运动容易变成无意义摆动。

### 2. 锁定初始状态

至少明确：

- 身体或物体朝向；
- 重心或支撑点；
- 手脚、关节或接触面的起始位置；
- 与其他人物、道具、地面的距离；
- 当前速度是静止、缓慢还是已经运动。

### 3. 拆动作阶段

不要只写动作名称。以“转头”为例：

- 眼神先移动；
- 下颌和颈部开始转动；
- 肩线轻微跟随；
- 转到目标方向；
- 视线重新锁定并停住。

以“起身”为例：

- 双脚获得支撑；
- 上身前倾；
- 重心从座椅转移到脚掌；
- 髋膝伸展；
- 身体站稳并回正。

动作阶段越清楚，跨帧越不容易像重新生成。

## 重量与物理反馈

运动可信至少要考虑：

- 重心：力量从哪里开始，最后落到哪里；
- 惯性：加速和停止是否有过程；
- 接触：手、脚、物体是否真正碰到目标；
- 受力：被推动、击中或拉动的方向；
- 阻力：地面、空气、布料、水体或物体重量；
- 环境反馈：尘土、水花、衣摆、头发、物品晃动；
- 恢复：动作后是否重新获得平衡。

不要用大量粒子和运动模糊代替真实受力。

## 动作强度分级

### 微动作

- 呼吸；
- 眨眼；
- 眼神移动；
- 嘴角和下颌变化；
- 指尖、发丝、衣角轻动。

适合表演和生活化视频，是保持“活人感”的主要方式。

### 常规动作

- 转头；
- 抬手；
- 走几步；
- 拿起或放下物品；
- 坐下、起身、回头。

通常一段只安排一个主动作。

### 高强度动作

- 奔跑、跳跃、翻滚；
- 打斗、球类突破、舞蹈爆发；
- 车辆冲刺；
- 大幅环境破坏。

必须拆阶段，并减少同时发生的镜头复杂度。

## 动作戏结构

动作、打击和碰撞优先使用：

```text
蓄力 → 接触 → 反馈 → 恢复
```

必须明确：

- 攻击者或动作主体姿态；
- 接触点（嘴角、下颌、肋骨、前臂、支撑腿等具体部位，不是“打中对方”）；
- 受力方向（头、肩、髋沿力的方向转动或偏移）；
- 短暂停顿或速度变化；
- 被作用主体的身体、表情、头发、耳环或衣袖反馈；
- 环境反馈：尘土、纸片、摊位晃动、脚步刮地；给破坏上限；
- 动作后的落点。

只有“快速出拳、激烈打斗”而没有接触和反馈，通常只会得到混乱摆动。15 秒片段把这些写进每个主 Beat，不靠把片长加倍来堆细节。

## 主体运动与镜头运动协调

使用错峰原则：

- 主体动作复杂时，镜头优先固定、轻跟或短距离移动；
- 镜头大幅运动时，主体动作保持单纯且方向明确；
- 接触或爆点瞬间，镜头可短暂强化，但随后必须恢复可读性；
- 不让主体和镜头在不同方向同时高速变化。

## 多主体运动

多人互动必须先定义关系：

- 谁主动、谁响应；
- 两人的初始距离和朝向；
- 接触顺序；
- 视线目标；
- 哪个人是当前视觉主角；
- 另一人的动作属于主动作还是反馈。

避免把多人动作写成各自动作清单，导致空间关系丢失。

## 非人物主体

### 物体

明确旋转轴、移动轨迹、速度变化、碰撞面和停止方式。

### 动物

尊重物种运动逻辑，写支撑点、步态、尾部与身体平衡，不直接套人类动作。

### 环境

风、雨、水、烟、火、植物等要说明主方向、强度和与主体的互动，避免所有环境元素无规律运动。

## 常见失败与修复

- 动作跳跃：补起始、中段和完成状态；
- 身体漂浮：补支撑点、重心和地面反作用；
- 手穿过物体：补接触面、抓握顺序和物体重量；
- 打击无力：补蓄力、接触点、受力方向和反馈停顿；
- 动作太多：只保留一个主动作，其余降为微动作；
- 动作读不清：降低运镜强度和环境特效。

## 输出前检查

- 动作目标是否明确；
- 起始姿态和支撑点是否存在；
- 动作是否被拆成连续阶段；
- 接触和受力方向是否清楚；
- 环境是否有合理反馈；
- 动作完成后是否有恢复或落点；
- 镜头是否会遮蔽主体动作。
