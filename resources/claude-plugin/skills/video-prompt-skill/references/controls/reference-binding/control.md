# Reference Binding Control

## 目标

为图片、视频、音频和文字参考分配明确职责，处理同维度冲突、局部借用、保留强度和禁止继承，避免多素材被平均融合。

本页负责“每份素材提供什么”，不负责任何模型专属引用语法。

## 何时读取

- 用户提供多张图片、多个视频或音频；
- 同一人物、服装、场景或动作存在多个版本；
- 需要从视频借运镜、从图片借人物、从音频借节奏；
- 用户要求只参考某个局部或某种结构；
- 素材之间风格、构图、动作或身份冲突；
- 目标平台需要显式绑定素材职责，但绑定逻辑应先在通用层完成。

## 基本原则

```text
一份素材可以承担多个明确职责；
一个关键维度只能有一个主真源；
辅助素材只能补充，不得悄悄覆盖主真源。
```

禁止默认把多张脸、多套服装、多种场景和多种镜头风格平均融合。

## 素材职责类型

### 图片可提供

- 人物身份；
- 服装和配饰；
- 场景结构；
- 首帧、尾帧或关键帧；
- 道具外观；
- 构图、光影、色调和材质；
- 表情或姿态终态。

### 视频可提供

- 主体动作；
- 运镜；
- 节奏；
- 转场；
- 特效；
- 表演节拍；
- 空间调度；
- 声音、语气和口型参考。

### 音频可提供

- 台词内容；
- 音色和语气；
- BGM；
- 节拍；
- 环境音；
- 拟音结构。

### 文字可提供

- 用户最终目标；
- 必须保留和必须修改；
- 剧情与动作；
- 参考素材的职责说明；
- 禁止继承内容。

文字中的明确要求优先于系统对素材的自动推断。

## 绑定流程

### 1. 建立素材清单

为每份素材编号，并记录可见或可听信息。

### 2. 指定主参考

确定当前任务各维度的核心真源：

- 人物身份主参考；
- 主场景；
- 动态结构主参考；
- 音频节奏主参考。

不必强行选一份全局主参考，但每个关键维度必须有唯一主参考。

### 3. 分配辅助职责

辅助素材只补充明确维度，例如：

- 图 1：人物身份和发型；
- 图 2：服装；
- 图 3：场景与光影；
- 视频 1：动作节拍；
- 视频 2：运镜；
- 音频 1：BGM 和重拍。

### 4. 标记局部参考

必要时明确：

- 只参考人物面部；
- 只参考上衣，不参考姿势；
- 只参考某个时间段的运镜；
- 只参考音乐节拍，不参考原视频剧情；
- 只参考特效结构，不复制具体角色和场景。

### 5. 设定保留强度

可使用三级：

- 强保留：身份、产品外观、关键场景结构等不可漂移；
- 中等保留：服装、构图、光影、节奏等允许合理适配；
- 弱参考：只借气质、结构或方向，不要求逐项复现。

### 6. 写禁止继承

明确排除：

- 原素材人物身份；
- 原剧情；
- 原文字、水印或品牌；
- 不需要的服装、背景和道具；
- 与目标冲突的节奏、动作和镜头。

## 冲突裁决顺序

```text
用户明确要求
→ 必须保留/必须修改
→ 当前任务目标
→ 各维度主参考
→ 辅助参考
→ 自动补全
```

同维度冲突时：

- 不融合两个身份主参考；
- 不同时继承互斥服装；
- 不把首帧构图和另一张完全冲突的构图都设为强保留；
- 不同时复刻两段不同运动路线的视频；
- 选择最符合主目标的一份，其余降为局部参考或放弃。

## 首帧、尾帧和关键帧绑定

- 首帧定义起始画面和可运动条件；
- 尾帧定义目标落点，不自动说明如何到达；
- 关键帧定义中间必须经过的动作或构图；
- 多帧之间必须验证身份、空间、动作和物理可达性；
- 无法自然到达时，应调整动作或拆分片段，不强迫模型瞬变。

## 视频参考的结构借用

复刻视频时先决定借什么：

- 运镜轨迹；
- 动作编排；
- 节奏和镜头长度；
- 转场机制；
- 特效逻辑；
- 表演反应。

禁止一句“完全参考视频”覆盖所有维度，除非用户确实要求整体复现且素材兼容。

## 导演台参考层

导演台是可选的、段落级的素材职责，不是新的任务或风格。只有上下文把素材指向预演、白模/彩模代理、镜头规划或最终资产替换时，才启用本节；歧义时按普通素材处理。

导演台素材可以是以下任一种，也可以不存在：

- **导演台预演视频**：提供可观察的镜头路线、机位变化、空间调度、代理模型宏观动作、节奏和片尾状态；
- **导演台关键帧**：提供构图、机位状态、主体/代理物位置、朝向、比例关系、场景结构和目标状态；运动由剧本、上下文和最终 Prompt 设计。

两者偶然同时存在时分工绑定：预演视频负责动态，关键帧负责静态锚点；不得把两者平均融合。

### 导演台识别与强度

- 用户明确写“导演台、预演、分镜预演、白模预演或代理动画”时，直接按导演台处理；
- 用户描述“控制镜头/空间/代理模型动作，最后替换成真实资产”时，按导演台处理；
- 用户明确职责优先于自动判断；普通参考视频或图片不自动升级为导演台；
- 片段级导演台默认对应一个连续镜头。发现切镜时，按镜头边界拆成子段；
- 导演台强保留镜头、空间和宏观动作，但没有可靠元数据时不虚构精确焦段、坐标或速度数值，应根据实际画面、剧本需求和最终目标设计语义镜头；
- 预演视频中的声音默认不继承。对白、BGM、环境音和拟音由文字或独立音频决定。

### 代理替换合同

代理模型无论是白色、蓝色、灰色或其他颜色，默认只表示位置、比例、朝向、运动和空间关系，不表示最终颜色、材质、服装、身份或风格。

最终资产来源优先级为：明确视觉参考 → 用户文字/剧本 → 低风险自动补全。上下文足够时自动建立“代理物 → 最终角色/场景/道具”的映射；映射不得改变导演台的宏观路径和接点。最终 Prompt 细化动作时，可补充步态、手势、表演、重心和材质反馈，但不得覆盖导演台的宏观动作，除非用户明确要求覆盖。

默认加入条件性说明：

> 代理模型的颜色和预演材质不代表最终外观；只继承其位置、比例、朝向、运动路径、时间结构和空间关系。

### 片尾与跨段承接

每个导演台片段都生成片尾锁定：摄影机位置/高度/角度/朝向、透视关系、主体画面占比、主体位置/朝向/姿态、关键道具和环境物位置，以及下一段可继承的运动趋势。连续片段自动继承上一段片尾状态；新的明确首帧或导演台可覆盖它。

风格、色彩、材质和代理渲染方式默认不继承，由最终 Prompt、视觉参考或 style 层决定。最终对外内容放入“导演台参考约束”区块，内部映射表不直接展示。

## 常见失败与修复

### 平均融合

表现：人物像多张脸的混合，服装和场景都不准确。

修复：为每个维度指定唯一主参考，其余明确降级。

### 辅助参考覆盖主图

修复：写清辅助素材只借用的局部和禁止覆盖项。

### 动作视频带入原人物和场景

修复：明确只参考动作或运镜，不继承身份、服装和背景。

### 首尾帧不可达

修复：检查身体姿态、视角、空间和道具状态，增加关键帧或拆段。

### 音频和画面节奏冲突

修复：确定节奏主参考，重排视觉事件，不同时服从多个不同拍点。

### 参考信息过载

修复：删除对主目标无贡献的素材，优先保留身份、动作、场景和节奏四类核心证据。

```text
禁止继承：

```

## 输出前检查

- 每份素材是否有明确职责；
- 每个关键维度是否只有一个主真源；
- 局部参考范围是否清楚；
- 保留强度是否合理；
- 禁止继承是否覆盖明显干扰项；
- 首尾帧和动作参考是否物理兼容；
- 是否删除了无贡献素材；
- 模型专属语法是否留给适配层转换。
