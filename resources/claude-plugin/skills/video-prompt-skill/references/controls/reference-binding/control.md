# Reference Binding Control

## 目标

为图片、视频、音频和文字参考分配明确职责，处理同维度冲突、局部借用、保留强度和禁止继承，避免多素材被平均融合。

本页负责“每份素材提供什么”，不负责任何模型专属引用语法。

## 何时读取

- 用户提供多张图片、多个视频或音频；
- 同一人物、服装、场景或动作存在多个版本；
- 需要从视频借运镜、从图片借人物、从音频借节奏；
- 用户要求只参考某个局部或某种结构；
- 素材之间风格、构图、动作或身份冲突；
- 目标平台需要显式绑定素材职责，但绑定逻辑应先在通用层完成。

## 基本原则

```text
一份素材可以承担多个明确职责；
一个关键维度只能有一个主真源；
辅助素材只能补充，不得悄悄覆盖主真源。
```

禁止默认把多张脸、多套服装、多种场景和多种镜头风格平均融合。

## 素材职责类型

### 图片可提供

- 人物身份；
- 服装和配饰；
- 场景结构；
- 首帧、尾帧或关键帧；
- 道具外观；
- 构图、光影、色调和材质；
- 表情或姿态终态。

### 视频可提供

- 主体动作；
- 运镜；
- 节奏；
- 转场；
- 特效；
- 表演节拍；
- 空间调度；
- 声音、语气和口型参考。

### 音频可提供

- 台词内容；
- 音色和语气；
- BGM；
- 节拍；
- 环境音；
- 拟音结构。

### 文字可提供

- 用户最终目标；
- 必须保留和必须修改；
- 剧情与动作；
- 参考素材的职责说明；
- 禁止继承内容。

文字中的明确要求优先于系统对素材的自动推断。

## 绑定流程

### 1. 建立素材清单

为每份素材编号，并记录可见或可听信息。

### 2. 指定主参考

确定当前任务各维度的核心真源：

- 人物身份主参考；
- 主场景；
- 动态结构主参考；
- 音频节奏主参考。

不必强行选一份全局主参考，但每个关键维度必须有唯一主参考。

### 3. 分配辅助职责

辅助素材只补充明确维度，例如：

- 图 1：人物身份和发型；
- 图 2：服装；
- 图 3：场景与光影；
- 视频 1：动作节拍；
- 视频 2：运镜；
- 音频 1：BGM 和重拍。

### 4. 标记局部参考

必要时明确：

- 只参考人物面部；
- 只参考上衣，不参考姿势；
- 只参考某个时间段的运镜；
- 只参考音乐节拍，不参考原视频剧情；
- 只参考特效结构，不复制具体角色和场景。

### 5. 设定保留强度

可使用三级：

- 强保留：身份、产品外观、关键场景结构等不可漂移；
- 中等保留：服装、构图、光影、节奏等允许合理适配；
- 弱参考：只借气质、结构或方向，不要求逐项复现。

### 6. 写禁止继承

明确排除：

- 原素材人物身份；
- 原剧情；
- 原文字、水印或品牌；
- 不需要的服装、背景和道具；
- 与目标冲突的节奏、动作和镜头。

## 冲突裁决顺序

```text
用户明确要求
→ 必须保留/必须修改
→ 当前任务目标
→ 各维度主参考
→ 辅助参考
→ 自动补全
```

同维度冲突时：

- 不融合两个身份主参考；
- 不同时继承互斥服装；
- 不把首帧构图和另一张完全冲突的构图都设为强保留；
- 不同时复刻两段不同运动路线的视频；
- 选择最符合主目标的一份，其余降为局部参考或放弃。

## 首帧、尾帧和关键帧绑定

- 首帧定义起始画面和可运动条件；
- 尾帧定义目标落点，不自动说明如何到达；
- 关键帧定义中间必须经过的动作或构图；
- 多帧之间必须验证身份、空间、动作和物理可达性；
- 无法自然到达时，应调整动作或拆分片段，不强迫模型瞬变。

## 视频参考的结构借用

复刻视频时先决定借什么：

- 运镜轨迹；
- 动作编排；
- 节奏和镜头长度；
- 转场机制；
- 特效逻辑；
- 表演反应。

禁止一句“完全参考视频”覆盖所有维度，除非用户确实要求整体复现且素材兼容。

## 参考绑定表

复杂任务建议内部建立：

| 素材 | 类型 | 主职责 | 辅助职责 | 保留强度 | 禁止继承 | 冲突备注 |
|---|---|---|---|---|---|---|
| 参考1 | 图片 | 人物身份 | 发型 | 强 | 背景、姿势 |  |

对外输出可压缩成简洁职责说明。

## 常见失败与修复

### 平均融合

表现：人物像多张脸的混合，服装和场景都不准确。

修复：为每个维度指定唯一主参考，其余明确降级。

### 辅助参考覆盖主图

修复：写清辅助素材只借用的局部和禁止覆盖项。

### 动作视频带入原人物和场景

修复：明确只参考动作或运镜，不继承身份、服装和背景。

### 首尾帧不可达

修复：检查身体姿态、视角、空间和道具状态，增加关键帧或拆段。

### 音频和画面节奏冲突

修复：确定节奏主参考，重排视觉事件，不同时服从多个不同拍点。

### 参考信息过载

修复：删除对主目标无贡献的素材，优先保留身份、动作、场景和节奏四类核心证据。

## 通用输出模板

```text
素材职责：
- 参考 1：
- 参考 2：
- 参考 3：

各维度主真源：
人物身份：
服装：
场景：
动作：
运镜：
节奏/音频：

强保留：
允许适配：
禁止继承：
冲突裁决：
```

## 输出前检查

- 每份素材是否有明确职责；
- 每个关键维度是否只有一个主真源；
- 局部参考范围是否清楚；
- 保留强度是否合理；
- 禁止继承是否覆盖明显干扰项；
- 首尾帧和动作参考是否物理兼容；
- 是否删除了无贡献素材；
- 模型专属语法是否留给适配层转换。
