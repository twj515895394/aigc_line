# Audio Visual Sync Control

## 目标

把对白、旁白、环境音、拟音、BGM 和视觉事件组织成同一条时间线，使声音有来源、有空间、有进入和退出，并与动作和剪辑同步。

本页负责音画关系，不负责提供具体音乐曲风库，也不处理模型专属音频格式和数量限制。

## 何时读取

- 视频包含对白、旁白、音乐卡点或音效；
- 角色口型、语气和动作不同步；
- BGM 盖住对白或所有声音同时出现；
- 音效没有画面来源；
- 多镜头需要用声音桥接；
- 用户提供音频参考或要求按节拍生成。

## 声音分层

### 1. 语言层

- 对白；
- 旁白；
- 喊声、耳语、喘息等人声表演。

### 2. 环境层

- 风、雨、街道、办公室、室内混响；
- 人群、设备、交通和远处声音。

### 3. 动作拟音层

- 脚步；
- 衣料摩擦；
- 物体碰撞；
- 门、杯子、纸张、武器、车辆等声音。

### 4. 音乐层

- BGM；
- 节奏脉冲；
- 情绪铺底；
- 高潮和收尾音乐变化。

每层只保留当前叙事真正需要的内容，不把“有声音”理解为全层同时拉满。

## 决策顺序

1. 当前片段最重要的声音是什么；
2. 声音来自画内还是画外；
3. 何时进入、持续多久、何时退出；
4. 对应什么视觉事件；
5. 与对白、环境音和音乐是否竞争；
6. 下一镜是否需要声音延续。

## 音画事件绑定

每个关键声音应绑定可见事件：

```text
时间点 + 声音事件 + 视觉事件 + 强度 + 延续/衰减
```

例如：

```text
2.4s：球落地的清晰撞击声，对应篮球第一次重拍地面，短促有重量，随后快速衰减。
```

不要写“配合震撼音效”，而不说明声音对应什么。

## 对白控制

- 明确说话者；
- 台词长度与可用时间匹配；
- 定义语速、音量、情绪和能量；
- 说话前留吸气、反应或视线变化；
- 说话后留倾听和情绪落点；
- 多人对白写清先后，不默认同时说；
- 环境音和 BGM 在对白期间应适当让位。

## 口型与声音同步

- 口型只在说话时间段启动；
- 台词结束后嘴部动作停止；
- 说话时下颌和唇部动作自然、幅度有限；
- 呼吸、吞咽和停顿与语气一致；
- 不在高速运镜和复杂动作中安排过长精准对白；
- 无法保证精确口型时，优先旁白、背面镜头、侧脸或短句。

## BGM 与节拍控制

音乐卡点应先提取：

- 主拍；
- 重拍；
- 过门；
- 情绪上升点；
- 停顿或 drop；
- 结尾衰减。

视觉事件根据重要性绑定：

- 重拍：动作接触、切镜、姿态定格、产品出现；
- 过门：转场、镜头方向变化；
- 上升：动作加速或情绪递进；
- 停顿：凝视、悬念、爆点前蓄力；
- 收尾：动作完成和画面停住。

不要让每个拍点都切镜，优先绑定真正重要的视觉变化。

## 环境音与空间

声音要体现距离和空间：

- 近处声音更清楚、更有细节；
- 远处声音更弱、更模糊；
- 室内有适量混响；
- 室外声音更开放；
- 镜头进入房间、车辆或水下时，声音空间应逐步变化；
- 声源移出画面后可继续短暂存在，形成空间连续性。

## 拟音与物理反馈

拟音必须匹配：

- 材质；
- 接触强度；
- 速度；
- 距离；
- 环境混响；
- 画面中的实际接触时刻。

轻放杯子不应使用重击音，远处脚步也不应像贴近麦克风。

## 声音桥接

多镜头可使用声音帮助承接：

- 下一镜声音提前进入；
- 上一镜声音延续到下一镜；
- 同一环境底噪保持空间一致；
- 对白尾音跨切镜；
- 音乐连续但画面改变。

声音桥接不能掩盖空间或时间已经发生重大变化的事实。

## 优先级与混音逻辑

常规优先级：

```text
关键对白/叙事声音 > 关键动作拟音 > 环境证据 > BGM 装饰
```

音乐视频或无对白动作片可以调整优先级，但必须明确主声层。

## 常见失败与修复

### 对白被音乐覆盖

修复：对白期间降低 BGM 强度和频段存在感，减少无关环境声。

### 口型持续乱动

修复：明确台词起止时间，无对白阶段保持自然呼吸和闭口状态。

### 音效提前或滞后

修复：把声音绑定到具体接触帧或视觉事件，而不是整段描述。

### 声音过满

修复：确定主声层，删除不服务叙事的环境和拟音。

### 卡点像幻灯片

修复：不在每拍切镜，使用动作内部变化、速度变化和姿态落点响应节拍。

### 场景切换声音瞬断

修复：使用环境音衰减、声音桥或明确的声场转换。

## 输出模板

```text
主声层：
对白/旁白：
环境音：
动作拟音：
BGM 与节拍：
关键音画绑定点：
声音空间和距离：
进入、持续与退出：
跨镜声音桥：
需要避免的音画问题：
```

## 输出前检查

- 每个关键声音是否有来源；
- 声音是否绑定具体视觉事件；
- 对白长度是否适配时间；
- 口型起止是否明确；
- 主声层是否会被其他声音覆盖；
- 音乐卡点是否只使用关键拍；
- 拟音是否匹配材质和力度；
- 多镜头声场是否连续；
- 结尾声音是否有衰减或落点。

## 边界

- 表演、语气和对白停顿读取 `performance-expression/control.md`；
- 视觉节拍读取 `timeline-rhythm/control.md`；

- 模型是否支持原生音频、口型和输入格式读取 `models/`。
