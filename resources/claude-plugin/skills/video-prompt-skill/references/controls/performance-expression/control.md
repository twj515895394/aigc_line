# Performance And Expression Control

## 目标

把抽象情绪转成可见、连续、不过度的表演过程，控制眼神、眉眼、嘴角、呼吸、姿态、小动作、对白停顿和口型。

本页负责“角色怎样演”，不负责罗列表情名称，也不代替人物身份一致性控制。

## 何时读取

- 用户要求角色更有活人感、微表情或情绪递进；
- 人物像面瘫、表情包或一直保持同一夸张情绪；
- 对白和口型机械，缺少停顿与反应；
- 表情变化导致五官漂移；
- 写实短剧、漫剧、关系戏、情绪特写和角色反应镜头。

## 表演结构

```text
表演目标 + 注意对象 + 起始状态 + 内部变化 + 外部可见信号 + 停顿/反应 + 结束状态
```

不要只写“悲伤、愤怒、心动”。应把情绪翻译成局部变化。

## 表演决策顺序

1. 角色此刻想得到、隐藏或避免什么；
2. 角色注意力落在哪里；
3. 起始表情和身体状态是什么；
4. 什么事件触发变化；
5. 哪些局部信号最先出现；
6. 情绪是压住、释放还是伪装；
7. 最后停在哪个状态。

## 微表情优先级

### 眼神

眼神通常是主锚点：

- 看向谁或什么；
- 视线是否稳定、闪躲、下垂或重新抬起；
- 瞳孔和眼睑变化是否必要；
- 眼神变化发生在头部动作之前还是之后。

### 眉眼

用于表达压力、怀疑、克制和放松：

- 眉头轻压或抬起；
- 眉间短暂收紧；
- 眼尾泛红或放松；
- 眼皮半垂或睁大。

### 嘴角与下颌

用于表达忍耐、犹豫和情绪泄露：

- 嘴角轻微上扬、下压或单侧变化；
- 双唇抿紧或短暂张开；
- 下颌收紧、松开；
- 吞咽、轻咬下唇等动作仅在剧情需要时使用。

### 呼吸

呼吸决定节奏：

- 屏住；
- 轻吸一口气；
- 呼吸变快；
- 说完后慢慢呼出；
- 身体起伏与情绪同步。

### 小动作

用于增加活人感，但只能服务情绪：

- 手指收紧或松开；
- 整理衣角；
- 轻触杯沿；
- 肩膀微缩或放松；
- 身体轻微后退、前倾或回正。

## 情绪变化过程

表演应有起点和变化，不直接跳到终态。

示例：从镇定到不安：

```text
保持礼貌注视 → 视线短暂移开 → 眉间轻收 → 呼吸停半拍 → 手指收紧 → 再次看向对方但嘴角不再上扬
```

示例：从惊讶到害羞：

```text
瞳孔放大和动作停住 → 视线相遇 → 迅速低头 → 耳侧和面颊轻微泛红 → 呼吸变浅 → 再次小心抬眼
```

## 强度控制

### 克制表演

- 使用 1 个主信号 + 1-2 个辅助信号；
- 允许停顿；
- 情绪变化幅度小；
- 适合写实短剧和关系戏。

### 明确表演

- 眼神、眉眼、嘴角和姿态共同变化；
- 仍保留顺序，避免全部同时发生；
- 适合动画、漫剧和明确剧情反应。

### 高强度表演

- 哭泣、暴怒、恐惧或崩溃需要身体、声音和呼吸共同参与；
- 高潮之前必须有积累；
- 高潮之后需要疲惫、停顿或恢复；
- 不让每个镜头都处于最高强度。

## 对白表演

对白不只是文字内容，还需要：

- 说话前的吸气、犹豫或视线；
- 语速、音量、能量和情绪；
- 句间自然停顿；
- 说话时身体和手部是否继续动作；
- 说完后的倾听或反应；
- 对方是否在合适时机回应。

避免多人同时说话，除非剧情明确要求重叠对白。

## 口型控制

- 台词尽量短，符合片段时长；
- 明确谁说哪一句；
- 说话期间嘴部动作自然，不持续夸张张合；
- 无对白时嘴巴保持自然闭合或符合呼吸状态；
- 口型变化不应改变唇形、下颌和整张脸的身份比例；
- 台词前后保留 0.2-0.5 秒的反应空间，具体按节奏调整。

## 表演与镜头关系

- 微表情：固定镜头、慢推近、中近景或特写；
- 双人拉扯：过肩、中近景和反打；
- 高强度动作：先保证身体动作，面部表演只保留可读主信号；
- 告别和隐忍：后撤、长焦旁观或动作完成后的停顿；
- 不在大幅环绕和高速动作中要求复杂口型与细微眼神同时精准完成。

## 画外驱动 → 画内后果

主动作在画外、镜头只留脸 / 肩 / 局部时，表演链必须把看不见的动作读出来：

```text
画外原因（一句，不写裁掉的器官）
→ 最先泄露的局部（眼睑 / 下颌 / 鼻翼）
→ 呼吸与肩线起伏
→ 锁线内可见的身体浮动或乳沟轻颤
→ 1-2 秒峰值
→ 软掉 / 余波
```

- 禁止只写情绪标签或「只写反应、不写动作」；
- 也禁止把画框外的手、胸、下体写进画面；
- 高强度峰值是事件不是全程状态：前面必须有忍住，后面必须留余波。

## 面部一致性保护

表情变化只修改相关局部：

- 愤怒：眉头压低、鼻翼轻张、下颌收紧；
- 害怕：眼睑打开、肩膀后缩、呼吸停住；
- 委屈：眼尾泛红、嘴角下压、视线移开；
- 冷漠：眼皮半垂、嘴角拉平、回答前停顿；
- 开心：眼睛轻弯、嘴角上扬、脸部肌肉放松。

不要用“脸变得更加……”推动表演，以免模型重塑身份。

## 常见失败与修复

### 面瘫

修复：增加眼神落点、呼吸和一个局部变化，而不是直接提高情绪强度。

### 表情用力过猛

修复：减少同时变化的面部区域，让情绪按顺序泄露。

### 情绪跳变

修复：补触发事件和中间反应，例如停顿、视线变化或吸气。

### 口型机械

修复：缩短台词，减少嘴部幅度，加入说话前后停顿和倾听反应。

### 表情导致变脸

修复：降低表情幅度，锁定脸部识别锚点，只改变相关肌肉。

### 每镜都强情绪

修复：建立情绪曲线，安排中性状态、积累、爆发和恢复。

## 输出模板

```text
表演目标：
注意对象：
起始状态：
触发事件：
眼神变化：
眉眼/嘴角/下颌变化：
呼吸与小动作：
对白与停顿：
结束状态：
表演强度：
面部一致性限制：
```

## 输出前检查

- 情绪是否被翻译为可见信号；
- 眼神是否有明确目标；
- 变化是否有触发和顺序；
- 微表情数量是否过多；
- 对白长度是否适配时间；
- 说话者、倾听者和反应时机是否清楚；
- 表情是否会改变身份比例；
- 结尾是否有表演落点。
