# 导演级运镜术语选择器

## 定位

本页来自导演级运镜术语资料的二次精读，服务 [[文生视频Prompt结构]]、[[图生视频Prompt结构]]、[[故事版分镜到视频流程]] 和 [[AI视频风格选择器]]。

## 运镜 Prompt 基础结构

```text
景别 + 机位角度 + 镜头运动 + 运动速度 + 主体动作 + 环境变化 + 情绪目标
```

## 五组术语怎么用

- 先定层级：景别镜头决定观众离人物多近，运动镜头决定镜头怎么走，情绪镜头决定观众怎么感受，动作镜头决定力量和冲击怎么落地。
- 同名术语会在不同组里重复出现，例如 `主观镜头` 既是景别/视角选择，也是运动组织方式；使用时按当前任务取其一层含义即可。
- 一个 Prompt 通常只放 1 个主运镜，再搭配 1 个景别或 1 个情绪目标，不要把 3 组术语同时硬堆进去。

## 叙事与定格镜头

| 镜头 | 主要作用 | 适配情节 |
|---|---|---|
| 推镜头 | 逐步靠近主体，压缩环境信息 | 觉醒、发现线索、情绪递进 |
| 拉镜头 | 后撤揭示环境和关系 | 结局揭晓、疏离、命运展开 |
| 摇镜头 | 横向浏览场景与人物关系 | 空间展示、多人对话、环境铺陈 |
| 移镜头 | 平行移动跟随节奏 | 行走、过程展示、日常叙事 |
| 跟镜头 | 持续跟随主体运动 | 追逐、主观行动、任务执行 |
| 升降镜头 | 改变视角层级与空间维度 | 登场、场面揭示、权力关系 |
| 俯拍定格 | 高角度静止构图 | 群像调度、孤立、场景总结 |
| 特写定格 | 锁定表情、物件或象征细节 | 情绪爆点、关键道具、结尾余韵 |

## 使用规则

- 先选情绪目标，再选景别和主运镜，不要先堆术语。
- 动作戏优先从 `动作镜头 + 运动镜头` 里各选 1 个主项，再补景别。
- 悬疑戏优先用窥视视角、推近压迫、拉焦转移、慢摇预兆、悬停审视。
- 情绪戏优先用中近景、特写、后撤疏离、长焦抽离、空镜余韵。
- 群像和空间戏优先用全景、远景、鸟瞰、摇镜头、长镜头调度、交叉穿行。
- 一个镜头 Prompt 中通常只放一个主运镜，最多再搭配一个焦点变化或一个速度变化。
