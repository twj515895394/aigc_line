# 故事版分镜到视频流程

## 定位

用于把分镜图、首帧图、角色图、场景图转换成视频 Prompt。它连接 [[分镜资产与image2故事版]]、[[图生视频Prompt结构]] 和 [[文生视频Prompt结构]]。

## 总流程

```text
目标剧情 -> 分镜拆解 -> 资产生成 -> 图像识别 -> 视频 Prompt -> 结果检查 -> 迭代
```

## 步骤

| 步骤 | 产物 | 检查重点 |
|---|---|---|
| 目标剧情 | 一句话目标 | 这一段视频要表达什么 |
| 分镜拆解 | 镜号、景别、动作、情绪 | 每镜只承担一个核心变化 |
| 资产生成 | 角色图、场景图、首帧图、分镜图 | 锚点是否稳定 |
| 图像识别 | 主体、场景、光影、可运动元素 | 是否抓住图像关键 |
| 视频 Prompt | 主体运动、镜头运动、节奏、限制 | 是否可执行 |
| 结果检查 | 变脸、跳帧、动作、构图 | 找出失败原因 |
| 迭代 | 修改变量 | 一次只改关键变量 |

## 首帧图到视频

1. 识别首帧主体、构图、光影和风格。
2. 判断画面里哪些元素可以运动。
3. 写主体运动和镜头运动。
4. 保持首帧锚点，不让模型新增无关内容。

## 分镜图到视频

1. 每张分镜只对应一个动作阶段。
2. 相邻分镜要明确承接关系。
3. 动作复杂时使用 [[打击帧与动作戏结构]] 拆解。
4. 镜头顺序按“远景交代、中景建立、近景推进、特写锁定”组织。

## 与文生视频的关系

- 有图像参考时，走 [[图生视频Prompt结构]]。
- 没有图像参考时，走 [[文生视频Prompt结构]]，先用文字建立首帧，再写时间轴。
