# AI 视频风格选择器

## 定位

本页来自 43 种 AI 视频风格资料的二次精读。它不鼓励堆风格名，而是把风格拆成“观看位置”和“画面气质”两层，供 [[文生视频Prompt结构]]、[[图生视频Prompt结构]]、[[电影感Prompt拆解公式]] 和 [[视角机位与景别选择器]] 调用。如果还没确定作品像哪类片，先看 [[影视风格选择器]]；本页负责把题材气质落到设备与观看位置。

## 选择顺序

1. 先定观看位置：观众是跟随、旁观、俯视、窥视、主观参与，还是被某种设备记录。
2. 再定媒介来源：电影机、手持、GoPro、FPV、Bodycam、CCTV、红外、热成像、X 光、玻璃反射、鱼眼等。
3. 再定作者气质：孤独、压迫、童话、治愈、黑色幽默、冷峻秩序、科幻奇观等。
4. 最后写镜头和画面变量：景别、机位、运动、光影、色彩、材质、节奏。

## 组合规则

- 设备风格解决“画面来自哪里”，作者气质解决“画面留下什么感受”。
- 一条视频通常只选 1 个设备风格 + 1 个作者气质，避免互相抵消。
- 写实短剧优先选择手持、固定机位、长焦、玻璃反射、冷调悬疑等可落地风格。
- 动作/运动优先选择 GoPro、FPV、广角、快速剪辑、Bodycam。
- 情绪短片优先选择长镜头、慢镜头、玻璃反射、王家卫式孤独、李安式克制。
- 科幻/实验优先选择红外、热成像、X 光、雷德利·斯科特式科幻。

## 写法模板

```text
视频风格：[设备/媒介风格] + [作者气质]
观看位置：[观众是跟随、窥视、俯视、主观参与或设备记录]
镜头语言：[景别、机位、运动、速度]
画面气质：[光影、色彩、材质、空间]
适用情绪：[紧张、孤独、治愈、压迫、奇观、真实]
限制：[不要堆叠多个互斥风格，不要只写导演名]
```
