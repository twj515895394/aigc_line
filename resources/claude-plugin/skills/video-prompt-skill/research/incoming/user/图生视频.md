# 图生视频

## 定位

图生视频把图片资产转成时间轴运动。优先引用 [[图生视频Prompt结构]]、[[图像风格提取流程]]、[[分镜资产与image2故事版]]、[[导演级运镜术语选择器]] 和 [[故事版分镜到视频流程]]。

- 动作戏：[[打击帧与动作戏结构]]

## 处理流程

1. 判断输入图类型：首帧、尾帧、分镜、角色图或场景图。
2. 提取主体、场景、光影、风格和可运动元素。
3. 写主体运动与镜头运动。
4. 设置时长、节奏、光影延续和质量限制。
5. 检查变脸、闪烁、跳帧、肢体畸形和新增无关元素。

## 常见失败模式

- 直接写运动，不先识别图片。
- 主体运动和镜头运动过多。
- 没有说明保持首帧光影和角色锚点。
- 动作复杂但没有分镜拆解。
