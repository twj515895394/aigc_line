# 图生视频 Prompt 结构

## 定位

图生视频从图片资产出发，先识别图像，再写运动。它连接 [[图像风格提取流程]]、[[分镜资产与image2故事版]] 和 [[故事版分镜到视频流程]]。

## 输入图类型

| 图片类型 | 识别重点 | Prompt 重点 |
|---|---|---|
| 首帧图 | 主体、构图、光影、可运动元素 | 从当前画面自然开始运动 |
| 尾帧图 | 目标姿态、落点、情绪结果 | 规划运动抵达方式 |
| 分镜图 | 镜号、动作阶段、镜头关系 | 保持镜间承接 |
| 角色图 | 外貌锚点、服装、表情 | 防止变脸 |
| 场景图 | 空间、道具、动线、光影 | 保持空间可信 |

## Prompt 结构

```text
图像识别结果 + 主体运动 + 镜头运动 + 时间节奏 + 光影延续 + 风格延续 + 质量限制
```

## 变量表

| 变量 | 写法重点 |
|---|---|
| 图像识别结果 | 不重复描述所有细节，只抓主体、场景、构图、光线 |
| 主体运动 | 人物动作、表情变化、衣物/头发/道具运动 |
| 镜头运动 | 推、拉、摇、移、跟、环绕、手持感 |
| 时间节奏 | 2 秒、4 秒、8 秒；慢动作、停顿、加速 |
| 光影延续 | 保持原图光源方向与色调 |
| 风格延续 | 保持摄影、动画或电影风格 |
| 质量限制 | 不变脸、不跳帧、不畸形、不新增无关主体 |

## 输出模板

```text
基于参考图，保持 [主体锚点、场景、光影、风格]。
[主体] 在 [时长] 内 [动作变化]，
镜头 [运动方式]，从 [起始景别/机位] 到 [结束景别/机位]。
保持 [色调/景深/材质]，
避免 [变脸/肢体畸形/画面闪烁/新增元素]。
```

## 检查表

- 是否先识别参考图，再写运动。
- 是否区分主体运动和镜头运动。
- 是否保留首帧或角色锚点。
- 是否写清时长和节奏。
- 是否避免让模型同时完成过多动作。
