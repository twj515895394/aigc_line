# 写实电影短剧

## 定位

写实电影短剧的重点是可信场景、清晰镜头、光影色调和连续表演。优先引用 [[电影感Prompt拆解公式]]、[[视角机位与景别选择器]]、[[导演级运镜术语选择器]]、[[AI视频风格选择器]]、[[电影光影与色调选择器]] 和 [[文生视频Prompt结构]]。

## 常用入口

- Prompt 公式：[[电影感Prompt拆解公式]]
- 镜头参数：[[视角机位与景别选择器]]
- 运镜术语：[[导演级运镜术语选择器]]
- 影视气质：[[影视风格选择器]]
- 视频风格：[[AI视频风格选择器]]
- 光影色调：[[电影光影与色调选择器]]
- 文生视频：[[文生视频Prompt结构]]
- 图生视频：[[图生视频Prompt结构]]

## 推荐组合

- 家庭关系戏：[[影视风格选择器]] 的“家庭克制现实” + 暖黄怀旧或纪录片自然色调 + 固定机位或轻手持。
- 都市夜戏：都市孤独现实模板 + [[AI视频风格选择器]] 的玻璃反射 / 长焦压缩 + 都市夜景电影色调。
- 悬疑调查戏：冷蓝悬疑感 + 低角度仰拍或窥视视角 + 明暗对比光。

## 短剧镜头顺序

1. 远景或全景交代场景和人物位置。
2. 中景建立人物关系。
3. 近景推进情绪。
4. 特写锁定证据或情绪爆点。
5. 结尾镜头留出情绪停顿。

## 质量检查

- 是否有清楚的镜头顺序。
- 光影和色调是否与剧情情绪一致。
- 角色是否在连续镜头中保持一致。
- 是否避免把“电影感”当成万能词。
