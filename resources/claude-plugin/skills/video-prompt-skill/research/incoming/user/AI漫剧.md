## 推荐组合

- 权谋 / 登场戏：[[影视风格选择器]] 的“权力史诗与仪式” + [[AI视频风格选择器]] 的低角度仰拍 / 对称构图 + [[电影光影与色调选择器]] 的黑金或冷蓝方向。
- 废墟 / 末世戏：[[影视风格选择器]] 的“废墟哲思与末世诗意” + 长镜头或高角度俯拍 + 冷灰、灰黄或丁达尔光。
- 打斗 / 对峙戏：群像戏剧模板 + [[导演级运镜术语选择器]] 的对峙、推近、停顿镜 + [[打击帧与动作戏结构]]。

## 题材工作流

1. 先做角色说明书，锁定外貌、服装、气质和表情范围。
2. 再做场景资产和空间站位。
3. 用故事版拆镜，每一镜只承载一个动作或情绪变化。
4. 对动作戏使用蓄力、接触、反馈、恢复。
5. 图生视频时保留角色锚点和场景锚点。
