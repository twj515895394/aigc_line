# 打击帧与动作戏结构

## 定位

用于 AI 漫剧、动作戏分镜、图生视频动作拆解和打斗画面。它连接 [[分镜资产与image2故事版]]、[[图生视频Prompt结构]] 和 [[AI漫剧]]。

## 动作戏基础结构

```text
蓄力 + 接触 + 反馈 + 恢复
```

| 阶段 | 写什么 | 视觉重点 |
|---|---|---|
| 蓄力 | 出拳前的身体扭转、重心后移、眼神锁定 | 让力量有来源 |
| 接触 | 拳脚或武器触碰目标的一瞬间 | 打击点、压缩、冲击线 |
| 反馈 | 被击中的身体、表情、衣物、环境反应 | 受力方向、停顿、变形 |
| 恢复 | 动作后的落点、喘息、重心回收 | 节奏收束 |

## 打击帧字段

```text
动作目标：
攻击者姿态：
受击者姿态：
接触点：
受力方向：
停顿感：
环境反馈：
镜头位置：
画面速度感：
```

## 动作戏检查表

- 是否写出接触点，而不是只写“打得很快”。
- 是否有受击反馈，包含身体、表情、衣物或环境。
- 是否有停顿帧，让观众感到力量。
- 是否有重心变化，避免动作像飘在空中。
- 镜头是否配合动作，例如低机位、近景、倾斜构图、运动模糊。

## 常见失败模式

- 只有动作名，没有物理反馈。
- 攻击者和受击者空间关系不清。
- 镜头太远，爽点看不见。
- 同一帧塞太多动作，模型无法稳定生成。
