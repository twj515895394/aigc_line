# 文生视频 Prompt 结构

## 定位

文生视频没有参考图，必须用文字先建立画面、运动和时间轴。它连接 [[基础Prompt结构]]、[[电影感Prompt拆解公式]] 和 [[故事版分镜到视频流程]]。

## Prompt 结构

```text
主题目标 + 场景世界 + 主体动作 + 镜头调度 + 时间轴变化 + 光影色调 + 风格质量限制
```

## 时间轴写法

| 段落 | 内容 | 作用 |
|---|---|---|
| 开始 | 主体初始状态、场景建立、第一镜头 | 让模型知道从哪里开始 |
| 中段 | 动作变化、镜头运动、关系变化 | 形成叙事推进 |
| 结尾 | 动作落点、情绪结果、画面停留 | 让视频有收束 |

## 模板

```text
生成一段 [时长] 的 [题材/风格] 视频。
场景：[地点、时间、天气、空间关系]。
主体：[人物/物体/群像]，初始状态为 [状态]。
时间轴：
0-[x] 秒：[建立画面与第一动作]。
[x]-[y] 秒：[动作变化与镜头运动]。
[y]-结束：[动作落点与情绪收束]。
镜头：[景别、机位、焦段、运动方式]。
光影色调：[光源、阴影、高光、色调]。
限制：[不变脸、不跳帧、不畸形、不出现文字水印]。
```

## 与图生视频的差异

| 项目 | 文生视频 | 图生视频 |
|---|---|---|
| 输入 | 纯文字目标 | 图片或分镜参考 |
| 难点 | 建立初始画面 | 保持参考图一致 |
| 关键字段 | 场景世界、时间轴、镜头调度 | 图像识别、锚点延续、运动方式 |

## 常见失败模式

- 没有时间轴，导致动作混乱。
- 只有故事梗概，没有可视化镜头。
- 镜头运动和主体运动同时过猛。
- 风格词堆叠太多，缺少光影和色调约束。
