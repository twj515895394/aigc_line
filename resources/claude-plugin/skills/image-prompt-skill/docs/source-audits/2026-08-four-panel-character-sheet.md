## 用户确认后的最终结构

默认四区角色身份参考板采用：

```text
1920 × 1080，16:9
2 个纵向 Body Panel + 2 个横向 Close-up Face Panel
22% + 22% + 56%
右侧 56% 上下 50% / 50%
```

四区职责：

1. 第一列：正面全身 Body Panel，唯一需要去掉头部的区域；必须无头、无脸、无头发。
2. 第二列：完整背面全身 Body Panel；必须包含后脑、头部和发型后部，但人物严格背对镜头，不得露脸。
3. 右上：3/4 中性表情 Close-up，Primary Identity Anchor。
4. 右下：同机位、同光线、同造型的自然微笑 Close-up，Expression Anchor。

这一结构是本次用户明确确认后的规则，优先于前序草稿中“前两列都无头”的错误版本。
