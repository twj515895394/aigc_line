# 角色资产 Playbook

## 用途

生成可复用、可延续、可用于多场景和多镜头的角色资产，而不是只做一张漂亮成片。

## 何时读取

适用于角色设定图、三视图、多角度头像、表情板、姿态板、换装板、四区角色身份参考板、手部鞋履饰品道具细节、游戏角色资产和角色主视觉。

## 核心目标

先锁定角色识别，再扩展可变资产。

```text
身份锚点
→ 外貌锚点
→ 轮廓与比例
→ 发型、服装和配色
→ 固定道具
→ 可变表情、姿态和换装
→ 特殊剧情状态
→ 一致性限制
```

## 固定项

至少判断：

- 年龄感、身份和常态气质；
- 脸型、眼距、眼型、鼻唇比例、下颌和耳位；
- 发际线、分线、发型主轮廓和发色；
- 头身比、肩胯关系、体型和四肢比例；
- 主服装轮廓、长度关系和核心配色；
- 标志性饰品、伤疤、痣或固定道具。

详细固定方法读取 `../../controls/identity-consistency/character-identity-anchors.md`。

写实真人角色还必须读取 `../../controls/realism-quality/anti-ai-realism.md`，把皮肤按纹理、高光位置、质感基调、轻微不完美和光线分开写。不要只写「真实皮肤」。

## 可变项

- 表情和表情强度；
- 姿态、动作和重心；
- 换装与临时配饰；
- 场景和镜头；
- 局部妆面强度；
- 光影和色调；
- 战损、淋雨、疲惫等剧情状态。

固定项和可变项必须明确分开。

## 写实真人必须叠加皮肤真实感

角色资产默认先锁身份和版式。只要当前角色是写实真人，皮肤真实感就不是可选项，必须写入 Prompt。

满足任一条件即判定为写实真人：

- 用户明确要求写实、真人、照片质感、photoreal 或真实人像；
- 参考图是真人照片、写实摄影或写实三维人像；
- 参考图可见真实皮肤、毛孔、摄影高光，而不是平涂、线稿或赛璐璐。

不要判定为写实、也不要加载皮肤五变量的情况：

- 用户明确要求动漫、插画、像素、Q 版、厚涂、赛璐璐或其他 stylized 媒介；
- 用户明确要求瓷肌、玻璃肤、美颜磨皮或低频美容皮。

风格未写明、又没有真人参考图时，不要擅自改成写真；按用户已给的媒介或最小风险默认值执行。

写实真人角色资产读取：

```text
identity-consistency
+ anti-ai-realism
```

这已经用满默认 2 个 control 额度。不要再为了皮肤另读 `../../controls/realism-quality/fidelity-detail-enhancement.md`。那一页只用于已有成片、构图光线都不变、只补微观纹理的局部编辑。

生成四区板、三视图、头像或表情板时，应用方式：

- 右侧 Close-up、多角度头像、表情板近景：把皮肤当主体，五个变量都写到位置上；
- 正面无头全身、背面全身、三视图远景身体：只保留半哑光基调和轻微质感，不要全铺同等密度毛孔；
- 颈、手、手臂入画时，必须和脸同一套光、同一套质感，不能比脸更干净、更磨皮；
- 同一张资产板或同一套资产包里，皮肤逻辑必须一致，不能中性格半哑光、微笑格全脸水光；
- 四区板可以继续用中性背景和统一棚拍光，但棚拍不得变成美颜磨皮、全脸油膜或陶瓷蜡像。

不要把角色设计图误判成「同一张照片的保真增强」。从一张人物照片做出四区板，是新的资产生成，身份锁定后仍要按生成向皮肤规则重写各区，而不是只给原图加毛孔。

## 推荐资产包

按需要选择，不要求每次全部生成：

1. 中性背景角色识别主图；
2. 四区角色身份参考板；
3. 正、侧、背三视图；
4. 4–6 张多角度头像；
5. 基础表情组；
6. 常用姿态和习惯性小动作；
7. 全身中性站姿；
8. 手部、鞋履、饰品和固定道具细节；
9. 换装组；
10. 特殊状态或剧情状态；
11. 场景化角色主视觉。

## 默认角色设计图：三大版面、四个功能区

当用户要求“角色设计图”“角色参考板”“character sheet”“四区设定图”，或希望用一张简单人物参考图建立稳定角色身份时，优先使用下面的结构。

这里要区分两个层级：**版面层面是 3 个主版面/纵向列，功能层面是 4 个区域**。左侧两个主版面分别承载正面与背面全身；右侧第三个主版面再上下分成两个面部特写区。两个表情不是两个角色，也不是额外增加一套全身图，而是同一身份的两种面部参考。

这类参考板的目标不是简单展示更多角度，而是把不同视觉信息分配给职责明确的面板：正面身体与服装、背面完整轮廓与后脑发型、中性脸部身份、微笑表情身份。避免让正面远景中的低细节小脸参与人物身份定义，同时保留背面完整头部信息用于后脑、发型和整体背影轮廓。

### 默认画布与版式

默认采用：

```text
画布：1920 × 1080，横屏 16:9
结构：2 个纵向 Body Panel + 2 个横向 Close-up Face Panel
横向宽度：22% + 22% + 56%
右侧 56% 区域：上下 50% / 50% 等分
```

推荐视觉结构：

```text
┌──────────┬──────────┬──────────────────────────┐
│          │          │                          │
│          │          │   Neutral Close-up       │
│ FRONT    │ BACK     │   Primary Identity       │
│ BODY     │ BODY     │   Anchor                 │
│ 22%      │ 22%      │                          │
│          │          ├──────────────────────────┤
│ 无头无脸 │ 完整后脑 │                          │
│          │ + 全背身 │   Smile Close-up         │
│          │          │   Expression Anchor      │
│          │          │                          │
└──────────┴──────────┴──────────────────────────┘
                         56%，上下各 50%
```

在 1920 × 1080 画布中，可近似理解为：

- 第 1 列约 422 px；
- 第 2 列约 422 px；
- 右侧人脸区约 1076 px；
- 右侧上下两格各约 540 px 高。

像素值允许因排版边线和模型输出略有浮动，核心约束是保持 `22% + 22% + 56%` 的视觉权重与右侧上下等分。

除非用户明确要求其他版式，否则四区角色身份参考板默认使用这一布局，不默认使用 2×2。

### 四个区域的固定职责

#### 第 1 区：正面 Body Panel，22%

**正面身体 / 服装参考，必须无头、无脸。**

- 角色自然直立，展示正面身体从颈部截断位置到双脚的完整比例；
- 头部在颈部位置完整移除；
- 不出现头顶、头发、脸部、五官或残留半张脸；
- 重点展示肩宽、胸腰胯比例、四肢长度、手部、服装正面结构、衣长关系、配饰和鞋履；
- 这一格不得承担任何正面脸部身份信息。

#### 第 2 区：背面 Body Panel，22%

**完整背面全身参考，必须包含后脑。**

- 展示同一角色从后脑、头部、颈部、背部一直到双脚的完整背面全身；
- 必须保留后脑、发型后部、发髻 / 辫子 / 马尾 / 后部轮廓等可见信息；
- 清楚展示肩背比例、服装背面结构、后部剪裁、衣摆、配饰后视关系和鞋履；
- 人物保持严格背对镜头，不转头，不露正脸或侧脸，不出现眼睛、鼻子、嘴等脸部身份信息；
- 这一格负责“完整背影 + 后脑发型 + 服装背面”，不是第二个人脸参考。

第 2 区保留头部的原因是：后脑发型、发量轮廓、发髻、辫子和头颈衔接属于角色背影资产的重要信息，同时严格背面对镜头不会引入一张低分辨率正面小脸与高清 Close-up 竞争身份。

#### 第 3 区：右上 Neutral Close-up

**3/4 视角中性表情大特写，Primary Identity Anchor。**

- 采用大尺寸胸像或肩部以上特写；
- 默认 3/4 视角，保持自然闭嘴中性表情；
- 清楚呈现脸型、眉眼、眼距、鼻梁鼻翼、鼻唇比例、唇形、下颌、耳位、肤色、发际线与发型；
- 保留适量颈部、肩线与服装领口，使脸部与角色造型建立联系；
- 这一格是最主要、最清晰的人脸身份来源。

#### 第 4 区：右下 Smile Close-up

**与第 3 区对应的微笑大特写，Smile / Expression Anchor。**

- 必须是与第 3 区完全相同的人；
- 尽量保持相同 3/4 朝向、人物尺寸、相机高度、焦段感、光线、背景、发型、妆容、服装领口和肩部位置；
- 主要变量只改变表情；
- 默认自然微笑，可轻微露齿；
- 用于稳定微笑时的唇形、嘴角宽度、牙齿可见程度、脸颊上提、法令纹和眼周变化；
- 不允许因为微笑导致脸型、五官比例或人物身份改变。

### 分区职责

```text
第 1 区：FRONT BODY / OUTFIT REFERENCE
正面身体与服装；无头、无脸。

第 2 区：BACK BODY + REAR HEAD REFERENCE
完整背面全身；包含后脑和发型后部；严格不露脸。

第 3 区：NEUTRAL IDENTITY ANCHOR
负责“这个人是谁”。

第 4 区：SMILE EXPRESSION ANCHOR
负责“这个人笑起来是什么样”。
```

不要让第 1 区重新出现远景正面小脸，也不要让第 2 区转头露出脸部。正面人脸身份应集中由右侧高清 Close-up 提供。

### 单张简单参考图输入

当用户只提供一张简单人物参考图时，把该图视为人物身份主参考，而不是要求它必须已经包含完整四区信息。

- 优先锁定参考图中真实可见的脸型、五官比例、肤色、发际线、发型、年龄感与常态气质；
- 如果可见全身或大部分服装，继续锁定体型、服装轮廓、长度关系、配色和鞋履；
- 如果参考图能看到后脑或发型后部，应把这些信息优先继承到第 2 区；
- 如果参考图没有展示背面和后脑，只做与已见发型、服装和身体结构一致的最小延续，不把推断写成“参考图中原本就有”；
- 如果参考图只有头像而没有服装信息，快速模式使用简洁、中性、低识别冲突的稳定服装补全；用户已指定服装时以用户描述为准；
- 如果用户明确要求先确认或共同设计，进入交互模式后优先确认最影响角色识别的缺失信息，而不是让用户填写长表。

### 无参考图、纯文字输入

当没有参考图时，角色身份必须由文字锚点建立。至少需要形成：

```text
年龄感与性别表达
+ 脸型与关键五官比例
+ 发型 / 发色 / 发际线 / 后脑发型结构
+ 身高感、体型与身体比例
+ 主服装轮廓、长度关系与配色
+ 常态气质
```

快速模式缺少部分信息时，使用稳定、可延续、不过度设定的最小风险默认值直接补全，不中断交付。

交互模式中如果用户明确要求“可以先问我”“一起设计”“需要确认再生成”，每次只确认一个高影响变量，推荐顺序：

```text
年龄感与身份气质
→ 脸型与最关键五官
→ 发型、发色与后脑结构
→ 身高感、体型与比例
→ 主服装与配色
```

用户要求直接出结果时立即停止追问。

### 四区 Prompt 组装顺序

```text
任务目标与同一角色声明
→ 参考来源与身份优先级
→ 1920×1080、16:9、22% + 22% + 56% 固定布局
→ 右侧 56% 上下 50/50 等分
→ 第 1 区：正面无头无脸 Body Panel
→ 第 2 区：完整背面全身 + 后脑 Rear Head Panel，严格不露脸
→ 第 3 区：中性 3/4 大特写 Primary Identity Anchor
→ 第 4 区：微笑 3/4 大特写 Expression Anchor
→ 跨区固定项
→ 中性背景与统一棚拍光线
→ 写实真人时：Close-up 皮肤五变量 + Body Panel 可见皮肤与脸同一套光
→ 关键失败限制
```

关键限制只围绕高风险问题：第 1 区不得出现头部、脸或头发；第 2 区不得缺失后脑，也不得转头露出正脸 / 侧脸；右侧两区不得变成不同人物；微笑不得导致嘴型、牙齿或脸部比例漂移；四区不得出现额外角色或不一致服装。

## 游戏角色资产交付

当角色用于游戏、动画、贴纸、UI 或建模时，先读取 `../../libraries/composition-shot/game-asset-presentation-types.md`，选择：

- 角色设定板；
- 剪影探索板；
- 表情 / 贴纸表；
- Sprite Sheet；
- 2D / 3D 转换对照；
- 载具或武器资产板；
- 宣传 Key Visual。

资产板与 Key Visual 不应混为一张：

- 资产板优先身份、比例、结构和可复用信息；
- Key Visual 优先宣传冲击、动作和世界观；
- 角色身份未稳定时，不先做强透视、强光效的主视觉；
- 网格型资产必须固定行列、单元格、基线和精确数量。

## 推荐出图顺序

先验证中性主图或四区角色身份参考板，再做三视图和头像；身份稳定后才进入表情、姿态、换装、Sprite 和场景化主视觉。不要从强光影或强场景主视觉开始定义角色。

## 输出形态重点

### 四区角色身份参考板

默认使用 1920 × 1080 横屏：左侧两个纵向 Body Panel 分别占约 22% 和 22%，右侧约 56% 区域上下等分为两个横向 Close-up Face Panel。第 1 区正面无头无脸负责正面身体与服装；第 2 区完整背面全身包含后脑，负责背影、后脑发型和服装背面；右上中性 Close-up 负责主要身份；右下微笑 Close-up 负责表情身份。

### 三视图

锁定比例、轮廓、服装结构、正侧背对应关系和中性站姿。

### 多角度头像

锁定脸部稳定区、发际线、眼距、鼻唇关系和耳位；角度变化不能变脸。

### 表情板

明确稳定区、可变化区域和强度；优先克制或明显表情，不让每格都爆发。

### 换装板

保持人物身份、发型主锚点、体型和气质；只改变服装、材质、配色与配饰。

### 姿态板

保持骨架比例，补重心、习惯动作和角色性格；姿态变化不能改变体型。

### Sprite Sheet

固定画布尺寸、脚底基线、朝向、角色占比、动作帧顺序和每帧输入输出状态；像素媒介下按需读取 `../../styles/illustration/pixel-art-visual-language.md`。

### 细节资产

手部、鞋履、饰品、固定武器或工具必须与主图的结构和配色对应。

## 常见失败与修复

- 第 1 区仍出现头或小脸：强化“正面 Body Panel 在颈部结束，完整移除头部、头发和所有脸部五官”；
- 第 2 区被错误做成无头背身：明确“完整背面全身，从后脑到鞋底全部入镜，必须显示后脑与发型后部”；
- 第 2 区转头露出侧脸或正脸：固定严格背对镜头，只允许后脑、耳后轮廓和发型背面，不显示眼、鼻、嘴；
- 版式退化成 2×2：重复声明 1920 × 1080、两个 22% 纵向 Body Panel、右侧 56% 上下等分两个横向 Face Panel；
- 中性脸和微笑脸像两个人：固定机位、焦段感、光线、发型和脸部一级锚点，只允许表情变化；
- 一微笑就换嘴：增加唇形、牙齿可见程度、嘴角和面部肌肉变化约束，降低夸张表情强度；
- 单张头像参考被擅自补成复杂服装：回退到简洁中性服装，或在交互模式确认主服装；
- 多角度变脸：补脸部稳定区，降低表情强度；
- 换装像换人：把人物身份和服装变量分开；
- 三视图比例不一致：固定头身比、肩胯和服装长度关系；
- 资产包只出脸：回补全身、手部、鞋履和道具；
- 角色依赖场景氛围：先在中性背景验证身份；
- 发型变化导致身份漂移：保留发际线、发色或其他强锚点；
- Sprite 帧基线漂移：固定单元格、脚底基线、朝向和动作阶段；
- 游戏资产被做成普通宣传图：重新选择交付类型；
- 特殊状态覆盖原身份：战损、湿发和妆面变化只能叠加，不能替换核心识别特征；
- 写实四区板只写「真实皮肤」或变成磨皮陶瓷脸：读取 `../../controls/realism-quality/anti-ai-realism.md`，Close-up 拆开高光与纹理，Body Panel 的颈和手不得比脸更光滑；
- 把写实角色设计图做成原图保真增强：回到本 Playbook，按四区重新生成资产，而不是只给原图补毛孔；
- 动漫或像素角色被误加真人毛孔：确认媒介后删除皮肤五变量。
