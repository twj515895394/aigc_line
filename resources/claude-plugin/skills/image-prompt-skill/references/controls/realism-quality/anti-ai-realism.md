# 去 AI 感与真实照片控制

## 用途

当用户要求“看不出是 AI”“像真实照片”“像手机或相机真实拍出来”时，用具体拍摄关系、真实材质和合理不完美压制合成感、摆拍感和商业精修感。

近景人像还要把皮肤拆开写：纹理、高光位置、质感基调、轻微不完美和光线不能绑成一个「真实皮肤」。

## 何时读取

- 真人或生活场景需要真实照片感
- 用户明确反感塑料皮、假景深、过度精修
- 从文字或整体改写生成近景、中近景人像，需要自然皮肤而不是美颜磨皮
- 写实真人的角色设计图、四区参考板、三视图、头像或表情板
- 图生图需要把棚拍、网红写真改为自然纪实
- 办公室、街头、家庭等普通空间需要可信感

不要在以下情况把本页当成皮肤编辑页：

- 已有成片只补微观纹理、不重新设计 → `fidelity-detail-enhancement.md`
- 用户明确要求瓷肌、玻璃肤、低频美容皮或美颜磨皮
- 动漫、插画、像素、Q 版等 stylized 角色资产

## 核心规则

真实感不是反复堆 `photorealistic`，而是以下关系同时成立：

- 拍摄者确实能站在那个位置
- 光线有明确且可信的来源
- 皮肤、布料和环境材质保留自然纹理
- 构图允许轻微但合理的不完美
- 场景存在真实使用痕迹和空间层次
- 主体像处在事件中，而不是专门配合镜头摆姿势

## 静态图片的四维检查

静态图片写实不是“全局完美”或“全局不完美”的开关，而是四个维度同时可解释：

| 维度 | 检查重点 | 不能替代它的伪修复 |
|---|---|---|
| 结构与因果 | 人体比例、动作、重心、接触；物体比例、装配和落点 | 毛孔、噪点或背景杂物 |
| 光学与拍摄 | 拍摄者位置、透视、焦点、曝光和景深；景深由观看距离、焦段与前后景关系决定 | 全局滤镜或统一虚化 |
| 材质与反射 | 皮肤、头发、布料、金属、玻璃如何响应同一套光线 | 统一颗粒或全局锐化 |
| 语境与使用 | 空间用途、使用痕迹、人与环境的关系和事件是否成立 | 随机脏旧或堆叠道具 |

修复时优先处理结构与光线，再处理材质，最后才补受控不完美。某一维的问题不能靠另一维的细节替代。

## 任务语境与理想化边界

- 生活纪实、朋友或同事视角：允许轻微偏心、裁切、遮挡、动作未完成和少量材质痕迹，但仍保留第一视觉落点。
- 商业人像、产品广告：可以洁净、对称和精致；不要为了“真实”强行加入污渍、随机褶皱或废片式缺陷，但光线、比例、接触和材质仍需可信。
- 写实 CGI：可以理想化和展示性更强，但反射、遮挡、装配、尺度和落地关系不能违背物理直觉。
- 用户明确要求无瑕皮肤、美颜或特定商业修饰时，遵循该目标；不要把生活纪实的不完美强加给互斥任务。

## 景别、材质与成像层级

- 远景和全身：优先轮廓、重心、空间和光线，只保留轻微整体质感，不铺同等密度的毛孔或微纹理。
- 中景和半身：补皮肤基调、头发层次、衣物拉力褶皱、物体接触和环境证据。
- 近景和特写：才把皮肤五变量、发丝、唇纹、反射边界或物体微结构写到具体位置。
- 高清不等于全局锐利；保持主体清楚、细节有层级、边缘自然过渡。皮肤纹理属于材质层，颗粒和噪点属于成像层，不能互相冒充。
- 物体和环境的使用痕迹必须能由材质、动作、重力或用途解释；产品洁净时不额外旧化。

## 优先控制变量

### 拍摄来源

根据场景明确：

- 手机随手记录
- 会拍照的人用手机抓拍
- 微单自然抓拍
- 同事、朋友、同行者或路人视角

“谁在什么位置拍”比单写“纪实感”更有效。

### 真实材质

优先补：

- 皮肤按五个变量分开写，不要只写「真实皮肤」
- 布料自然褶皱、拉力和穿着痕迹
- 普通环境反射
- 真实空气感和前中后景层次

### 合理不完美

合理不完美必须有来源，例如拍摄者站位、动作阶段、现场光线、材质反应或实际使用过程。每张图只选 1–2 个最有价值的证据，不把随机瑕疵堆成素材包。

允许：

- 主体略偏画面一侧
- 轻微裁切或前景遮挡
- 背景不完全干净但信息可控
- 普通顶灯、窗光或环境反射造成的色温差

真实不等于故意降低画质，也不等于杂乱无重点。

## 生成时的皮肤控制

只写「真实皮肤」「高清皮肤」或「8K 毛孔」时，模型常见的理解是：脸要更干净、更均匀、更像精修照片。结果往往是一边加毛孔，一边继续磨皮，再给整张脸铺一层均匀亮膜。细节变多了，真实感却没有出现。

真实皮肤最重要的不是全脸都清晰，而是不同位置有不同状态。

### 五个控制点

毛孔只占其中一项。脸假时不要第一反应继续加毛孔。

| 变量 | 需要写清什么 | 最常见翻车 |
|---|---|---|
| 纹理 | 毛孔、细小绒毛、轻微凹凸；鼻翼和眼周密度不同 | 只写「真实」，或全脸同一层颗粒 |
| 高光位置 | T 区有克制皮脂高光，脸颊、下颌、眼周更哑 | 全脸统一水光，或全脸死哑无体积 |
| 质感基调 | 半哑光或克制缎光 | 过度磨皮、塑料高光、陶瓷脸 |
| 轻微不完美 | 少量泛红、浅纹、小痣或不对称，只选 1–2 项 | 追求绝对无瑕，或把瑕疵当素材包叠满 |
| 光线 | 受光面、暗部和阴影过渡与环境同一套光 | 均匀柔光把整张脸打平 |

默认最小结构：

```text
纹理 + 高光位置 + 半哑光基调 + 轻微不完美 + 合理光线
```

### 什么时候写细，什么时候少写

- 面部近景、中近景、肩部特写：把皮肤当主体写，五个变量都要落到位置上
- 全身、远景、小脸：只保留基调和轻微质感，不要铺同等密度毛孔
- 手、颈、手臂入画时，必须和脸同一套光，不能比脸更干净
- 同一组图里，皮肤逻辑保持一致；不要一张半哑光、一张全脸水光、一张完全死哑

### 正面先写清楚

先告诉模型哪些细节该出现、哪里该亮、哪里该哑：

```text
皮肤为 [半哑光 / 克制缎光]，不过度平滑。
T 区（额头、鼻梁、鼻尖）只有轻微皮脂高光；脸颊、下颌和眼周更哑，高光不连成一片。
鼻翼可见细微毛孔，眼下只保留极浅纹理；允许 [少量泛红 / 浅纹 / 轻微不对称] 其中一两项。
脸和环境使用同一套光线，受光面和暗部有过渡。
```

直闪、机顶闪光或 CCD 快照还要补高光边界：闪光可以强，但不能把额头、鼻梁、脸颊和嘴唇打成同一种亮度。高光只落在 T 区和真实受光面，脸颊与下颌保留层次。

微瑕疵只用于松开过度完美，不是把脸做脏。雀斑、痘印、毛孔、泛红、黑眼圈不要一次性全写。

### 负面约束后补

第一轮如果已经把高光和纹理分开，不必先堆负面词。仍出现油膜、蜡像、全脸湿亮或继续磨皮时，再针对性补 2–4 组：

- 不要塑料皮 / 蜡像 / 陶瓷感
- 不要全脸连续湿亮或油膜
- 不要过度磨皮
- 不要全脸统一毛孔或砂纸贴图
- 直闪场景再加：不要被闪光打平、不要闪光造成的假光滑

负面词只负责收翻车，不能代替正面把位置写清楚。

### 出图仍假时的检查顺序

1. 先看高光：额头、鼻梁、鼻尖、脸颊是否全部一起亮。是，就把高光收回 T 区和真实受光面。
2. 再看光线：有没有明确受光面和暗部。没有，就补光线方向和阴影过渡。
3. 最后看纹理：毛孔太少，和全脸铺同一种毛孔，改法完全不同。不要继续追加「超真实」。

很多时候改对高光位置和光线关系，不必再堆皮肤词。

### 不要和成像颗粒绑死

近景如果已经在写真实毛孔、绒毛和浅纹，就不要再叠「胶片颗粒、噪点颗粒、胶片质感」作为皮肤真实感来源。二者叠加后，人像容易碎、脏、像双重纹理。颗粒属于成像层，皮肤属于材质层，分开控制。

## 更稳的 Prompt 写法

不要只写：

```text
photorealistic, masterpiece, 8k, perfect skin
```

普通生活场景优先写：

```text
像真实工作日中被同事用手机顺手记录的瞬间，非摆拍，主体没有刻意正对镜头，普通环境光形成自然明暗差，构图略有偏移但可信，背景保留真实使用痕迹，不过度磨皮，不过度虚化
```

面部近景再补皮肤句，而不是把「真实皮肤」塞进质量词堆：

```text
皮肤半哑光，T 区只有轻微皮脂高光，脸颊和下颌更哑；鼻翼有细微毛孔，眼下纹理更浅，允许少量自然泛红，高光不连成一片
```

## 慎用词

以下词容易把普通真实场景推向合成、海报或商业精修：

- masterpiece
- best quality
- ultra detailed
- 8k
- unreal engine
- perfect skin
- flawless face
- cinematic masterpiece
- award-winning photography
- 真实皮肤（单独使用时）
- 高清皮肤 / 8K 毛孔 / 超真实皮肤

不是绝对禁止，而是不能依赖这些词建立真实感。

## 负向约束

只选择当前最危险的 2–4 组：

- no AI look
- no CGI
- no plastic skin
- no beauty filter
- no over-retouching
- no glamour studio shot
- no ad-like composition
- no fake bokeh
- no wax texture

近景人像优先针对当前翻车补：全脸油膜、陶瓷蜡像、统一毛孔贴图或被闪光打平。

## 常见失败与修复

- 把真实理解成低清：恢复清楚主体，只保留自然纹理和曝光差
- 负向词很多但画面仍假：补拍摄者站位、动作阶段和环境证据
- 抓拍变成偷窥：改成同事、朋友或同行者的合理在场视角
- 纪实变成废片：保留第一视觉落点，不让不完美压过主体
- 只写「真实皮肤」更油、更滑：拆开五个变量，先收高光范围
- 毛孔有了但仍像塑料面具贴皮：高光和纹理分开，禁止全脸连续亮膜
- 全脸死哑没有体积：恢复 T 区克制高光和受光面，不要把所有高光压掉
- 微瑕疵把脸做脏：只留 1–2 项，删掉素材包式堆叠
- 远景也写满毛孔：降低皮肤权重，只保留与景别匹配的轻微质感
- 手背比脸更光滑：把手和脸写进同一套光和同一套质感
- 皮肤词和胶片颗粒互相打架：先写材质，颗粒只作为成像层，必要时去掉一层

## 校验

删除所有质量大词后，主体、场景、镜头、光线和材质仍然像一张现实中能够拍到的照片，才算控制成立。

近景人像再多查一项：把「真实皮肤」删掉以后，高光落点、区域纹理和半哑光基调是否仍写在具体位置上。
