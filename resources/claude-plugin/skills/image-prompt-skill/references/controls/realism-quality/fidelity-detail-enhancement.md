# 保真细节增强控制

## 解决什么问题

当一张图的人物、构图、光影和氛围已经成立，只是皮肤被磨平、发蜡、发塑料，或缺少高分辨率下应有的微观起伏时，把任务定义成“同一张照片的质感增强”，而不是重新生成一个相似的人。

只写“真实皮肤”或“增加毛孔”不够。模型可能一边加毛孔、一边继续磨皮，或给整张脸贴上一层密度均匀的颗粒。必须同时说清：允许增加什么、必须锁定什么、明确排除什么。

## 什么时候读取

- 用户提供已有成片，要求补皮肤纹理、去磨皮、去塑料感、保真增强、超清细节重绘，且其他内容保持不变；
- Midjourney 或其他模型出的人像构图和光影可用，但放大后额头、面颊、颈部过于光滑；
- 需要把静帧作为视频风格锚点，但皮肤微观细节撑不住近景；
- 局部编辑的唯一目标是提高皮肤、唇部或可见肌肤的真实微观细节和有效分辨率。

不要在以下情况读取：

- 从文字重新生成一张真人照片，或需要把皮肤拆成纹理 / 高光 / 基调来写 → `anti-ai-realism.md`；
- 允许换场景、换构图、换光影或整体风格 → `../../tasks/image-to-image/playbook.md`；
- 用户明确要求瓷肌、美颜磨皮、玻璃肤或低频平整美容皮；
- 只替换物体、改文字或增删元素，皮肤不是编辑目标。

## 核心规则或选择结构

先判断原图是否已经“大结构成立”。成立的标志是：人物身份可读、构图成立、光影方向清楚、场景可辨。这时不要建议重新抽卡，也不要改走整体图生图。

### 三件事必须同时写清

```text
允许增加：
细小毛孔、极细汗毛、轻微肌理起伏、克制的肤色变化、自然唇纹

严格锁定：
人物身份、脸型五官、眼神表情、年龄气质、妆容肤色、发型走向、身体姿态、服装、背景、构图裁切、透视景深、焦点、光影边界、曝光白平衡、色彩关系

明确排除：
油光 / 水光 / 湿润膜、塑料感 / 蜡像感、继续磨皮、夸张锐化 / HDR、锐化光晕、重复毛孔、纹理贴图感、统一颗粒、人为新增雀斑痣瑕疵、换脸美颜、重新布光、改变构图、添加新物体或文字
```

### 目标隐喻

最终效果应像同一张照片拿到了更高质量的原始底片扫描或高像素母版，而不是另一张相似的新照片。

### 只改皮肤责任区

优先指定需要增强的皮肤区域，例如脸部、颈部、以及入画的手臂或手背。不要把全身、背景、布料和空气都写成同一套高频纹理。

允许头发、眼睛、睫毛、嘴唇和服装恢复原本应有的精细度，但不能改变形态或材质。

### 高光与纹理分开锁

- 保持原图已有高光的位置、面积和强度；
- 皮肤维持原图的半哑光、自然缎光或现有反射，不另加一层油膜；
- T 区只保留原图已经存在的克制高光，不要把脸颊、下颌和眼周连成连续亮面；
- 毛孔密度不能全脸均匀；鼻翼、面颊可有轻微凹凸，眼周和嘴角附近过渡更平滑；
- 手如果入画，必须和脸使用同一套光，不能比脸更干净。

近景把皮肤当主体写；远景或全身中小脸不要堆同等密度的毛孔描述。

### 强度选择

不同编辑模型对同一合同的执行强度不同。不要把某个模型名写成必选参数。按用户目标选择强度：

| 强度 | 适用 | 写法要点 |
|---|---|---|
| 克制 | 需要保留原图柔和感 | 浅纹理、低绒毛可见度、高光完全沿用原图 |
| 标准 | 接近高像素摄影 | 面颊、额头、下颌纹理清楚，但仍低调、不粗糙 |
| 强微观 | 需要明显汗毛和肌理 | 提高局部绒毛和毛孔可见度，同时更严地锁定高光与身份 |

用户未指定时，默认使用标准强度，并保持半哑光、不新增油光。

## Prompt 结构或执行方法

```text
基于附件原图做保真细节增强。这是同一张图的质感增强，不是重新生成、重新拍摄或重新设计人物。

只提升 [脸部 / 颈部 / 可见手臂等皮肤区域] 的真实微观细节和有效分辨率。
自然补回细小毛孔、极细汗毛、轻微肌理起伏、克制肤色变化和自然唇纹。
纹理必须细腻、低调、符合高分辨率真实摄影，不能变成粗糙颗粒、重复毛孔或皮肤贴图。

保持原图已有的高光位置、面积和强度，皮肤维持 [半哑光 / 自然缎光 / 原图现有反射]。
完整保留现有光影边界、曝光、白平衡和色彩关系。

严格锁定人物身份、五官比例、眼神表情、年龄气质、妆容、发型、姿态、服装、背景、构图、裁切、透视、景深和焦点。

允许恢复头发、眼睛、睫毛、嘴唇和服装原本应有的精细度，但不能改变形态或材质。
不要使用夸张清晰度、HDR、锐化描边或局部对比度拉爆。

禁止换脸、美颜瘦脸、眼睛放大、鼻唇重塑、美白、改妆、改发型、改衣服、改背景、重新布光、改变色调、改变构图，以及添加文字、Logo、水印或新物体。

输出该模型可用的最高原生分辨率，保持原图画幅和完全相同的画面内容。
最终应像同一张照片的高像素母版，而不是另一张相似人像。
```

方括号内容根据原图替换。不确定时，保留“原图现有状态”，不要发明新的光型或妆面。

原图如果有明确光影事件，例如窗光切过脸颊、直闪落在鼻梁或逆光勾出发缘，必须把这条光影边界写成锁定项，而不是只写“光线不变”。

## 常见失败与修复

- 只写“真实皮肤 / 增加毛孔”：补齐允许项、锁定项和排除项，把高光与纹理分开
- 加了毛孔但整张脸更油、更滑：锁定原高光，明确半哑光，禁止油光、水光和继续磨皮
- 全脸密度一样，像贴了一层皮：按区域写毛孔密度，眼周和嘴角不要与鼻翼同等高频
- 变成另一个相似的人：重复锁定脸型、五官、发型走向、表情和光影边界
- 构图或光线被重做：显式锁定裁切、人物位置、阴影形状和原有成片质感
- 过度锐化、描边、HDR：禁止清晰度滤镜、锐化光晕和局部对比度增强
- 远景也写满毛孔：降低皮肤权重，只保留与景别匹配的轻微质感
- 手背比脸更光滑：把手和脸写进同一皮肤责任区，共用同一套光
