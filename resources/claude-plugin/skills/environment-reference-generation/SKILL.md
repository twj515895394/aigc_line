# 场景参考图生成

为每个不同 `sceneId` 创建一张可被多个视频片段复用的四宫格空间参考图，四格属于同一场景版本，作为一个 `image` 节点和一张参考图片使用。场景参考图服务于空间、材质、光线和行动路线连续性，不直接充当成片构图。

## 输入与归并

先取得场景清单、成片画幅、统一视觉风格和图片工作流。每个场景档案至少包括：

- 地点、时代、用途、空间尺度、层高和主要结构；
- 正面主墙面或主要入口，以及以正面视图为基准的左侧、右侧和背面方位；室外场景以主要建筑立面或核心地标确定正面；
- 出入口、窗、走廊、楼梯、人物行动路线和关键视线；
- 固定家具、关键道具、墙地顶材质及磨损状态；
- 时间、天气、主光方向、色温、实用光源和阴影关系；
- 剧情阶段造成的布置、污染、湿润、损坏或灯光变化。

同一地点只有在布局、时间、天气、灯光或破坏状态发生可见变化时才新建版本。外观相同的场次复用同一个 `sceneId` 和节点。

## 画面规范

- 一张图只表现一个场景版本，整体画幅与成片一致，采用 2×2 等尺寸四宫格。按从左到右、从上到下固定排列：
  - 左上 **Front View（正面视图）**：正对场景主墙面，展示主要空间特征或入口。
  - 右上 **Left View（左侧视图）**：从场景左侧向内部观察。
  - 左下 **Right View（右侧视图）**：从场景右侧向内部观察。
  - 右下 **Back View（背面视图）**：朝正面视图的反方向观察，展示背面墙或背面的环境。
- 先确定正面朝向，再固定其余三个方位；左右指以正面视图为基准的场景侧位，不是把正面图水平翻转或裁切。四格使用一致的平视相机高度和相近视野，以真实透视展示四个方向，不使用高机位俯视或垂直鸟瞰。
- 四个视角共同交代出入口、行动通道、固定家具、关键道具和空间分区；让人物将来从哪里进入、移动、停留和离开一目了然。
- 四格必须是同一空间的不同观察方向，布局、物件位置、尺度、材质、时间、天气和灯光状态一致；主光方向按场景空间固定，投影随视角自然变化，不得为每格重新布置家具、门窗或光源。
- 保持真实透视、立面和纵深，不使用等距插画、剖面图、建筑蓝图或二维户型图。
- 场景中不得出现人物、人体局部、人形模特、镜中人或可辨识角色；普通环境陈设可以保留。
- 不生成文字、标签、尺寸线、水印、Logo 或装饰边框；四格清晰分区，不增加额外视图。视图名称和顺序写入提示词，不要求图片内渲染标签。

## 创建与生成

1. 调用 `GetCanvasCapabilities`，选择真实可用的文生图工作流，不猜测 `workflowId`。
2. 为去重后的每个场景版本创建一个 `image` 节点，标题使用 `场景｜状态版本｜无人四宫格环境图`，prompt 使用中文。
3. 在 prompt 中写明四宫格排列、正面方位和各视角可见内容，以及空间结构、出入口、行动路线、固定物、材质、时间天气、主光方向和禁止项；不要把人物动作或视频运镜塞进场景图。
4. 汇总待生成节点、sceneId、工作流和中文提示词摘要，明确询问是否开始生成。只有用户明确同意后才能调用 `InvokeNodeAction(generate)`。
5. 等待全部节点离开 `generating`，读取实际图片并检查：是否无人、是否为顺序正确的 2×2 正面/左侧/右侧/背面四宫格、四个方向是否可区分且没有重复或镜像冒充、空间是否完整可读、立面和纵深是否真实，以及四格布局/材质/光线是否彼此一致且符合档案。
6. 不合格时只修改受影响节点；说明原因和重做范围，重新取得明确确认后再生成。
7. 若由生产 Skill 调用，返回 `sceneId → nodeId → sourcePath → reusedBySegmentIds` 映射，并标明尚未生成或待重做的版本。

## 中文提示词骨架

把下列结构写成自然、具体的中文，不保留占位符：

```text
无人场景四视图设定图，[视觉媒介与时代风格]，整图为[成片画幅]，2×2 等尺寸四宫格，四格展示同一个[场景名称]的不同方向。左上 Front View（正面视图）：正对[主墙面或主要入口]，展示[正面可见内容]；右上 Left View（左侧视图）：从以正面视图为基准的场景左侧向内部观察，展示[左侧视角可见内容]；左下 Right View（右侧视图）：从场景右侧向内部观察，展示[右侧视角可见内容]；右下 Back View（背面视图）：朝正面视图的反方向观察，展示[背面墙或背面环境及其可见内容]。四格采用一致的平视相机高度、相近视野和真实透视，共同交代地面、立面、纵深、出入口、行动通道、固定家具与关键道具；空间布局固定为[空间布局和路线]，不得镜像或重新布置。材质为[墙地顶与家具材质]，均处于[时间/天气/状态]，主光在场景空间中固定从[方向]进入，[实用光源与色温]，投影随视角自然变化。画面中无人、无人形、无文字标签、无尺寸线、无水印、无装饰边框，仅保留四格清晰分区；不使用高机位俯视、垂直鸟瞰、二维户型图、等距插画或剖面图。
```
