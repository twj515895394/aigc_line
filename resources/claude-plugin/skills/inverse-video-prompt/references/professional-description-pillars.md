# 专业视频描述三大支柱

本参考用于最终视频提示词生成前的高优先级描述增强。它只聚焦三个最影响反推提示词质量的方面：

1. **情绪 → 可见表演（Visible Performance）**
2. **动作事件 → 动作质感（Action Quality）**
3. **镜头说明 → 画面效果（Visible Camera Effect）**

目标不是增加硬约束，也不是把每个镜头写得很长，而是把已经观察到的事实表达得更专业、更具体、更有视频感。

核心原则：

> **先写观众能够看到的变化，再用专业词总结；先写过程，再写结果；先写画面效果，再补技术名称。**

---

## 1. 情绪 → 可见表演

### 1.1 不要让情绪标签独立承担描述

“紧张、疲惫、警觉、亲密、犹豫、愤怒、悲伤、克制”可以作为总结词，但不能替代表演本身。

优先寻找这些可见证据：

- **视线**：落点、移动路径、回避、固定、追踪、突然停住
- **眼周**：眯起、睁大、张力增加、湿润、眨眼节奏
- **眉部**：内收、上提、眉间紧张
- **嘴部**：嘴角、抿唇、微张、笑意维持/减弱、颤动
- **下颌与脸部张力**：收紧、松开、短暂僵住
- **呼吸与喉部**：吸气、屏息、呼气、吞咽、呼吸变浅
- **头部**：转动幅度、速度、停顿、轻微低头/抬头
- **肩颈与躯干**：绷紧、松弛、后撤、靠近、保持静止
- **手部**：抓紧、松开、摩擦、覆盖、犹豫后接触、无意识小动作
- **动作量**：情绪越压抑时，动作可能反而越少

### 1.2 推荐表达结构

根据画面自由组合，不要求全部出现：

```text
可见起始状态
→ 某个细小变化首先出现
→ 其他面部/身体区域随后响应
→ 情绪被维持、压住或释放
→ 最终呈现出某种情绪状态
```

例如“警觉”：

弱：

```text
她显得警觉而紧张。
```

增强：

```text
她原本分散的视线逐渐固定下来，头部几乎不动，只让注意力缓慢转向后视镜；嘴唇轻微收紧，下颌保持克制的张力，身体动作反而减少，使警觉感更多来自持续观察而不是夸张反应。
```

例如“疲惫但坚持”：

弱：

```text
男性显得疲惫而坚决。
```

增强：

```text
他始终把视线钉在前方道路上，眼周和面部肌肉保持较重的紧张感，嘴部几乎没有多余表情；握方向盘的动作稳定但略显僵硬，疲惫没有转化成迟疑，而是表现为一种持续压住身体反应的专注。
```

例如“克制的亲密”：

弱：

```text
两人显得亲密而克制。
```

增强：

```text
两人没有明显拥抱或大幅度情绪反应，身体仍各自保持原来的驾驶和乘坐姿态；亲密感主要来自短暂而主动的手部接触，以及接触之后没有立即分开的停留。
```

### 1.3 复合情绪优先描述“冲突”

真实表演经常不是单一情绪。

例如：

- 嘴角仍有笑意，但眼睛已经湿润
- 身体想靠近，但视线回避
- 手在发抖，但动作仍然完成得很慢
- 表情很平静，但呼吸和下颌暴露紧张

遇到这类情况，不要强行压缩成一个标签。

推荐：

```text
她仍试图保持浅笑，嘴角没有完全放下，但眼神已经失去原来的轻松感；表面的笑意和眼周逐渐上升的情绪同时存在，使“强忍”本身成为表演重点。
```

### 1.4 避免心理小说化

不要把：

```text
她低头了一下。
```

擅自写成：

```text
她想起过去的创伤，因此陷入悲伤。
```

可以写：

```text
她短暂避开视线，表情从开放变得更收敛，呈现出犹豫或情绪压制感。
```

## 2. 动作事件 → 动作质感

### 2.1 动作描述的重点是“怎么发生”

动作名称只是起点。

当画面允许时，从以下维度选择最有价值的几项：

- **起始姿态**：动作从什么状态开始
- **触发/停顿**：是否先犹豫、蓄力、等待、确认
- **路径**：直线、弧线、向内、向外、跨过身体、贴近表面
- **速度**：缓慢、突然、逐渐加速、先快后慢
- **力度**：轻触、稳稳推动、快速甩开、沉重撞击
- **重量感**：物体或身体是否有明显惯性
- **身体参与**：只动手腕，还是肩膀/躯干一起参与
- **接触方式**：抓、握、覆、推、托、碰、滑过
- **反馈**：衣料、头发、烟尘、液体、物体是否产生响应
- **余势**：动作结束后是否继续滑动、震动、摇摆、回弹
- **结束状态**：手停在哪里、身体距离是否变化、物体最终状态

### 2.2 推荐表达结构

```text
起始状态 + 动作启动方式 + 路径/速度/力度 + 接触或反馈 + 结束状态
```

不要求全部使用。

例如“抬起打火机”：

弱：

```text
他抬起打火机点燃雪茄。
```

增强：

```text
他在继续驾驶的同时，从较低位置抬起空着的那只手，打火机沿身体前方缓慢靠近雪茄末端；动作幅度很小，没有明显急促感，手腕在接近嘴边时短暂停住，再完成点火。
```

如果画面能看到火光，可进一步写：

```text
短暂火焰在雪茄末端亮起，同时给墨镜边缘和脸侧带来一瞬偏暖的局部高光，随后迅速消失。
```

例如“握手”：

弱：

```text
女性伸手和男性握住。
```

增强：

```text
女性先把手伸到两人之间，动作不快，手掌在靠近时略有停顿；男性没有转头，只从驾驶姿态中腾出一只手回应，两只手在画面中央短暂交叠并保持接触，动作很小，却成为这一镜最明确的关系变化。
```

例如“推开”：

弱：

```text
她把他的手推开。
```

增强：

```text
她没有突然甩开，而是先停住一瞬，再用前臂和肩部缓慢把对方的手从自己身后移开；接触过程持续而克制，完成后她的上半身也随之轻微拉开距离。
```

### 2.3 关系动作比孤立动作更重要

当动作发生在两个角色之间，描述：

- 谁先发起
- 谁回应
- 是否同步
- 是否犹豫
- 是否有视线交流
- 接触持续多久
- 动作后两人的空间关系怎样改变

这通常比单纯写“牵手”“拥抱”“推开”更能复刻表演。

### 2.4 小动作也可以很有价值

当镜头是中近景/特写时，以下动作可能比大动作更重要：

- 手指逐渐收紧
- 拇指轻微摩擦
- 雪茄在嘴角轻微移动
- 呼吸带动肩膀
- 头部随车辆颠簸产生被动小幅运动
- 手腕停顿后继续
- 视线和动作不同步

前提是画面确实可见。

### 2.5 不要把“动作质感”写成编舞扩写

如果只看到“手抬起来”，不要凭空补：

```text
先摸口袋 → 掏出物体 → 翻转 → 旋转手腕 → 按钮弹开 → 点燃
```

除非视频真的展示了这些步骤。

## 3. 镜头说明 → 画面效果

### 3.1 技术名称只回答“它叫什么”

高质量反推还需要回答：

- 主体在画面里怎么变化
- 背景怎么变化
- 前景怎么掠过
- 空间深度怎么改变
- 透视有没有变化
- 画面稳定性是什么质感
- 焦点/景深怎样重新分配注意力
- 镜头动作什么时候开始、什么时候停
- 这种运动如何影响画面节奏和观看感受

因此推荐：

```text
[可选技术名称] + [画面中实际发生的视觉变化]
```

### 3.2 稳定镜头也要描述运动质感

弱：

```text
镜头稳定，带轻微震动。
```

增强：

```text
整体构图始终保持稳定，人物和挡风玻璃框架没有明显漂移；车辆行驶只带来持续、细碎、低幅度的轻微颠簸，使车内线条和人物产生真实的被动震动，而不是明显手持摇晃。
```

### 3.3 缓慢推进

弱：

```text
镜头缓慢推近。
```

增强：

```text
镜头在整个表演过程中以很轻的速度逐渐靠近，人物面部占画比例持续增加，背景信息被慢慢挤出注意中心；推进没有明显启动感，而是在情绪逐渐收紧时悄悄缩短观众与人物之间的距离。
```

最后一句属于“观看效果”描述，不是硬技术约束。

### 3.4 跟拍 / 后退跟随

弱：

```text
镜头跟随人物后退。
```

增强：

```text
人物持续向镜头方向前进，而摄影机以接近的速度后退，使主体在画面中的尺寸基本稳定；与此同时，地面与两侧环境快速向后产生明显视差，速度感主要由背景运动而不是主体尺寸变化建立。
```

### 3.5 后视镜 / 反射镜头

反射镜头重点不只是“镜中有什么”，还要分析：

- 镜框在画面中的占比和位置
- 镜内与镜外是否同时存在信息
- 两层空间谁清晰、谁虚化
- 镜中人物和远方事件是否竞争注意力
- 焦点是否发生转移
- 镜面震动是否与车辆/人物运动一致

例如：

```text
后视镜成为画面中心的第二层空间：女性的脸和后方公路被压缩在同一块狭窄镜面里，而镜外真实车内只保留少量辅助信息。后方车辆最初只是镜面深处的小型闪光点，随着距离缩短逐渐变大，使人物倒影与外部威胁在同一视觉区域里持续叠加。
```

### 3.6 Rack Focus / 焦点转换

弱：

```text
焦点从汽车转到人物眼睛。
```

增强：

```text
开始时远处目标保持更清晰，人物倒影略软；随后清晰区域逐渐从深处移动到人物面部，背景追踪目标变得柔化，观众注意力也从外部威胁转回人物的即时反应。
```

### 3.7 Handheld / Vehicle Vibration / Rough Motion 要区分质感

不要只写“手持感”。可描述：

- 是否随机
- 是否持续
- 幅度大小
- 是否跟随脚步/车辆/呼吸
- 是否有水平漂移或垂直冲击
- 构图是否仍然可控

例如：

```text
镜头不是自由手持式漂移，而是以稳定机位为基础叠加车辆路面反馈：轻微垂直颠簸和细小横向偏移持续存在，但主体构图始终可读。
```

### 3.8 镜头效果不要写成心理因果断言

可以写：

```text
逐渐靠近的构图让面部细节占据更多画面，压迫感随之增强。
```

不要无证据写：

```text
镜头推进象征她童年创伤重新浮现。
```

## 4. 三大支柱的联合描述

真正高质量的句子通常同时包含两到三个层次。

例如，一个简单的车内握手镜头：

基础：

```text
女性伸手和男性握住，镜头稳定，两人很亲密。
```

专业增强：

```text
女性先从副驾驶一侧缓慢把手伸到两人之间，接近时有一个很短的停顿；男性没有移开前视视线，只从驾驶姿态中腾出一只手回应。两只手在挡风玻璃双人构图的中央短暂交叠，整体机位依旧稳定，仅保留车辆行驶带来的细碎震动。两人几乎没有额外表情或身体靠近，关系变化因此主要通过这次小幅、持续的手部接触显现出来。
```

这里同时完成：

- **Performance**：不转头、不夸张表情、克制回应
- **Action Quality**：缓慢伸手、停顿、回应、持续接触
- **Camera Effect**：稳定构图 + 车辆细碎震动 + 中央视觉焦点

## 5. 推荐句法模式

这些是思考模式，不是固定模板。

### Performance

```text
[原始表情/姿态]，随后 [第一处可见变化]；[第二处身体/面部响应]，使 [情绪总结] 以克制/明显/突然的方式逐渐显现。
```

### Action

```text
从 [起始状态] 开始，主体 [以某种速度/力度] 沿 [路径] 完成动作；[接触/物理反馈]，最后停在 [结束状态]。
```

### Camera

```text
镜头 [技术动作或稳定方式]，使 [主体尺寸/构图/焦点] 发生变化，同时 [背景/前景/视差/透视] 呈现出 [可见运动效果]。
```

### Combined

```text
[表演变化] 与 [动作过程] 同时发生；镜头通过 [可见画面变化] 保持/强化对这一变化的关注。
```

不要为了满足句法模式而填入不存在的信息。

## 6. 描述密度控制

### 简单镜头

选择最重要的一项增强即可。

### 中近景人物镜头

优先：

1. Performance
2. Action Quality
3. Camera Effect

### 动作镜头

优先：

1. Action Quality
2. Camera Effect
3. Performance reaction

### 脸部特写

优先：

1. Performance / Micro-expression
2. Temporal change
3. Camera / focus effect

### 风景/环境镜头

这三项不是重点时，不要强行套用；转而依赖空间、光线、材质和环境描述。

## 7. 最终编译前的三问

对每个重要 Shot，快速检查：

1. **情绪是否仍然只是标签？**
   - 如果是，而且可见证据足够，把它改写成眼神、面部、呼吸、姿态或手部表现。

2. **动作是否仍然只是动词？**
   - 如果是，而且动作重要，补充路径、速度、力度、停顿、接触、反馈或结束状态中的关键项。

3. **镜头是否仍然只是术语？**
   - 如果是，补充主体尺寸、构图、视差、透视、焦点、稳定性或背景运动等实际画面效果。

如果三项都已经足够，不继续扩写。**专业度来自准确的可见过程，不来自字数。**
