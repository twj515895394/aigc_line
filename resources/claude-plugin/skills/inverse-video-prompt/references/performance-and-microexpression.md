# 人物表演与微表情反推

本参考用于人物近景、特写、情绪递进、克制表演、哭戏、笑戏、惊讶、犹豫、愤怒、恐惧等以“表演过程”为核心的视频。

目标不是给人物贴一个情绪标签，而是尽可能从可见证据中还原：**情绪如何通过眼神、眉部、嘴部、下颌、呼吸、头部、肩颈与细小动作，在时间中逐渐发生变化。**

## 1. 基本原则

1. **先描述可见变化，再总结情绪。**
2. **微表情是时间过程，不是静态表情词。**
3. **不要强行解释人物心理。** 可以写“表现出犹豫/强忍”，但不要凭空解释“因为想起童年所以悲伤”。
4. **不要要求每个部位都变化。** 真实克制表演常常只有少数区域发生明显变化。
5. **变化幅度很小时，要描述克制感。** 不要把轻微眼神变化夸成夸张哭喊。
6. **看不清就降级。** 分辨率、遮挡、墨镜、侧脸或快速运动会限制微表情判断。

## 2. Performance Timeline

对于明显存在情绪变化的连续镜头，优先建立表演时间线。

可按自然阶段拆分，而不是固定等分：

```text
initial state
→ subtle shift
→ emotional trigger/reaction
→ restraint or escalation
→ threshold
→ release / recovery / unresolved end
```

例如“高兴逐渐要哭”：

```text
自然笑意
→ 笑容出现停顿
→ 眼神开始失去轻松感
→ 试图维持笑意并压住情绪
→ 眼眶湿润、呼吸变化
→ 笑意消失，接近落泪或真正落泪
```

不要为了凑阶段而机械切分。一个 10 秒镜头可能有 3 个明显阶段，也可能有 6 个细微阶段。

## 3. 眼睛与视线 Gaze / Eyes

重点观察：

- 视线落点：镜头、对手、下方、远处、游移
- 视线移动速度：突然、缓慢、迟疑
- gaze hold：是否突然固定
- focus quality：眼神是否从明亮集中变得发空、失焦或回避
- eyelid tension：上下眼睑是否收紧或放松
- blink pattern：眨眼是否变频、变慢、连续快速眨眼或长时间不眨
- moisture：眼眶是否逐渐出现湿润、高光、水膜或泪液
- squint / widening：是否轻微眯眼或睁大

基础：

```text
她变得难过。
```

增强：

```text
她原本明亮而稳定的视线出现短暂停顿，眼睛缓慢移向下方；再次抬眼时注视变得更固定，眨眼次数减少，眼眶逐渐出现湿润的高光，但她仍没有让眼泪立即落下。
```

### 泪意不要一步到位

如果视频中是“逐渐要哭”，优先描述：

```text
眼周紧张 → 眼眶湿润 → 水膜明显 → 泪液积聚 → 泪珠形成 → 滑落
```

只写实际可见到的阶段。

## 4. 眉部 Brows

可观察：

- 内眉上提
- 眉间靠拢
- 外眉下压
- 一侧眉毛轻微变化造成复杂情绪
- 眉部保持不动但眼周开始紧张

眉部变化往往和眼神一起构成委屈、担忧、压抑、怀疑或痛苦，但不要仅凭一个眉形就断言复杂心理。

例如：

```text
眉间没有明显夸张皱起，只是内侧眉峰非常轻微地上提，使原本放松的笑容逐渐带出脆弱和强忍感。
```

## 5. 嘴部 Lips / Mouth

重点观察：

- 嘴角上扬幅度
- 左右是否对称
- 笑容是否维持、变僵、逐渐消失
- 嘴唇是否闭紧、抿住、张开
- 下唇是否轻微颤动
- 是否吞咽、吸气、试图重新微笑
- 是否笑着哭、哭着维持礼貌笑容

例如“笑意逐渐崩掉”：

```text
最初嘴角自然上扬，笑容松弛；随后嘴角保持在原位置却不再继续上扬，像是表情短暂冻结。几秒后上扬幅度缓慢减小，嘴唇轻轻抿住，下唇出现很小的紧张和不稳定，最后笑意彻底退出面部。
```

## 6. 下颌、面中部与肌肉张力

可观察：

- jaw clench / 下颌收紧
- chin tension / 下巴肌肉紧张或细小颤动
- cheek tension / 颧部与脸颊从笑容支撑转为松弛
- nostril / 鼻翼细微变化
- facial freeze / 面部突然僵住
- asymmetry / 左右不对称的小幅变化

这些细节适合辅助描述强忍、愤怒、悲伤、压抑或犹豫，但不要硬套生理规律。

## 7. 呼吸、喉部与吞咽 Breath / Throat

当画面可见时，呼吸是表演的重要组成：

- 胸口/肩部起伏
- 鼻吸或口吸
- 突然屏息
- 短促吸气
- 长呼气
- 吞咽
- 喉结或颈部肌肉变化
- 哭前试图稳定呼吸

例如：

```text
她短暂屏住呼吸，肩膀几乎不动；随后吸入一口很浅的气，嘴唇仍然闭着，像是在主动压住即将失控的情绪。
```

如果画面只拍脸且看不到肩胸，不要虚构明显呼吸动作。

## 8. 头部、肩颈与姿态

微表情不只发生在脸部。

观察：

- head tilt / 轻微偏头
- chin drop / 下巴逐渐降低
- head stillness / 原本活动的头部突然静止
- withdrawal / 身体后撤
- lean-in / 微微靠近
- shoulder tension / 肩膀变紧
- neck tension / 颈部绷紧
- posture collapse / 姿态轻微塌下

例如：

```text
她仍然保持正面朝向镜头，但下巴比最初降低了一点，头部动作逐渐减少，最后几乎完全静止；这种静止让眼睛和嘴部的细小变化变得更加明显。
```

## 9. 手部与自我调节动作

近景中如果能看到手部，可关注：

- 握紧/松开
- 指尖摩擦
- 抓衣角
- 触摸脸、脖子、头发
- 无意识的小动作突然停止
- 握住物体作为情绪支撑

这些可以增强表演描述，但不要把常规动作过度心理化。

## 10. 情绪转换的“可见机制”

不要只写：

```text
高兴 → 悲伤
```

更有价值的是：

```text
笑容先停顿而不是立即消失；眼神随后发生变化；人物尝试重新维持笑意；眼眶开始湿润；嘴唇和下颌出现强忍的紧张；最后笑容彻底失去支撑。
```

常见转换可参考：

### 开心 → 想哭

- 笑容保持但逐渐变僵
- 眼神先于嘴部变得复杂
- 视线短暂躲开或固定
- 眼眶湿润
- 嘴角缓慢下降或抿紧
- 呼吸/吞咽变化
- 强忍后才出现泪液

### 平静 → 愤怒

- 视线变得集中
- 眨眼减少
- 下颌和嘴唇收紧
- 眉间张力增加
- 呼吸变深或动作变少
- 最后才可能出现更明确的爆发动作

### 怀疑 → 决绝

- 视线游移/观察
- 停顿
- gaze lock
- 面部多余动作减少
- 嘴唇或下颌固定
- 姿态转为稳定

### 惊讶 → 恐惧

- 眼睛/眉部先快速变化
- 嘴部短暂打开或呼吸停顿
- 视线寻找威胁来源
- 身体开始后撤或僵住
- 情绪由瞬时反应转为持续紧张

这些只是观察启发，不是必须套用的模板。

## 11. 克制表演 Restraint

很多高质量表演不是“情绪越大越好”。当视频呈现压抑、强忍、若无其事或笑着难过时，特别注意：

- 表情变化幅度是否非常小
- 是否存在“想表现正常”的反向动作
- 嘴在笑、眼睛却开始湿润
- 眼神失去笑意，但嘴角仍维持
- 快要哭时反而把头抬高/看向别处
- 强忍导致动作突然减少

描述这种“两个信号同时存在”的状态，比单一情绪词更有价值。

例如：

```text
她仍然努力维持嘴角的浅笑，但眼睛已经不再带笑；眼眶逐渐泛湿，下颌开始收紧。笑容和悲伤短暂同时存在，形成明显的强忍感，随后嘴角才缓慢失去支撑。
```

## 12. 表演强度与速度

描述：

- subtle / barely perceptible
- restrained
- gradual
- hesitant
- sudden
- involuntary
- controlled
- escalating
- breaking / releasing

例如：

```text
变化非常缓慢且克制，没有夸张哭相；前半段主要依靠视线和嘴角细微变化，真正明显的情绪失守直到最后两秒才发生。
```

这种总体强度描述对视频生成模型非常有用。

## 13. 10 秒脸部特写示例

### Evidence Pattern

一个连续 10 秒脸部特写。人物最初自然开心，随后逐渐被情绪触动，最后接近哭泣。镜头本身变化很少，表演是主要信息。

### Performance Timeline

```text
0.0–2.0s
自然轻松的笑容，嘴角稳定上扬，眼神明亮并保持交流感，面部肌肉松弛。

2.0–4.0s
笑容出现第一次很轻的停顿；眼神短暂向下移动，再重新抬起。嘴角仍在笑，但眼睛里的轻松感开始减弱。

4.0–6.0s
人物努力维持原来的笑意，嘴角幅度开始缓慢收小；眨眼和视线停顿更明显，眼眶逐渐出现湿润高光，下颌轻微收紧。

6.0–8.0s
眼睛已经明显不再带笑，水膜感增强。人物短暂屏住或控制呼吸，嘴唇轻轻抿住，笑容和悲伤在脸上同时存在，形成克制的强忍状态。

8.0–10.0s
嘴角最终失去笑容，视线变得固定而脆弱；下唇或下巴出现非常轻微的不稳定，眼眶中的泪意达到临界点，最后接近落泪或出现第一滴泪，但没有夸张哭喊。
```

### Compiled Performance Prompt

```text
保持连续脸部特写，让整个 10 秒几乎完全依靠细微表演完成情绪转换。人物最初带着自然、松弛的笑容，眼神明亮。随后笑意先出现几乎不可察觉的停顿，视线短暂向下再抬起；嘴角仍努力维持，但眼睛逐渐失去原本的轻松感。中段眼眶慢慢泛起湿润高光，下颌和嘴唇出现轻微紧张，人物像是在主动把情绪压回去。后段让“仍在笑”和“已经想哭”短暂同时存在：嘴角保留一点浅笑，眼睛却明显泛湿，呼吸变得克制。最后两秒笑容才真正消失，视线固定，嘴唇轻抿，下唇或下巴出现很轻的颤动，泪意达到临界点。整个过程缓慢、细腻、克制，不突然切换情绪，不做夸张哭相。
```

## 14. 不确定性与遮挡

以下情况应降低细节确定性：

- 墨镜遮挡眼睛
- 刘海遮眉
- 侧脸导致一侧面部不可见
- 强运动模糊
- 低清晰度
- 强逆光
- 快速剪辑
- 美颜/动画风格削弱真实肌肉变化

此时可写：

```text
可见的嘴角和下颌逐渐收紧；眼部细节被墨镜遮挡，无法可靠判断眨眼和泪意变化。
```

不要补出看不到的细节。

## 15. 使用建议

优先读取本参考的场景：

- 面部特写或大特写
- 单镜头人物表演
- 情绪变化是视频主要内容
- 哭戏、笑戏、克制表演
- 用户明确要求微表情、演技、表演过程
- 表情变化决定最终 Prompt 质量

对于动作片、风景、产品、机械流程等不依赖人物表演的视频，无需强制加载本参考。
