# 视频描述增强与专业表达

本参考用于在完成基础视频反推之后，对描述进行第二层增强。目标不是增加更多硬约束，而是让输出更丰富、更专业、更像摄影指导、导演、表演指导或美术指导对画面的描述，同时始终以可见证据为基础。

核心原则：**丰富描述，不等于增加剧情；专业表达，不等于虚构技术参数。**

## 1. 描述增强的目标

基础反推通常回答：

- 画面里是谁/是什么
- 在哪里
- 做了什么
- 镜头怎么拍
- 光线和风格是什么

描述增强进一步回答：

- 动作是如何发生的
- 表演是如何显现的
- 构图内部各元素如何组织
- 镜头运动在画面中呈现出怎样的视觉效果
- 光线如何作用于人物、材质和空间
- 材质具体呈现出什么表面特征
- 环境如何建立空间深度、空气感和尺度
- 一个视觉状态如何随时间逐渐变化成另一个状态
- 氛围是由哪些可见因素共同形成的

不要为了“高级”而添加没有证据的镜头焦段、灯具型号、摄影机品牌、精确角度、具体速度或剧情解释。

## 2. Performance / 表演描述

当人物表演是镜头重点时，不要只用抽象情绪词。

除了“开心、警觉、犹豫、愤怒、悲伤、疲惫”等总结性词语，还应根据可见证据描述：

- gaze / 视线方向与移动路径
- eye tension / 眼周紧张程度
- blink / 眨眼和停顿
- brow / 眉部变化
- mouth / 嘴角、嘴唇状态
- jaw / 下颌与面部肌肉张力
- breath / 呼吸节奏与屏息
- head movement / 头部转动幅度和速度
- shoulders / 肩颈姿态
- hand behavior / 手部无意识动作
- restraint / 情绪压制
- release / 情绪释放

优先把抽象情绪翻译成可见表演。

基础：

```text
她变得警觉。
```

增强：

```text
她的视线从后视镜下缘缓慢抬起，转动幅度很小；嘴唇逐渐收紧，下颌轻微绷住，原本游移的观察变成稳定而持续的凝视，情绪仍然被克制在很小的面部动作里。
```

如果细节无法看清，可以保留更概括的情绪描述，不要硬造微表情。

## 3. Action / 动作质感

动作不仅描述“做了什么”，还可以描述“怎么做”。

根据画面选择性记录：

- starting posture / 起始姿态
- path / 动作路径
- speed / 速度
- acceleration / 加减速
- force / 力度
- weight / 重量感
- body participation / 身体参与程度
- hesitation / 犹豫与停顿
- inertia / 惯性
- follow-through / 动作余势
- final state / 动作结束状态

基础：

```text
她移开男人的手。
```

增强：

```text
她先短暂停顿，没有猛地甩开对方，而是用前臂和肩膀缓慢把他的手从自己身后移开；动作幅度不大但态度明确，随后身体轻微向车门方向拉开距离。
```

动作描述应服务于可见运动，不要把一个简单动作扩写成不存在的复杂 choreography。

## 4. Composition / 构图与画面内部关系

不要只记录“谁在左、谁在右”。在构图明显重要时，可进一步描述：

- foreground / midground / background
- subject scale / 主体占画比例
- visual weight / 画面权重
- negative space / 留白
- frame-within-frame / 框中框
- leading lines / 引导线
- center of attention / 视觉中心
- overlap / 遮挡和重叠关系
- symmetry / asymmetry
- depth layering / 空间层次
- narrative anchor / 具有叙事功能的构图锚点

例如：

```text
女性位于前景左侧，男性位于右侧并稍靠近镜头；方向盘与挡风玻璃形成下方和前方的视觉框架，中央后视镜悬在两人之间，既稳定双人构图，也成为后续追车信息进入画面的视觉中心。
```

只描述画面实际支持的关系，不要把所有构图都套进固定理论术语。

## 5. Camera / 运镜的“可见效果”

技术名称有帮助，但最终描述应尽量说明镜头运动在画面中呈现了什么。

除了 pan / tilt / dolly / tracking / orbit / handheld 等词，可补充：

- 主体在画面中的尺寸如何变化
- 主体是否被稳定保持在某个构图位置
- 背景视差如何变化
- 前景掠过速度
- 透视是否改变
- 运动是否平稳、漂浮、粗粝、颠簸、克制
- 运镜何时开始、何时停止
- 镜头动作是否与人物动作同步

基础：

```text
轻微手持。
```

增强：

```text
构图整体保持稳定，但画面持续带有细碎、低幅度的不规则震动，使人物和车内结构产生真实行驶中的轻微漂移，而不是明显的剧烈摇晃。
```

基础：

```text
镜头缓慢推进。
```

增强：

```text
镜头以几乎不可察觉的速度向人物靠近，面部在画面中的比例逐渐增大，背景信息缓慢退出注意中心；推进本身不抢戏，而是在情绪发生变化时逐步增加压迫感和亲密距离。
```

## 6. Lighting / 光线如何作用于画面

除了光源类别和色温，还应描述光线“落到哪里、如何变化、形成什么视觉结果”。

可观察：

- source direction / 入射方向
- hard vs soft / 软硬
- falloff / 衰减
- key / fill / rim relationship
- highlight behavior / 高光特征
- shadow density / 阴影浓度
- skin response / 皮肤受光
- reflective response / 金属、玻璃、湿地等反射
- moving light / 光影是否随运动变化
- exposure transitions / 曝光是否变化

例如：

```text
炽热日光从挡风玻璃斜向进入车内，在人物面部形成偏暖的硬侧光。车辆前进时，车体框架和沿途阴影不断切割光线，明暗条带快速掠过皮肤、墨镜和米色内饰；高光略带曝晒感，阴影较深但仍保留皮肤纹理。
```

## 7. Material / 材质与表面特征

当材质对风格和年代感有贡献时，不只写“红色车漆”“皮衣”“金属门”。可根据可见证据描述：

- new / aged / worn / polished / oxidized
- glossy / matte / satin
- scratches / dust / folds / dents / patina
- transparency / translucency
- reflection softness
- wetness / dryness
- fabric weight
- skin texture
- smoke / dust / particle density

例如：

```text
红色车漆经过长期日晒后饱和度略微衰减，表面仍保留不均匀的高光和轻微旧化质感；米黄色内饰带有老式皮革或乙烯基材料的细小折痕与使用痕迹。
```

不要把无法分辨的材质强行确定为某一种具体材料。

## 8. Environment / 空间、空气与尺度

环境描述不要只停留在“荒漠、公路、仓库、卧室”。根据画面补充：

- openness / enclosure / 开阔或封闭
- horizon / vanishing depth
- foreground-midground-background separation
- spatial anchors
- scale cues
- atmospheric perspective
- haze / heat shimmer / fog / dust
- background activity
- density / emptiness
- environmental motion

例如：

```text
笔直公路穿过几乎没有遮挡物的开阔荒漠，地平线压得很低，远处空气因高温产生轻微热浪扭曲；道路两侧浅黄褐色沙土不断向后掠过，使高速运动显得更加孤立、暴露而持续。
```

## 9. Temporal Change / 时间变化描述

视频描述应特别重视“如何从 A 变化到 B”。

对于任何重要变化，尽量识别：

```text
初始状态 → 开始变化 → 变化加深 → 临界点/峰值 → 结束状态
```

可以用于：

- 表情
- 姿态
- 速度
- 距离
- 光线
- 焦点
- 景深
- 烟雾
- 粒子
- 反射
- 背景运动
- 追踪目标接近
- 颜色或曝光变化

基础：

```text
警车逐渐接近。
```

增强：

```text
起初追踪车辆只是后视镜深处很小的闪光点；随后它们在镜面中的尺寸持续增大，红蓝闪光从被热浪压缩的模糊色块逐渐变得更清晰，距离感和压迫感不断增强。
```

这类“时间过程”通常比增加静态形容词更有价值。

## 10. Atmosphere / 氛围来源

可以使用“紧张、暧昧、危险、温柔、压抑”等总结词，但尽量说明氛围由哪些可见因素构成。

例如：

```text
两人的身体距离很近，却几乎没有直接交流；男性手臂停留在女性身后形成若即若离的亲密感，而后视镜中不断逼近的警灯持续制造外部威胁。暖金色日光与褪色红色车漆提供表面的浪漫公路片质感，但克制的肢体动作和越来越固定的视线让画面始终带着潜在危险。
```

不要用大量情绪形容词替代具体可见信息。

## 11. 描述增强的使用强度

描述增强不是要求每个 Shot 都把所有维度写满。片种补丁同样是加法：空槽不填，不把 18 维检查清单当成增强完成。无字幕、无小窗时不要补图形填空。

### 轻量增强

适用于简单镜头：只补最有价值的 1–3 类细节。

### 详细增强

适用于需要忠实复刻的多镜头视频：对表演、动作、构图、光线、空间和时间变化进行较完整描述。

### 表演/摄影重点增强

当视频核心是人物表演、镜头语言、光影或材质时，把对应维度写得更细，其他部分保持克制。

## 12. 最终检查

增强描述后确认：

- 是否增加了“如何发生”，而不仅是更多名词。
- 是否增加了时间过程，而不是把视频写成静态图片。
- 是否把抽象情绪落到了可见表演上。
- 是否说明运镜的画面效果，而不仅是术语。
- 是否说明光如何作用于主体和空间。
- 是否描述了材质、空气、空间层次等真实视觉属性。
- 是否所有新增细节都有视觉依据或被明确写成合理推测。
- 是否避免为了专业感而虚构精确技术参数。
- 是否避免 8K / 帧率 / 抗锯齿 / 无噪点等生图画质开关。
- 是否每个镜头都能读出起始画面和结束画面。

最终目标：**让 Prompt 更丰富、更可视、更有专业影像语言，但仍保持开放，不把参考视频过度翻译成僵硬的生成规则。**
