# 片种补丁

主分析维不够用、且视频主类型可识别时，再读本页。本页是加法，不替换 Subject / Action / Performance / Camera / Lighting 等基础维，也不要求每个镜头填满补丁字段。

识别不出主类型：不加载。不要追问用户选类型。不要为了「看起来专业」给风景写微表情、给产品写哭戏。

最多选一层主补丁。广告里夹一句对白，仍走广告；剧情里闪一下产品，仍走剧情。

## 如何并入交付合同

补丁字段写进该镜头的五段合同，不要另开一套平行 Prompt：

- 站位、视线、正反打 → 起始画面 / 结束画面 / 主体动作
- 产品角度、手-产品、Logo → 起始画面 / 主体动作 / 结束画面
- 大气透视、地形运镜 → 摄影机运动 / 环境
- 节拍与快切 → 镜头衔接 / 节奏
- 台面布局、材质状态 → 起始画面 / 主体动作 / 结束画面
- 字幕、小窗 → 图形层；有则写入对应镜头，无则整层缺省

## 剧情 / 人物

只在有对话、对视、反应镜头或多人调度时启用。

可补：

- 每人情绪弧：可见起点 → 变化节点 → 终点，落到眼神、嘴角、呼吸、肩颈
- 多人空间：站位、距离、朝向、谁挡住谁、谁先动
- 正反打：谁的过肩、是否跳轴、视线是否交叉
- 对白密度：有词 / 停顿 / 沉默的可见功能；听不清则不编台词

正反打最小写法：

```text
起始画面：A 过肩看向画面右外的 B。
主体动作：A 视线锁在 B，中途一次短暂停顿后开口；B 只露肩背。
结束画面：A 仍看向右外，头未翻到镜头。
镜头衔接：HARD CUT 到 B 的反向过肩，视线应对画面左外的 A，不跳轴。
```

不要把「开心/紧张」写进补丁却不写可见表演。

## 产品 / 商业广告

只在产品是反复出现的被展示对象时启用。

可补：

- 每次入画的展示角度（正面 / 四分之三 / 顶视 / 细节）
- 手-产品交互：拿起、放下、旋转、按压、倾倒；几只手、哪只手、接触点
- 材质高光落在哪、是否随转动滑动
- Logo 何时完整可见、何时被手指或转角遮住
- 信息节奏：快切推情绪 vs 停住推细节
- 字幕 / 价格 / 标题交给图形层，这里只写它们是否抢走产品

手-产品最小写法：

```text
起始画面：产品四分之三侧置于桌面，Logo 正向镜头。
主体动作：一只右手从画面右缘进入，拇指与食指捏住瓶身中段旋转约四分之一圈，Logo 转到最完整可见后停住；全程只有这一只手、这一件产品。
结束画面：手仍握瓶，产品停在 Logo 正向，高光沿玻璃弧面停在左上。
```

## 风景 / 旅行

只在空间、天气、地形或大气是观看主体时启用。

可补：

- 大气透视：近清晰 → 中略降对比 → 远朦胧
- 自然光时段是否在镜内变化（通常不变；变了才写）
- 运镜如何贴地形：沿脊线摇、顺河流跟、越过山头升降
- 环境运动：云、水、草、尘，与主体/镜头谁更快

不要编具体焦段。写透视压缩或空间延伸的可见效果即可。

## 音乐 / MV

只在剪辑明显踩拍、或段落节奏随音乐块变化时启用。

可补：

- 切点落在可见动作峰值、口型峰值还是灯光闪白
- 段落节奏：前奏长镜 / 副歌快切 / 间奏空镜（只写实际看见的）
- 色彩或特效是否随段落切换

听不清原曲：只描述可见剪辑节奏，不编歌名、歌词或 BPM。声音层仍按推荐逻辑写。

## 美食 / 手工 / 教程

只在步骤、手部操作或材料状态变化是主体时启用。

可补：

- 俯拍台面：工具、材料、成品的左右前后关系
- 特写触发点：关键步骤、材质变化、完成瞬间
- 手部动作：切、搅、倒、撒的速度与力度；几只手
- 材质状态链：稀 → 浓、生 → 熟、散 → 成形，只写看见的阶段

特写不要无故切断状态：切之前的材料形态必须能接到切之后。

## 明确不要做的

- 不给每个镜头套全部五类补丁
- 不把片种关键词（电影感、日系清新、广告大片）当成分析完成
- 不因为选了剧情就把风景空镜写成人物情绪
- 不把补丁写成必填表
